# 日期检查

**⚠️ 用户原话："你那个日期的skill，好像没有生效"**

执行任何日期相关任务前，先运行：

```bash
date
```

输出格式：`Mon Jun 22 09:16:32 CST 2026`

根据输出判断：
- 周一到周五 = 交易日（需进一步判断是否节假日）
- 周六周日 = 休市
- 交易时段：9:30-11:30, 13:00-15:00

**不要凭记忆猜日期，永远先查。**

**触发场景**（遇到以下情况必须先加载此skill）：
- 任何包含"今天""昨天""明天""周几""几月几号"的对话
- 选股系统的执行价采集、风险监控
- cron job的时间判断
- 文件名中包含日期的场景
