# OCR完整性验证模式

## 问题描述

即使用正确的切片高度（2000px）逐段OCR课件图片，vision_analyze仍可能遗漏整个章节。

### 真实案例（第十二课健康断病课件）

**课件实际内容（8个大点）：**
1. 伤灾官非（总纲核心法则）
2. 子平正统派断病
3. 盲派断病
4. 古典断病
5. 刑冲合断病
6. 十神断病
7. 高应验断病
8. 大运流年断病

**OCR识别结果（只识别出3个）：**
1. 伤灾官非（总纲核心法则）✅
2. 子平正统派断病 ✅
3. 盲派断病 ✅
4. 古典断病 ❌ 遗漏
5. 刑冲合断病 ❌ 遗漏
6. 十神断病 ❌ 遗漏
7. 高应验断病 ❌ 遗漏
8. 大运流年断病 ✅

**遗漏原因：**
- vision_analyze对长图切片的识别不完整
- 章节标题在切片边界附近时容易丢失
- 不同切片之间可能有重叠或间隙

## 验证流程

### 阶段0必须执行的交叉验证

```
1. 完成所有课件的切片OCR
2. screencapture -x /tmp/screen_now.png 截取用户屏幕
3. vision_analyze 看截屏，逐个数出所有大标题（一、二、三...八、）
4. 对比OCR输出中的章节列表
5. 检查是否有遗漏
6. 如果有遗漏，重新切片OCR遗漏部分
```

### 验证清单模板

```
📋 OCR完整性验证：
- 课件截图显示N个大点：[列出所有标题]
- OCR输出识别M个章节：[列出所有章节]
- 遗漏：[列出缺失的章节]
- 状态：✅完整 / ❌需补充
```

## 处理遗漏的方法

### 方法1：重新切片OCR
- 对遗漏部分重新切片，用更小的切片高度（如500px或200px）
- 逐片仔细识别，确保不遗漏

### 方法2：让用户截屏
- 如果重新切片仍无法识别，让用户截屏发过来
- 用vision_analyze分析用户截屏
- 手动补充遗漏内容

### 方法3：对比转录稿
- 在转录稿中搜索遗漏章节的关键词
- 从转录稿中提取内容补充到笔记

## 预防措施

1. **Phase 0必须交叉验证**：OCR完成后必须用screencapture验证
2. **数章节标题**：逐个数出课件中的所有大标题，对比OCR输出
3. **不要假设完整性**：即使用了正确的切片高度，仍可能遗漏
4. **用户反馈优先**：用户说"少了好多"时，立即重新验证
