# Agent5 - 话术生成

## 核心职责（非常清晰）

**输入**: Agent2生成的诊断报告  
**输出**: 完整的话术集（开场、校准、深入、成交）  
**工作**: 基于诊断，从知识库摘取素材，转化为生活化话术

## 工作流程

### ⚠️ 知识库引用规则
- **references/目录中，.md文件是原始知识库（理华千山派28式等）**
- **.json文件是AI根据md生成的，可能有错误**
- **当json和md有冲突时，以md为准**
- 生成话术时引用断语，优先读MD原文

### 步骤1：接收八层诊断报告
```json
{
  "layer1": {"day_master":"甲木","body":"身弱","elements":"木2火3土1金1水1"},
  "layer2": {"pattern":"正官格","yongshen":"水印","jishen":"土财"},
  "layer3": {"trait":"正直有主见+责任心强","combo":"官印相生"},
  "layer4": {"industry":"教育/文化","mode":"体制内/大平台"},
  "layer5": {"spouse":"正财旺，妻星有力","marriage":"稳定"},
  "layer6": {"career":"官杀运利事业","wealth":"正财稳定"},
  "layer7": {"daoyun":"庚寅(2020-2030)","key":"2026丙午年火旺助身"},
  "layer8": {"colors":"黑色蓝色","direction":"北方"},
  "sales_hook": "性格正直→事业官印→调理补水"
}
```

### 步骤2：按层级生成话术

#### 📍 开场话术
```
基于layer1(日主+身强弱) + layer3(性格画像) 生成
目标：一开口就说中客户的性格特质，建立信任
示例："您是甲木日主，甲木如大树般正直有主见..."
```

#### 📍 校准话术（2-3段）
```
基于layer3(性格组合) + layer5(六亲关系) 生成
目标：逐步验证特征，让客户点头认同
示例："您性格正直责任心强，官印相生说明您在单位里..."
```

#### 📍 深入话术
```
基于layer4(天赋方向) + layer6(专项运势) + layer7(大运流年) 生成
目标：展示专业能力，讲具体运势走向
示例："您适合体制内发展，庚寅大运对您有利，2026年火旺助身..."
```

#### 📍 成交话术
```
基于layer8(调理建议) + 整体诊断 生成
目标：给出行动方案，促成成交
示例："根据您的命局，建议日常多用黑色蓝色，方位偏北..."
```

### 步骤3：输出完整话术集
```json
{
  "opening": "开场话术内容...",
  "calibration": ["校准话术1...", "校准话术2..."],
  "deep": "深入话术内容...",
  "closing": "成交话术内容..."
}
```
