# 风险评估模块参考（V2 - 评分与风险分离）

## 概述

`risk_assessment.py` 实现三类信号分级评估。**V2核心改动：风险评估不再参与评分，只反映操作建议。**

## 评分与风险分离（V3设计）

### 设计原则
- **评分系统**：反映股票综合质量（基本面+资金面+趋势面），输出具体分数
- **风险系统**：反映当前操作建议，**不参与评分**，只影响买卖决策

### 为什么分离？
用户指出双重扣分问题：
```
原始评分48分（已因均线跌破等因素扣分）
风险调整-15分（又因均线跌破扣分）
最终33分（同一事件被扣了两次）
```

V3解决方案：评分和风险独立输出，风险只影响操作建议。

## 四级风险等级

| 等级 | 图标 | 操作建议 |
|------|------|----------|
| normal | 🟢 | 正常交易 |
| watch | 🟡 | 暂停新建仓，已有仓位继续观察 |
| risk | 🔴 | 暂停新建仓，已有仓位考虑减仓 |
| sell | 🚨 | 建议卖出，核心逻辑已破坏 |

## 评估的8类指标（只检测不扣分）

### 1. 股东人数（资金型指标，周度变化）
- **数据源**: 东方财富API `RPT_F10_EH_HOLDERNUMCHANGE`
- **watch**: 小幅增加(>3%)
- **risk**: 大幅增加(>10%)

### 2. 北向资金（资金型指标，周度变化）
- **数据源**: 东方财富API `RPT_MUTUAL_STOCK_NORTHSTA`
- **watch**: 连续3日流出
- **risk**: 持续大幅流出(>-1亿/3日)

### 3. 均线跌破（趋势型指标，日/周变化）
- **数据源**: K线数据计算
- **watch**: 跌破20日线
- **risk**: 跌破60日线或120日线

### 4. 成交量（趋势型指标）
- **数据源**: K线数据计算
- **watch**: 持续缩量(量比<0.5)
- **risk**: 放量下跌(量比>1.5且跌幅>3%)

### 5. 高位回调（趋势型指标）
- **数据源**: K线数据计算
- **watch**: 从高点回调20-30%
- **risk**: 从高点回调>30%

**V2改动**：突破位计算改用60日高点（而非120日），并增加回调幅度判断。原因：如果用120日最高价的95%作为突破位，对于从高位大幅回调的股票（如从37.95跌到23.55），突破位36.05和当前价差距太大不合理。

### 6. 公告风险（事件型指标，即时触发）
- **数据源**: 东方财富API `RPT_PUBLIC_OP_NEWPREDICT`
- **watch**: 风险提示（减持/质押/诉讼）
- **sell**: 重大风险（立案/造假/暴雷）

### 7. 资产负债率（稳定型指标，季度更新）
- **数据源**: 财务数据
- **watch**: 65-80%
- **risk**: >80%

### 8. 利润增长率（稳定型指标，季度更新）
- **数据源**: 财务数据
- **watch**: 增速放缓(<10%)
- **risk**: 转负增长
- **sell**: 大跌(<-30%)

## 输出格式

```json
{
  "level": "risk",
  "events": [
    {"event": "均线跌破", "level": "risk", "detail": "跌破MA60(24.44)"},
    {"event": "高位回调", "level": "watch", "detail": "从高点37.95回调37.9%"},
    {"event": "利润增速放缓", "level": "watch", "detail": "增长率2.1%"}
  ],
  "action": "暂停新建仓，已有仓位考虑减仓"
}
```
