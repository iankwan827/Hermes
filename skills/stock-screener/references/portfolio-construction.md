# 行业集中度限制 — 回测方法论

## 背景

选股系统按分数排Top5，但可能高度集中在同一行业。例如第一池Top5中有4只有色金属（株冶集团/西部矿业/洛阳钼业/兴业银锡），板块轮动时一起跌。

行业集中度限制强制每个行业最多N只，从其他行业找分数最高的替补。

## 选股逻辑（伪代码）

```python
def select_by_industry(stocks, max_per_industry, top_n=5):
    selected = []
    industry_count = defaultdict(int)
    
    # 按分数降序排列
    stocks_sorted = sorted(stocks, key=lambda x: x.score, reverse=True)
    
    for stock in stocks_sorted:
        industry = get_industry(stock.code)
        
        if industry_count[industry] < max_per_industry:
            selected.append(stock)
            industry_count[industry] += 1
        
        if len(selected) == top_n:
            break
    
    return selected
```

**关键点**：
- 必须按分数遍历，不是按行业分组
- 同一行业分数最高的优先入选
- 跳过已满行业的股票，继续看下一只
- 不是"先选2只有色金属，再从其他行业选3只"——是混合排序后自然筛选

## 平均分门槛测试（2026-07-03新增）

### 逻辑
先选Top3/4算平均分，低于平均分不能入选。选不够5只时取消行业限制，用最高分替补。

### 测试结果（第二池）

| 基准 | 平均分 | 正常入选 | 替补数 | 状态 | 平均收益 |
|------|--------|---------|--------|------|---------|
| Top3 | 66.0 | 宏达70分 | 4只 | 行业限制取消 | -6.23% |
| Top4 | 65.2 | 宏达70分 | 4只 | 行业限制取消 | -6.23% |

### 结论
1. **平均分门槛在行业集中时无效**：取消限制后替补还是同行业（分数最高）
2. **需要更长时间验证**：两周样本太小，偶然性大
3. **用户观点**："两周是暂时的，系统是看长远的"

### 伪代码
```python
def select_with_avg_score(stocks, max_per_industry, base_count=3):
    # 第一步：算Top{base_count}的平均分
    stocks_sorted = sorted(stocks, key=lambda x: x.score, reverse=True)
    avg_score = mean([s.score for s in stocks_sorted[:base_count]])
    
    # 第二步：行业≤N，分数≥平均分
    selected = []
    industry_count = defaultdict(int)
    for stock in stocks_sorted:
        if stock.score >= avg_score and industry_count[stock.industry] < max_per_industry:
            selected.append(stock)
            industry_count[stock.industry] += 1
        if len(selected) == 5:
            return selected, "行业限制生效"
    
    # 第三步：选不够→取消行业限制→用最高分替补
    for stock in stocks_sorted:
        if stock not in selected:
            selected.append(stock)
        if len(selected) == 5:
            return selected, "行业限制取消"
    
    return selected, "行业限制取消"
```

## 注意事项

1. **低分替补风险**：花园生物60分，比被替换的快克智能62分还低，风险更高
2. **单只暴涨不可复制**：花园生物+31.34%是维生素板块偶然事件，不能作为规则有效性的依据
3. **需要更长回测**：两周数据太短，建议至少4-8周
4. **行业分类是人工判断**：CSV不含行业字段，基于股票名称和常识分类，可能有误差
5. **新浪API补全价格**：部分股票跌出Top20后CSV无价格，需用实时API获取
6. **新浪API返回GBK编码**：用 `result.stdout.decode('gbk', errors='ignore')` 解码
