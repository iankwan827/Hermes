# 从语音转录稿中提取八字案例的工作流

> 适用场景：用户提供命理课程的语音转录文本，要求提取八字案例、分析、知识点。

## 一、语音识别常见谐音/错别字映射表

语音转录（尤其是繁体/普通话混合的识别结果）中，命理术语的错误是**高度可预测的**。以下是高频映射：

### 组合识别技巧
- **"四五味三和"** = 巳午未三合（四≈巳，五≈午，味≈未）
- **"害害自行"** = 亥亥自刑
- **"齐位"** = 己未
- **"丁四丁位"** = 丁巳 丁未
- **"贵位"** = 癸未（贵≈癸，位≈未）
- **"根虚"** = 庚戌（根≈庚，虚≈戌）
- **"心毛"** = 辛卯（心≈辛，毛≈卯）

## 二、提取案例的系统工作流

### Step 1：全文扫描，标记干支出现位置
用搜索工具查找所有天干地支组合（甲乙丙丁戊己庚辛壬癸 + 子丑寅卯辰巳午未申酉戌亥），标记行号。

### Step 2：区分完整案例 vs 片段提及
- **完整案例**：连续出现4组干支（年月日时），且有上下文讨论（如"男命""女命""这个八字"等）
- **片段提及**：只出现1-2个干支，或在理论讲解中作为示例
- **不完整案例**：出现3个干支，缺时柱（常见）

### Step 3：结合上下文还原四柱
- 看说话者是否提到"男命/女命"确认性别
- 看是否有"日元""日柱"等词确认日柱
- 看是否有"年柱""月柱""时柱"或"年上""时上"等位置提示
- 看是否有流年讨论（如"今年丙午年"）帮助定位

### Step 4：提取分析内容
在案例出现的前后5-10行内搜索：
- 性格描述（"喜欢什么类型""性格特点"）
- 婚姻感情（"恋爱""婚姻""配偶"）
- 健康判断（"肝病""心脏""脾胃"）
- 格局判断（"贵格""贱格""身强身弱"）
- 应期（"42岁""流年""大运"）

### Step 5：整理知识点
每个案例应包含：
1. **八字原文**：四柱干支（标注日元）
2. **讲师分析**：直接引用或转述讲师的判断
3. **相关知识点**：该案例体现的命理原理

## 三、注意事项

1. **不要猜测不确定的柱**：宁可标注"缺时柱"也不要编造
2. **注意伏吟/反吟**：转录中"年月伏吟"意味着年柱和月柱相同
3. **注意合化条件**：如"丁壬合化木"需要月令为木才能成立
4. **健康案例**：肝对应木、心对应火、脾对应土、肺对应金、肾对应水
5. **转录时间戳**：注意行号，方便回溯验证
