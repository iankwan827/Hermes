# 太公奇门起局法速查

## 核心：月日时刻四层推演

```
月宫 → 日宫 → 时辰宫（命宫）→ 刻宫（运宫）
```

## ⚠️ 顺进方向（易错）

顺进 = 沿后天八卦九宫格**外圈逆时针**走：

```
巽(4) 离(9) 坤(2)
震(3)  中(5)  兑(7)
艮(8) 坎(1)  乾(6)
```

**顺进路径：坎→艮→震→巽→离→坤→兑→乾→坎**

⚠️ 常见错误：把坎→艮→震→巽写成坎→乾→兑→坤（方向反了）。记住：震在巽下面，艮在坎左边。

## 宫-地支对应（易错）

每个宫管1-2个地支，**不是一一对应**：

| 宫 | 地支 |
|---|---|
| 坎 | 子 |
| 艮 | 丑、寅 |
| 震 | 卯 |
| 巽 | 辰、巳 |
| 离 | 午 |
| 坤 | 未、申 |
| 兑 | 酉 |
| 乾 | 戌、亥 |

⚠️ 丑归艮不归坎！坎只管子。

## 起局步骤

1. **定月宫**：正月起坎宫，每月顺进一宫
2. **定日宫**：从月宫起初一，每日顺进
3. **定时宫（命宫）**：从日宫起子时，每时辰顺进
4. **定刻宫（运宫）**：从命宫起刻，每刻顺进（每刻=10分钟，12地支=12步）

### 计算示例（农历四月十七20:50=庚戌时）

- 月宫：坎(1)→艮(2)→震(3)→**巽(4)**
- 日宫：从巽起初一，顺推17步→**巽**
- 命宫：从巽起子时，顺推至戌→**坤**（未/申）
- 运宫：从命宫坤起刻，顺推12步→**坎**（子）

### ⚠️ 实战：用真实盘验证

计算完务必和用户的真实盘面对照。常见错误点：
1. **顺进方向搞反**：坎→艮→震→巽（✓） vs 坎→乾→兑→坤（✗）
2. **宫-地支对应记错**：丑归艮不归坎，坎只管子
3. **刻的步数**：按12地支一圈算，不是按8宫
4. **命宫起点**：从日宫起子时顺推，不是从月宫

## 命宫 vs 运宫

- 命宫 = 时辰所在宫 = 代表自己
- 运宫 = 刻所在宫 = 代表所问之事
- 问财运 → 运=财运；问合作 → 运=对方

## 装盘

- **八神**：以日干所在宫起青龙，**顺时针**排（按宫的顺序）
  - 顺序：青龙→朱雀→勾陈→腾蛇→白虎→玄武→地运→天运
- **九星**：以时干所在宫起一白，顺飞
- **八门**：固定不动
  - 坎=合门（虎门）
  - 艮=天门
  - 震=阴门
  - 巽=凶门
  - 离=官门（珍珠门/富贵门）
  - 坤=恶门
  - 兑=阳门
  - 乾=地门
- **十二宫**：从运宫逆时针排
  - 运→兄→偶→子→财→疾→迁→友→官→田→福→父

## 命运关系断吉凶

| 关系 | 含义 |
|------|------|
| 命生运 | 一生劳累辛苦，白手成家 |
| 运生命 | 逢凶化吉，贵人相助 |
| 命克运 | 半途而废，自己克自己 |
| 运克命 | 处处受压制，怀才不遇 |
| 命运同宫 | 一荣俱荣一损俱损 |

## 关键口诀

- 三星主贵、七星主富
- "日月同辉"（三星+七星同在天位）= 富贵双全
- 六金不发少年人（三十前不易发迹）
- 太公奇门的九星是灵魂，九星虽然好是灵魂的，但是离不开行从可害
