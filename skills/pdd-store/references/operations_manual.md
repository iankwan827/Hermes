# 拼多多个人店运营全流程

## 一、上架商品（APP操作）

### 步骤
1. 打开"拼多多商家版"APP → "管理" → "发布商品"
2. 选分类（家居日用对应各类目）
3. 上传主图（用1688实物图或Gemini生成的图）
4. 填标题（核心词+属性词+长尾词+卖点词）
5. 设价格（3级SKU：引流价/主推价/套餐价）
6. 填详情（文案图批量上传）
7. 设库存（初期10件）
8. 发布

### 标题公式
```
核心词 + 属性词 + 长尾词 + 卖点词
```
示例：`硅胶厨具套装13件套 木柄不粘锅专用 锅铲汤勺打蛋器 食品级耐高温`

### 定价策略（3级SKU）
| 产品 | 引流价 | 主推价 | 套餐价 |
|------|--------|--------|--------|
| 硅胶厨具套装 | 8件套¥19.9 | 13件套¥29.9 | 14件套¥39.9 |
| 手机防水袋 | 单个¥5.9 | 2个装¥9.9 | 3个装¥13.9 |
| 厨房电子秤 | 1kg¥9.9 | 3kg¥19.9 | 5kg¥29.9 |
| 双面清洁抹布 | 3条¥4.9 | 5条¥7.9 | 10条¥12.9 |
| 头皮按摩梳 | 基础¥6.9 | 檀木¥14.9 | 礼盒¥21.9 |

### 发货时效
- 新店先选48小时
- 确认供应商能24小时发后再改24小时
- 48小时发货率 >95% 是底线

---

## 二、1688下单发货（一件代发）

### 流程
1. 拼多多有新订单 → 记录买家信息
2. 1688 APP搜商品 → 下单
3. **收货地址填买家地址**（直接寄给买家）
4. **留言：一件代发，不放随货单据**
5. 支付宝付款
6. 供应商发货 → 获取快递单号
7. 回填单号到拼多多 → 确认发货

### ⚠️ 注意
- 48小时内必须发货
- 备注"一件代发"必须写
- 同时找2-3家备用供应商

---

## 三、退货退款

### 流程
1. 买家申请退货 → 同意退货
2. 把1688供应商退货地址发给买家
3. 买家退回供应商
4. 供应商确认收到 → 同意退款

### 退货地址获取
- 1688 APP → 我的 → 退换货管理 → 退货地址
- 或联系1688卖家客服

---

## 四、客服回复

### 自动回复设置
拼多多APP → "管理" → "客服管理" → "自动回复"

### 常用话术
```
售前：亲，源头工厂直发，质量保证！有问题随时问~
物流：亲，已发货，快递单号XXX，预计3-5天送达~
退货：亲，支持7天无理由退换，有问题随时联系~
```

## 五、日常运营

### 每天（5分钟）
1. 查看新订单 → 1688下单
2. 查看客服消息 → 及时回复
3. 查看售后申请 → 及时处理

### 每周（30分钟）
1. 查看数据：销量、流量、转化率
2. 优化标题关键词
3. 调整价格
4. 回复评价

### 每月（1小时）
1. 分析热销产品 → 加大推广
2. 淘汰滞销产品
3. 寻找新品
4. 对账算利润

---

## 六、推广方法

### 免费推广
1. 多多进宝 → 佣金20-30%让达人推
2. 活动报名 → 9.9特卖、秒杀、百亿补贴
3. 搜索优化 → 优化标题关键词

### 付费推广（有销量后再投）
1. 直通车 → 日预算30-50元起
2. 全站推广 → 平台自动投放

---

## 八、断货处理

### 预防
- 备2-3家供应商
- 初期库存设10件
- 提前问供应商有没有现货

### 断货时
- 有替代品 → 联系买家换货
- 完全没货 → 道歉+退款
- 延迟 → 协商等几天+给优惠

## 九、常见问题

**Q：1688下单后多久发货？**
A：通常24-48小时

**Q：买家收到货跟图片不一样？**
A：用1688实物图做主图

**Q：1688价格变了？**
A：及时调整拼多多售价

**Q：多久能赚钱？**
A：通常1-2周起量，1个月稳定盈利
