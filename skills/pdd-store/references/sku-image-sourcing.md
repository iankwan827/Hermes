# SKU 预览图获取流程

> 每个SKU（引流/利润/套餐）需要对应的预览图，必须从1688找真实产品图

## 为什么不能用AI生图

- AI生成的图跟实际产品不一致，买家收到货会投诉
- 1688供应商的产品图最真实，直接用最可靠

## OpenCLI 获取SKU图流程

### 1. 搜不同规格的产品

```bash
# 搜8件套
opencli 1688 search "硅胶厨具套装 8件套" --limit 1

# 搜12件套
opencli 1688 search "硅胶厨具套装 12件套" --limit 1

# 搜14件套
opencli 1688 search "硅胶厨具套装 14件套" --limit 1
```

### 2. 获取商品图片URL

```bash
# 用 item 命令获取详情（含主图URL）
opencli 1688 item <offer_id>
# 输出中的 main_images 字段就是图片URL列表
```

### 3. 下载图片

```bash
# 下载第一张主图作为SKU预览图
curl -sk -o "产品_规格名.jpg" "图片URL"
```

### 4. 命名规范

```
产品名_规格名.jpg
例：硅胶厨具_3件套.jpg
例：硅胶厨具_8件套.jpg
例：硅胶厨具_12件套.jpg
```

## 5个产品的SKU规格对照

| 产品 | 引流款 | 利润款 | 套餐款 |
|------|--------|--------|--------|
| 硅胶厨具套装 | 3件套 | 8件套 | 12件套 |
| 手机防水袋 | 单只 | 2只装 | 3只+挂绳 |
| 厨房电子秤 | 1kg | 3kg | 5kg |
| 双面清洁抹布 | 3条装 | 5条装 | 10条装 |
| 头皮按摩梳 | 基础款 | 檀木款 | 礼盒款 |

## 同产品不同图片的技巧

如果搜不到不同规格，可以用同一产品的不同角度图片：
- 主图 → SKU1
- 侧面图 → SKU2
- 细节图 → SKU3

## 注意事项

- 每个SKU图必须跟实际发货的产品一致
- 如果供应商只有一种规格的图，就跟买家沟通确认
- 图片尺寸建议 750x750px 以上
