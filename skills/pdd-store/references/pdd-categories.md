# 拼多多店铺分类与命名规则

## 店铺名禁用词

个人店名称不能包含以下词语：
- 物美、优质、精品、名牌
- 官方、旗舰、专卖、专营
- 品牌名（除非是该品牌授权店）
- 其他平台名称（淘宝、京东等）

## 个人店可选类目

| 类目 | 保证金 | 需要资质 |
|------|--------|---------|
| 服饰/鞋帽 | 0-500元 | 无 |
| 家居日用 | 0-500元 | 无 |
| 厨房用品 | 0-500元 | 无 |
| 清洁工具 | 0-500元 | 无 |
| 宠物用品 | 0-500元 | 无 |
| 饰品/发饰 | 0-500元 | 无 |
| 手机配件 | 0-500元 | 无 |
| 文具用品 | 0-500元 | 无 |

## 个人店不能卖的类目

| 类目 | 原因 |
|------|------|
| 食品 | 需要食品经营许可证 |
| 美妆/个护 | 需要化妆品经营许可 |
| 药品/医疗器械 | 需要药品经营许可 |
| 3C数码 | 需要品牌授权/质检报告 |
| 图书/音像 | 需要出版物经营许可 |
| 酒类 | 需要酒类流通许可 |

## 保证金说明

- 2026年个人店大部分品类保证金为0-500元
- 部分类目可先开店后补缴
- 保证金在关店时可退
- 具体金额以拼多多后台提示为准
