# 大运流年分析技能

核心原则：看岁运不能孤立看某一个字，必须看它对原局格局和用神的化学反应。
大运为"地利"（提供环境），流年为"天时"（引发事件）。

---

## 分析优先级（铁律）

**先看五行力量对比，再看十神关系。** 五行层面谁克谁是明牌，十神只是给"谁有事"贴个标签。例如：岁运并临巳巳 → 火力翻倍 → 水被蒸发 → 正印（母亲）有事。不用绕"乙木泄印+巳中戊土克印"那套，五行层面火旺水干就是最直接的因果。

## 五步操作流（标准化流程）

### Step 0 【定格局定用忌】（最重要！不可跳过）

**⚠️ 致命教训：** 脚本（generate_bazi_analysis.js）只输出十神，不输出格局和用神忌神。脚本输出的"用/忌"列是算法自动判定，经常出错（如把正官格的食伤标为"用"，实际上食伤是正官格的忌神）。**用神忌神必须用格局法手动推导，绝不能直接抄脚本输出。**

**推导流程：**
1. 看月令本气 → 取格（如月令酉金本气辛金=正官 → 正官格）
2. 根据格局确定用神（格局核心=用神，生格局核心者=用神）
3. 根据格局确定忌神（克格局核心者=忌神，泄格局核心者=忌神）
4. 写出完整的用神/忌神清单，后续所有分析以此为准

**十大格局用神忌神速查：**

| 格局 | 月令取格 | 用神 | 忌神 |
|------|----------|------|------|
| 正官格 | 月令本气正官 | 正官、财星(生官)、印星(护官) | 比劫(抗官)、食伤(制官) |
| 七杀格 | 月令本气七杀 | 七杀、食神(制杀)、印星(化杀) | 比劫(抗杀)、财星(生杀) |
| 正财格 | 月令本气正财 | 正财、官星(护财) | 比劫(夺财)、印星(克财源) |
| 偏财格 | 月令本气偏财 | 偏财、官星(护财) | 比劫(夺财)、印星(克财源) |
| 正印格 | 月令本气正印 | 正印、官杀(生印) | 财星(坏印)、比劫(泄印) |
| 偏印格 | 月令本气偏印 | 财星(制枭破印)、食伤(泄身) | 比劫(身强时帮身致旺+夺财为忌；身弱时可通关印→比劫→食伤化枭夺食)、官杀(官生印)、印星(枭神夺食加重) |
| 食神格 | 月令本气食神 | 食神、财星(泄秀) | 印星(枭夺食)、官杀(浊食) |
| 伤官格 | 月令本气伤官 | 伤官、财星(泄秀) | 印星(制伤)、官星(伤见官) |
| 比肩格 | 月令本气比肩 | 比肩、食伤(泄秀) | 官杀(制身)、财星(耗身) |
| 劫财格 | 月令本气劫财 | 劫财、食伤(泄秀) | 官杀(制身)、财星(耗身) |

**特殊说明：**
- 伤官格特殊：伤官配印（印制伤）可以成格，此时印为用不是忌
- 食神格特殊：食神制杀格中，七杀为用不是忌
- **偏印格特殊（渊海子平）：偏印格是凶格（枭神夺食），喜财星制枭破印→财星为用神，不是忌神。** 传统命理认为"偏印见财为进身之阶"，有财制枭才能成贵格。无财制枭则枭神夺食无解，人生压抑。
- 以上是"一般情况"，具体命局需结合整体组合微调
- 月令本气不透时，仍取月令本气十神为格，看哪个藏干透到天干来"应格"

**⚠️ 五行生成关系（易错点）：**
- **印生比劫，不是比劫生印**：金（印）生水（比劫），不是水生金。比劫是被印所生，不是印的来源。**但比劫可以泄印（印的力量被比劫分散）**。
- **官杀生印，不是印生官杀**：土（官杀）生金（印），所以正官/七杀会增强印星力量。偏印格中正官是忌神（官生印）。
- **财星克印**：火（财）克金（印）。**对正印格**：财星坏印=忌神。**对偏印格**：财星制枭=用神（渊海子平：偏印格喜财来破印，枭神夺食以财制枭为药）。
- **食伤泄身**：木（食伤）泄水（日主），但偏印格中食神是忌神（枭夺食，偏印克食神）。**⚠️ 但当枭神夺食时，食伤是被保护的对象（见下方"病药分析"）。**
- **比劫通关**：水（比劫）生木（食伤）。当偏印格枭神夺食时，比劫可以作为通关之神：金（偏印）→水（比劫）→木（食伤），形成连续相生，化解枭神夺食。**但身强时比劫帮身致旺，仍是忌神。****

**⚠️ 身强/身弱对用忌的影响：**
- 以上速查表是"格局标准用忌"，假设日主力量适中
- **身强时**：比劫帮身→身更强→比劫是忌神（即使比劫在格局标准中是用神）
- **身弱时**：比劫帮身→身变强→比劫可能是用神（即使比劫在格局标准中是忌神）
- **⚠️ 格局核心太过时用神反转**：当格局核心星太旺（如偏印格三印、正官格官杀混杂），格局核心本身从用神变为忌神（太过成灾），用神转为能泄/克格局核心的字。例：偏印格身强偏印旺→偏印太过成枭→偏印变忌神，用神转为食伤（泄身）和七杀（克身）。
- **判断流程**：先按格局定标准用忌→再根据身强弱微调→再检查格局核心是否太过→最终用忌以调整后为准

**⚠️ 病药分析框架（动态用忌，优先于静态格局用忌）：**

静态格局用忌表是"标准参考"，但具体命局要动态分析。核心逻辑：**找到"病"（问题所在），找到"药"（解决问题的力量），药就是用神。**

**偏印格枭神夺食的病药分析：**
- **病**：偏印太旺成枭，克食神（枭神夺食）→金旺克木→人生压抑、才华受阻
- **药**：财星（火）制枭（火克金）→解救食神→用神
- **结论**：偏印格枭神夺食时，财星制枭是**第一核心用神**（不是忌神），食伤是**第二辅助用神**（被保护的对象）
- **忌神**：印星（金，病根）、官杀（土，官生印）。**比劫看情况**：身强时比劫帮身致旺+夺财为忌；身弱时比劫可通关（金生水，水生木=印生比劫，比劫生食伤）化枭夺食。

**其他格局的病药思路：**
- 正官格伤官见官→病=伤官，药=印星（印制伤）→印为用
- 食神格枭神夺食→病=偏印，药=财星（财制枭）→财为用
- 七杀格杀太旺→病=七杀，药=食神（食制杀）→食为用

**判断流程（最终版）：**
1. 先按格局定标准用忌（速查表）
2. 再根据身强弱微调
3. 再检查格局核心是否太过（用神反转）
4. **最后用病药框架验证**：找到病→找到药→药就是最终用神
5. 如果病药用忌与前面推导一致→确认；如果冲突→以病药为准

### Step 1 【查基调】
判定当前大运是助用神（吉运）还是助忌神（凶运）。
- 大运天干/地支若生、扶、拱、合原局用神 → 吉运
- 大运天干/地支若克、泄、冲、刑原局用神 → 凶运
- 大运天干/地支若为忌神透出/坐支 → 凶运
- 若大运走吉运，流年即使凶，也不至于一败涂地
- 若大运走凶运，流年再逢凶，则是"祸不单行"

**关键判断方法：**
1. 大运天干的十神是什么？是用神还是忌神？
2. 大运地支藏干的十神是什么？是用神还是忌神？
3. 天干地支同向（都是用/都是忌）→ 力量明确
4. 天干地支矛盾（一用一忌）→ 需看哪个力量更大（天干管上半年/明面，地支管下半年/暗藏）

### Step 2 【找引线】
看流年天干透出什么十神：
- 透财 → 钱财、情缘
- 透官杀 → 事业、压力
- 透食伤 → 投资、想法、表达
- 透印 → 学业、贵人、文书
- 透比劫 → 人际、竞争、合伙

**注意：** 流年天干的十神是用神还是忌神，决定了这条引线是好事还是坏事。透用神=好事来敲门，透忌神=坏事找上门。

### Step 3 【看化学反应】
检查流年地支与大运、原局地支的冲、合、刑：
- 冲哪里 → 哪里就有变动
- 合哪里 → 哪里就有牵绊
- 刑哪里 → 哪里就有伤病、官非、暗疾

**特殊反应——半合/三合引动提纲：**
- 岁运地支与月支半合/三合 → 引动月柱（提纲）→ 事业大变动
- 引动时要看合出来的五行是什么：如果合出的是官杀，官杀被加强；如果合出的是财星，财星被加强
- 引动官杀同时要注意：是否造成官杀混杂（正官+七杀同时浮出）

**特殊反应——合动藏干：**
- 岁运地支与原局地支半合/三合时，会把地支藏干的力量"拉出来"
- 原本藏在地支中不透干的十神，可能被引动后与天干发生作用
- 例：原局正官藏月支不透干，岁运半合引动后，正官力量浮出，可能触发天干伤官见官

### Step 4 【下断语】
结合十神寓意与冲合结果，给出具体断语。
- 每个断语必须说明依据：什么组合攻击/辅助了什么用神
- 断语要严谨，可经行家检验——定义不能含糊
- 不成立的组合不贴标签，用替代分析

## 四个核心公式

### 公式一：岁运吉凶判定公式（核心算法）

```
吉凶结果 = (大运干支 × 流年干支) → 原局用神/忌神
```

- 若结果为"生、扶、拱、合"用神 → 吉（升职、发财、得子、病愈）
- 若结果为"克、泄、冲、刑"用神 → 凶（破财、官非、伤病、离职）
- 若大运/流年天干地支本身就是忌神 → 直接判凶，不需要额外生克判断

**判断要点：**
1. 先确认大运干支的十神属性（用神还是忌神）
2. 再确认流年干支的十神属性（用神还是忌神）
3. 大运流年叠加后对用神的综合效果
4. 两者同向（都生/都克）则力量加倍；一吉一凶则相互抵消
5. ⚠️ 判断十神属性时必须对照Step 0的格局用忌，不能凭"通用十神含义"

### 公式二：岁运相战公式（动荡与意外判定）

```
岁运相战 = (大运干 ↔ 流年干 天克) + (大运支 ↔ 流年支 地冲)
```

**判定条件：**
- 流年与大运发生天克地冲（如大运甲子，流年庚午）
- "岁运交战，日主无情" → 该年生活天翻地覆
- 主意外、迁徙、破产或大病

**岁运并临特例：**
- 大运干支 = 流年干支
- 若并临的字为原局忌神 → 大凶（忌神力量翻倍）
- 若并临的字为原局喜神 → 大吉（用神力量翻倍）
- 若并临的字一用一忌（如正官格的巳火：食神为忌但巳中偏财可用）→ 需拆开分析，不能简单定论

**冲支方向性原则：**
- 岁运带冲支，即使被冲的支不在原局，冲的"方向性力量"仍然存在
- 例：岁运巳来了，巳亥冲 → 巳火带着"找水冲"的势，原局有子水（正印）也会受压
- 这是应期层面的概念：原局是"种子"（静态格局），岁运是"应期触发器"（激活潜在威胁）
- "冲者动也"——动的是五行力量对比，不只是具体某个支

**天克对照表：**
甲↔己、乙↔庚、丙↔辛、丁↔壬、戊↔癸

**地冲对照表：**
子↔午、丑↔未、寅↔申、卯↔酉、辰↔戌、巳↔亥

### 公式三：引动公式（人事物落地公式）

```
事件发生 = 岁运干支 × 原局干支 (合/冲/刑)
```

原局的字是"静态的基因"，岁运的字是"动态的开关"。

**冲动（冲）→ 变动：**
- 冲年柱 → 搬家、长辈变动
- 冲月柱（提纲）→ 换工作、搬家（"冲提大运"多险阻）
- 冲日支（夫妻宫）→ 感情危机、结婚、离异、身体受伤
- 冲时柱 → 子女远行、投资变动

**合动（合）→ 获得、羁绊、合作：**
- 岁运财星合入日柱 → 恋爱、赚钱
- 岁运官星合入日柱 → 升职、有贵人
- 岁运印星合入日柱 → 学业、考试、贵人

**半合/三合引动：**
- 岁运地支与原局某支半合/三合 → 引动该支所在柱
- 引动月柱 = 事业变动；引动日柱 = 感情变动
- 半合/三合的力量弱于六冲，但持续时间更长

**刑动（刑）→ 伤病、官非：**
- 三刑（寅巳申、丑未戌）→ 大灾
- 自刑（辰辰、午午、酉酉、亥亥）→ 内耗、暗疾
- 子卯刑（无礼之刑）→ 感情/家庭是非、口舌

**藏干引动（进阶）：**
- 岁运地支与原局地支半合/三合时，会把地支藏干"拉出来"
- 藏干一旦被引动浮出，就可能与天干发生冲合关系
- 例：正官藏月支不透干 → 岁运半合引动 → 正官力量浮出 → 天干伤官"看见"正官 → 伤官见官触发

### 公式四：经典败格公式（岁运凶险触发器）

**伤官见官公式：**
```
原局有伤官 + 岁运逢正官 → 官非/破职/伤残
```
- 直接触发：岁运天干透出正官
- 间接触发：岁运地支半合/三合引动原局藏干中的正官
- 注：金水伤官等极少数例外（金水伤官喜见官）

**食神制官公式（正官格专用）：**
```
正官格 + 岁运食伤旺 → 官星被制 → 事业受阻/降职/失业
```
- 与伤官见官不同：食神制官是"慢性消耗"，伤官见官是"正面冲突"
- 食神制官不一定触发官非，但事业一定受阻
- 如果食神力量特别强（如大运流年都是食神），可能从"受阻"升级为"破格"

**枭神夺食公式：**
```
原局有食神(且为用) + 岁运逢枭神(偏印) → 有始无终/因财致祸/女命损子
```

**贪财坏印公式：**
```
原局用印抗煞 + 岁运逢财星破印 → 贪赃枉法/声名狼藉/因钱财生灾
```

**比劫夺财公式（正财格/偏财格专用）：**
```
财格 + 岁运比劫旺 → 财被夺 → 破财/合伙失败/被人争利
```
- 比劫不仅夺财，还会断掉"财生官"的链条，连累官星

## 断语模板

**大吉年：** 大运走用神 + 流年生扶用神 + 无冲克
例："此年大运XX助用神，流年XX透出正财坐长生，合入日柱，主发财、升职、姻缘三喜临门。"

**平稳年：** 大运吉 + 流年平（无明显生克）
例："此年大运平稳，流年无特殊引动，生活按部就班。"

**小凶年：** 大运凶 + 流年无明显助力
例："此年大运不利用神，流年透出XX耗泄日主，主事业不顺、小人是非。"

**大凶年：** 大运凶 + 流年再逢凶（天克地冲/岁运并临忌神/经典败格触发）
例："此年岁运交战，大运XX与流年XX天克地冲，冲动日支夫妻宫，主婚姻危机、事业大变、需防意外。"

## 分析优先级：五行 > 十神

**先看五行力量对比，再看十神关系。**

五行层面的生克是"物理层"，十神层面的吉凶是"应用层"。物理层已经决定结果时，应用层只是贴标签。

例：岁运并临巳巳 → 火力翻倍 → 水被蒸发 → 不用绕十神关系，五行层面火旺水干已经是明牌。然后才用十神说"这个水是正印=母亲"。

**口诀：五行定生死，十神定六亲。**

## 应期体系

八字原局是"种子"，岁运是"应期触发器"。原局有潜在威胁但没出事，是因为应期未到。

**应期触发的三个层次：**
1. **冲则动**：岁运带来冲支 → 即使被冲的支不在原局，冲的"方向性力量"仍然激活原局中对应五行的潜在威胁
2. **岁运并临**：干支相同 = 力量翻倍 = 把原局潜在威胁"放大并激活"
3. **五行力量对比逆转**：岁运改变了原局的五行平衡 → 原本撑得住的元素扛不住了

**例：丁卯己酉甲子丁卯，大运流年乙巳（岁运并临）**
- 原局潜在威胁：火旺压水（一直存在，但水有子为根撑得住）
- 岁运触发器：巳巳并临 → 火力翻倍
- 应期信号：巳亥冲方向（火找水开战）
- 结果：水扛不住 → 印星长辈应灾

## 六亲生死判断补充

**六亲无根先倒原则：**
- 某六亲星在原局无根（天干不见、地支无禄旺墓库），岁运克制时最先应灾
- 有根的还有缓冲，无根的直接暴露

**巳亥冲的方向性：**
- 岁运带巳，即使亥不在原局，巳的冲性仍指向水
- 原局有水（子），火旺水衰的大环境下所有水都受压
- 传统命理中对此有流派分歧：有些认为冲必须双方都在局中才算，有些认为冲意即冲力
- 但从五行力量对比看，火旺水干是确定的，"谁先倒"看根深根浅

## 易学五行分类

**易学本体属水（玄学），传播属火（文化）：**
- 学易/算命/做预测/做咨询 → 水（隐学、智、未见之事）
- 开课/出书/做自媒体/传播 → 火（公开、明亮、表达）
- 不要把所有"文化"都归为火，易学是特殊类别

## 核心分析原则

### ⚠️ 五行优先于十神（铁律）

**先看五行力量对比，再贴十神标签。**

例：岁运并临巳巳 → 火力翻倍 → 水被蒸发 → 不用绕十神关系，五行层面火旺水干已经是明牌。然后再用十神贴标签：水=印星=母亲/长辈。

错误做法：绕半天"乙木泄印+巳中戊土克印"，结论模糊。
正确做法：火旺水干 → 水=印星 → 长辈有险。三步到位。

### ⚠️ 应期 vs 八字是两套体系

- **八字**：看格局强弱、用神忌神、原局潜在威胁
- **应期**：看什么时候兑现。"冲则动"——岁运带冲支就是应期触发器
- 岁运并临 = 应期信号，把原局静态威胁激活成动态事件
- 巳亥冲：即使亥不在原局，巳的冲性本身就是"动"的信号，激活火旺水衰的应期

### ⚠️ 六亲无根先倒

判断六亲风险等级时：
- 有根的六亲星（天干透出+地支有禄旺墓库）→ 受损但有缓冲
- 无根的六亲星（天干不见+地支无对应支）→ 直接暴露，最先应灾
- 例：母亲(癸水)坐子(水旺地)有根 vs 爷爷(壬水)天干不见+亥不在局中无根 → 爷爷风险更大

### ⚠️ 巳亥冲方向性力量

岁运带冲支，即使被冲的支不在原局，冲的"方向性力量"仍然存在。巳来了就带着"找水冲"的势，原局所有水都受压。这是"冲者动也"——动的是五行力量对比，不只是具体某个支。（注：此论断在传统命理中有流派分歧，需注明。）

## 应期判断（岁运兑现时机）

应期 = 原局的潜在威胁在什么时候变成现实事件。原局是"种子"，岁运是"应期触发器"。

**核心原则：**
- 冲则动：岁运冲某个支，该支代表的六亲/领域在该年应事
- 合则绊：岁运合某个支，该支代表的六亲/领域被牵绊、延迟
- 刑则伤：岁运刑某个支，该支代表的六亲/领域有伤病、官非
- 岁运并临本身 = 一种应期信号，把原局潜在威胁"放大并激活"

**五行力量对比应期：**
- 当岁运改变五行力量对比（如火旺水干），这就是应期
- 不需要具体的冲合刑，单靠五行力量变化就能触发事件
- 例：原局火旺水弱（潜在威胁）→ 岁运并临巳巳（火翻倍）→ 水扛不住（应期兑现）

**六亲应期判断：**
- 某六亲星在原局无根 + 岁运克制 → 该六亲最先应灾
- 某六亲星在原局有根 + 岁运克制 → 受损但有缓冲
- 冲六亲所坐之柱 → 该六亲有大变动/灾厄

## 应期 vs 本机数据库

⚠️ 应期判断主要依据传统命理学理（冲则动、五行力量对比、六亲根深根浅），这些知识来自训练数据中的命理典籍，不在本地 bazi-vault 数据库中。分析应期时不要只搜本地数据库，要结合训练知识中的应期原理。

## 六亲风险判断

当岁运克某五行时，该五行对应的六亲有险。判断谁风险最大，看根深根浅：
- 某六亲星在原局有根（坐旺地、有禄）→ 虽受损但有抗力
- 某六亲星在原局无根（天干不见、地支无根）→ 直接暴露，最先应灾
- 例：正印癸水坐子（水旺地）有根，偏印壬水天干不见无根 → 岁运火旺水干时，壬水（爷爷）比癸水（母亲）更危险
- 六亲递推关系详见 bazi-sales skill 的 `references/15_六亲递推速查.md`

## 使用注意

1. **Step 0不可跳过：** 用神忌神必须格局法推导，绝不能抄脚本输出。脚本只提供十神标注，格局和用忌是分析师的工作。
2. 排盘十神必须来自JS脚本（generate_bazi_analysis.js），不能手算
3. 断语要严谨，可经行家检验——定义不能含糊
4. 大运需手动推算（cnlunar不提供大运数据），见下方「大运手动推算流程」
5. 每个断语都要说明依据：什么组合攻击/辅助了什么用神
6. 不成立的组合不贴标签，用替代分析
7. 半合/三合引动藏干是常见触发机制，分析时必须检查地支藏干是否被拉出
8. 正官格的食伤是忌神不是用神——这是最常见的分析错误
9. **⚠️ 偏印格正官是忌神（官生印）**：正官（土）生印星（金），增强忌神。偏印格身强时，正官不是用神。同时注意：比劫（水）不生印（金生水，不是水生金），比劫只是帮身，不是印的来源。
10. **⚠️ 身强弱会改变用忌**：格局速查表是标准用忌，身强时比劫可能从用神变忌神（帮身致更旺），身弱时比劫可能从忌神变用神（帮身变强）。必须先定格局用忌，再根据身强弱微调。
11. **六亲递推规则：** 每一代偏财=父亲、正印=母亲，逐层递推。详见 `bazi-sales` skill 的 `references/15_六亲递推速查.md`。
12. 六亲推导用递推法：偏财=父，正印=母，父亲的偏财=爷爷，父亲的正印=奶奶（详见bazi-sales/references/15_六亲递推速查.md）。

## 大运手动推算流程

### ⚠️ 脚本性别Bug

`generate_bazi_analysis.js` 有时会忽略gender参数，输出错误的性别（如男命输出女命）。**必须检查脚本输出的性别是否与用户指定一致**，不一致则手动推算大运。

### 大运方向判定

| 出生年天干 | 男命 | 女命 |
|-----------|------|------|
| 阳干(甲丙戊庚壬) | 顺排 | 逆排 |
| 阴干(乙丁己辛癸) | 逆排 | 顺排 |

- **顺排**：从月柱天干地支向后排（己酉→庚戌→辛亥…）
- **逆排**：从月柱天干地支向前排（己酉→戊申→丁未…）

### 起运岁数计算

1. 查当年节气表（cnlunar的`getSolarTermsDateList(year)`可得节气日期）
2. 确定月柱对应节气：寅月=立春，卯月=惊蛰，辰月=清明，巳月=立夏，午月=芒种，未月=小暑，申月=立秋，酉月=白露，戌月=寒露，亥月=立冬，子月=大雪，丑月=小寒
3. **顺排**：从生日顺数到下一个节气的天数
4. **逆排**：从生日逆数到上一个节气的天数
5. **换算**：3天=1年，1天=4个月，1时辰=10天

**示例**：1987年9月12日男命，丁卯年(阴年)→逆排。白露9月8日(上一个节气)，从9月12日逆数到9月8日=4天。4天=1年4个月→约2岁起运。

### 大运序列写法

从月柱出发，逐柱逆排/顺排天干地支，每步10年：

```
逆排示例(月柱己酉)：
天干：己→戊→丁→丙→乙→甲→癸→壬→辛→庚
地支：酉→申→未→午→巳→辰→卯→寅→丑→子

大运序列：戊申(2-12)→丁未(12-22)→丙午(22-32)→乙巳(32-42)→甲辰(42-52)→...
```
