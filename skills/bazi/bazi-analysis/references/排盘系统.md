# Web排盘系统

**路径**: `D:/hermes-agent/bazi-project/`
**启动**: `cd D:/hermes-agent/bazi-project && node server.js` → 访问 `http://localhost:3001`
**端口**: 3001（启动时自动杀占用端口的旧进程）

## API接口

**排盘**: `POST /api/paipan`
请求体: `{"year":"1987","month":"9","day":"12","hour":"6","gender":"M"}`
返回: 完整JSON（四柱、十神旺衰、格局、大运、特征、交互关系）

**断语分析**: `POST /api/duanyu`
请求体: `{"baziJson": <paipan返回的JSON>, "analysisType": "做过三关分析（格局判定、用神忌神、日主强弱）"}`
功能: 用baziJson中的input信息构造prompt → 通过 `run_duanyu.sh` 调 `hermes chat -q` → 返回分析结果
核心思路: 不传排盘数据给hermes，只传出生信息+分析类型，让hermes自己调skill排盘+分析

## 前端功能
- 四柱排盘（天干地支+藏干+十神+纳音+神煞，五行着色）
- 身强身弱进度条 + 用神忌神
- 十神旺衰表 + 格局分析 + 大运流年
- 特征标签（自动去重）
- 分步分析按钮组（过三关、事业、婚姻、性格、六亲、大运流年、完整报告）

## 技术要点
- 启动时自动kill占用端口的旧进程（Windows: netstat+taskkill, Linux: lsof+kill）
- 断语调用链: server.js → 写prompt到tmp_prompt.txt → `bash run_duanyu.sh tmp_prompt.txt` → hermes chat -q + bazi-analysis skill
- ⚠️ 不能直接用Node.js exec传中文prompt给hermes，必须用shell脚本做中间层
- hermes输出需清理ANSI码和UI装饰字符（╭╮╰╯、⚕ Hermes、session info等）
- 用户偏好分步分析（每次只问一个方面，10-20秒出结果）
