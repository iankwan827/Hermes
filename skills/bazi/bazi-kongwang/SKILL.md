# 八字空亡专题分析

## 用途
- 过三关中空亡相关断语
- 判断某柱/某十神是否空亡

---

## 一、空亡本质

**核心口诀：** 干支不到作空看，力量虚浮、应事不实，并非绝对无用。

- **空：** 空虚、空洞、有名无实
- **亡：** 消亡、衰微、柔弱（非死亡之意）
- **本质：** 某一旬中无天干对应的两个地支，主力量虚浮、应事不实
- **规律：** 空亡并非绝对无用，而是状态不稳定、力量减弱

## 二、空亡查法（必背口诀）

```
甲子旬中戌亥空，甲戌旬中申酉空，
甲申旬中午未空，甲午旬中辰巳空，
甲辰旬中寅卯空，甲寅旬中子丑空
```

### 查法三步骤
1. 确定日柱所在旬首
2. 用口诀查该旬空亡地支
3. 查看年、月、日、时地支是否出现空亡地支

### ⚠️ 重要：日柱空亡的真正含义

**日柱空亡 = 年柱空亡 + 月柱空亡 + 时柱空亡 的合集**

查空亡时，需要分别查每一柱的空亡：
1. 年柱甲戌旬 → 空亡申、酉
2. 月柱壬申旬 → 空亡戌、亥
3. 日柱乙酉旬 → 空亡午、未
4. 时柱壬午旬 → 空亡申、酉

**判断方法**：如果日支出现在**其他三柱**的空亡地支里，则日柱空亡。

**示例**：1994年8月27日女命
- 年柱甲戌旬空亡申、酉
- 日支酉 = 年柱空亡地支 → **日柱空亡！**

**核心原则**：以日柱查旬首来确定空亡地支，然后看四柱地支哪些落在空亡里。日柱空亡不是日支本身必须空，而是日支出现在其他柱的空亡里。

## 七、空亡避坑

1. **凶神空亡减凶反吉** — 七杀、伤官等凶神空亡，凶性减弱
2. **用神空亡主一生辛劳** — 用神空亡则该方面力量不足
3. **空亡≠无用** — 只是力量减弱、状态不稳定
4. **真空亡 vs 假空亡** — 有透干/刑冲合会为假空（有作用），无则为真空（彻底无力）
