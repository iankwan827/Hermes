# 八字空亡判断工具

## 定位
本skill**只做空亡判断**，不做任何断语。
断语由各专题skill加载本skill后自行下（如婚姻skill判断配偶宫空亡→结婚困难）。

---

## 一、空亡本质

**核心：** 干支不到作空看，力量虚浮、应事不实。

- **空：** 空虚、空洞、有名无实
- **亡：** 消亡、衰微、柔弱（非死亡之意）
- **本质：** 某一旬中无天干对应的两个地支，主力量虚浮、应事不实
- **规律：** 空亡并非绝对无用，而是状态不稳定、力量减弱

---

## 二、空亡查法

### 核心口诀
```
甲子旬中戌亥空，甲戌旬中申酉空，
甲申旬中午未空，甲午旬中辰巳空，
甲辰旬中寅卯空，甲寅旬中子丑空
```

### 查法步骤
1. 确定日柱所在旬首
2. 用口诀查该旬空亡地支
3. 查看年、月、日、时地支是否出现空亡地支

**核心原则**：以日柱查旬首来确定空亡地支，然后看四柱地支哪些落在空亡里。

### 六旬速查表

| 旬首 | 空亡地支 | 包含日柱 |
|------|----------|----------|
| 甲子 | 戌、亥 | 甲子、乙丑、丙寅、丁卯、戊辰、己巳、庚午、辛未、壬申、癸酉 |
| 甲戌 | 申、酉 | 甲戌、乙亥、丙子、丁丑、戊寅、己卯、庚辰、辛巳、壬午、癸未 |
| 甲申 | 午、未 | 甲申、乙酉、丙戌、丁亥、戊子、己丑、庚寅、辛卯、壬辰、癸巳 |
| 甲午 | 辰、巳 | 甲午、乙未、丙申、丁酉、戊戌、己亥、庚子、辛丑、壬寅、癸卯 |
| 甲辰 | 寅、卯 | 甲辰、乙巳、丙午、丁未、戊申、己酉、庚戌、辛亥、壬子、癸丑 |
| 甲寅 | 子、丑 | 甲寅、乙卯、丙辰、丁巳、戊午、己未、庚申、辛酉、壬戌、癸亥 |

## 三、空亡按位置分类

| 位置 | 代表事项 |
|------|----------|
| 年柱空亡 | 祖业、长辈、远方、外部环境 |
| 月柱空亡 | 事业、同事、家乡、工作环境 |
| 日柱空亡 | 自身、配偶、婚姻、核心生活 |
| 时柱空亡 | 子女、晚辈、晚年、后部区域 |
| 互换空亡 | 年日互空/日时互空，双方均无依托 |

## 四、空亡填实方法

| 填实方式 | 具体组合 | 效果 |
|----------|----------|------|
| 填实 | 大运/流年遇空亡地支 | 直接填实，力量恢复 |
| 冲实 | 空亡地支遇对冲 | 间接填实，力量增强 |
| 刑实 | 空亡地支遇相刑 | 间接填实，力量渐增 |
| 合实 | 空亡地支遇相合 | 温和填实，力量稳定 |

---

## 五、真空亡 vs 假空亡

- **真空亡**：空亡地支无透干，无刑冲合会，无生扶 → 彻底无力
- **假空亡**：空亡地支有透干，或有刑冲合会，或有生扶 → 表面空、实际仍有作用

---

## 六、判断示例

**案例：丁卯 己酉 甲子 丁卯**

1. 日柱甲子 → 甲子旬 → 空亡：戌、亥
2. 四柱地支：卯、酉、子、卯
3. 检查：卯、酉、子、卯都不在空亡（戌、亥）里
4. 结论：此命无空亡

**案例：甲戌 壬申 乙酉 壬午**

1. 日柱乙酉 → 甲申旬 → 空亡：午、未
2. 四柱地支：戌、申、酉、午
3. 检查：时支午 = 空亡地支
4. 结论：时柱空亡（子女、晚年）
