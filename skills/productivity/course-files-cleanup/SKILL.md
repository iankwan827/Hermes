# 课件文件夹清理

## 保留文件

| 类型 | 文件模式 | 说明 |
|------|----------|------|
| 图片 | `*.png`, `*.jpg` | 课件截图 |
| OCR文档 | `拾易*.md` | OCR识别的课件 |
| 录音 | `*.mp3` | 语音转录源 |
| 文字稿 | `*_文字稿.md` | Whisper输出 |
| 完整笔记 | `*_完整笔记.md`, `*_完整笔记.docx` | 最终笔记 |
| PDF | `*.pdf` | 用户提供的原始PDF |

## 删除文件

| 类型 | 文件模式 | 说明 |
|------|----------|------|
| 视频 | `*.mp4` | 原始视频(太大) |
| HTML | `*.html` | 中间产物 |
| 脚本 | `*.py` | 生成脚本 |
| JSON | `*.json` | 中间产物(知识点/匹配/审核) |
| 时间段 | `*_时间段整理.md` | 中间产物 |

## 文件夹结构

```
~/Pictures/八字课/
├── 第一课/
│   ├── *.png/jpg       (课件图片)
│   ├── 拾易*.md        (OCR课件)
│   ├── *.mp3           (录音)
│   ├── *_文字稿.md     (Whisper输出)
│   ├── *_完整笔记.md   (最终笔记)
│   ├── *_完整笔记.docx (Word文档)
│   └── 理华老师语录.*  (用户语录)
├── 第二课/
│   └── ...
└── 第N课/
```

## 清理命令

```bash
cd ~/Pictures/八字课/第N课

# 删除脚本
rm -f *.py

# 删除HTML
rm -f *.html

# 删除JSON中间产物
rm -f *.json

# 删除时间段整理
rm -f *_时间段整理.md

# 删除视频(可选，释放空间)
rm -f *.mp4
```

## ⚠️ 注意

- 每节课单独一个文件夹（第一课、第二课...）
- 清理前确认文件已上传飞书
- `理华老师语录.*` 是用户提供的语录，保留
- `拾易*.md` 是OCR课件，保留
