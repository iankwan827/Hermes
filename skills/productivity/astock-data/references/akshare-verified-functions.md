# akshare 已验证函数清单

> 验证时间：2026-06-21（更新）
> akshare版本：1.18.64

## 已验证可用

### stock_hsgt_individual_em(symbol="000001") — 北向资金个股持仓
- 列名：持股日期, 当日收盘价, 当日涨跌幅, 持股数量, 持股市值, 持股数量占A股百分比, 今日增持股数, 今日增持资金, 今日持股市值变化
- 返回所有历史期的北向资金持仓数据
- 用于判断北向资金是否持续增持（"今日增持股数">0的天数比例）
- 验证时间：2026-06-21

### stock_hsgt_hist_em(symbol="沪股通") — 北向资金历史流向
- 列名：日期, 当日成交净买额, 买入成交额, 卖出成交额, 历史累计净买额, 当日资金流入, 当日余额, 持股市值, 领涨股, 领涨股-涨跌幅, 上证指数, 上证指数-涨跌幅, 领涨股-代码
- 参数：symbol="沪股通" 或 "深股通"
- 验证时间：2026-06-21

### stock_lhb_detail_em() — 龙虎榜
- 列名：序号, 代码, 名称, 上榜日, 解读, 收盘价, 涨跌幅, 龙虎榜净买额, 龙虎榜买入额, 龙虎榜卖出额, 龙虎榜成交额, 市场总成交额, 净买额占总成交比, 成交额占总成交比, 换手率, 流通市值, 上榜原因, 上榜后1日, 上榜后2日, 上榜后5日, 上榜后10日
- "解读"字段：如 "1家机构买入，成功率46.03%"、"2家机构买入，成功率25.51%"
- 无需参数

### stock_dzjy_mrmx() — 大宗交易明细
- 列名：序号, 交易日期, 证券代码, 证券简称, 成交价, 成交量, 成交额, 买方营业部, 卖方营业部
- 无需参数
- 注意：只返回最近几天数据

### stock_circulate_stock_holder(symbol="000001") — 流通股东
- 列名：截止日期, 公告日期, 编号, 股东名称, 持股数量, 占流通股比例, 股本性质
- 返回所有历史期的前十大流通股东
- 通过比较不同截止日期的持股数量判断筹码集中度

### stock_financial_abstract(symbol="000001") — 财务摘要
- 列名：选项, 指标, [各期日期...]
- 行数：80行，包含完整财务指标
- 关键指标（中文名）：
  - 归母净利润
  - 营业总收入
  - 经营现金流量净额
  - 净资产收益率(ROE)
  - 归属母公司净利润增长率
  - 营业总收入增长率
  - 资产负债率
  - 毛利率
  - 销售净利率
  - 营业利润率
  - 每股经营现金流
