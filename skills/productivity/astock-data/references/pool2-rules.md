# 第二池：成长爆发池规则

> 创建时间：2026-06-21
> 脚本：`~/Pictures/选股/pool2_screener.py`

## 目标

抓"资金刚开始进 + 业绩还没完全兑现 + 可能走主升浪"的股票。
包括：创业板、科创板（不排除）。

## 与第一池核心区别

| 维度 | 第一池（稳健） | 第二池（成长） |
|------|---------------|---------------|
| 核心 | 稳定盈利 | 资金启动 |
| ROE | 必须高(>8%) | 不重要 |
| 现金流 | 必须好 | 可波动 |
| 机构 | 已经验证 | 刚开始进入 |
| 目标 | 稳定复利 | 捕捉爆发 |
| 风险 | 低 | 中高 |
| 更新频率 | 月/季 | 周/日 |
| 持仓时间 | 长 | 中短 |
| 操作 | 被动持有 | 主动跟随 |
| 卖点 | 基本面变化 | 资金+趋势变化 |

## 筛选逻辑

### ① 基础过滤（只排雷）
- ST → 排除
- 财务造假/退市风险 → 排除
- 近2年持续亏损 → 可以保留
- 经营现金流 → 不强制为正

### ② 成长性（看"加速"）
- 营收增长 >20% 或明显加速
- 净利润不要求连续正，但要"改善趋势"
- 毛利率稳定或提升
- 研发费用占比 >5%（科技类）

### ③ 资金启动信号（核心）
- 龙虎榜：最近30天机构/游资共振
- 连续放量：≥3~5天明显放量
- 换手率：单日 >5%（启动期信号）
- 大宗交易：有机构接盘（非必须）
- 涨幅结构：仍在低位启动区（未暴涨）

### ④ 趋势（只看"启动"）
- 站上60日均线
- MA60刚开始走平或上拐
- MA120可跌破，但不能极端下行
- 突破3~6个月平台

### ⑤ 行业（决定上限）
必须在热点行业：
AI / 半导体 / 机器人 / 医药 / 新能源 / 消费电子 / 军工
或政策驱动方向。没有行业热点 = 直接降级。

### ⑥ 市值
- 最优：30亿 ~ 300亿
- 可接受：300亿 ~ 800亿
- >1000亿：基本不做第二池

## 评分权重

| 维度 | 权重 | 满分 | 指标 |
|------|------|------|------|
| 资金启动 | 35% | 35 | 放量(10) + 连放天数(5) + 龙虎榜(10) + 大宗(5) + 换手率(5) |
| 成长改善 | 30% | 30 | 增长(10) + ROE(8) + 现金流(6) + 负债(6) |
| 趋势启动 | 20% | 20 | MA60(8) + MA60拐头(5) + 突破平台(7) |
| 行业热度 | 15% | 15 | 热门关键词(15) / 创业板科创(8) / 普通(3) |

## 买卖规则

### 买入（3条必须同时满足）
1. **资金启动**：放量突破 + 龙虎榜共振
2. **结构突破**：突破3~6个月平台
3. **行业热度**：板块处于上涨期

### 仓位
- A级（最强）：10%~15%
- B级：5%~10%
- C级：2%~5%
- 原则：宁可分散，不要单押

### 卖出（硬规则，任一触发）
- 放量跌破10日均线
- 连续2~3天资金流出
- 板块热度消失
- 大阴线破位

### 降仓（软规则）
- 涨幅 >50%但量能下降
- 连续缩量上涨
- 资金不再流入
→ 减仓30%~50%

### 止盈
- +30% → 出1/3
- +60% → 再出1/3
- 剩余看趋势
- 跌破10日线 → 全出
- 板块退潮 → 全出

### 风控
- 单票亏损 >10% → 必须减仓
- 走势破位 → 快速退出
- 无资金接力 → 不补仓
