# 选股系统架构参考

> 更新时间：2026-06-21（v2.1 A股实战优化版）

## 第一池：稳健池（stock_screener.py）

### 板块覆盖
- 沪市主板 + 深市主板 + 创业板（6032只）
- **排除**：科创板（688xxx）、北交所（8xxx/92xxx）— 门槛50万+

### 评分权重（v2.1）

| 维度 | 权重 | 满分 | 包含指标 |
|------|------|------|---------|
| 资金面 | 35% | 35 | 龙虎榜连续性(12) + 大宗交易(10) + 放量(8) + MA60趋势(5) |
| 趋势结构 | 25% | 25 | MA250上方(10) + MA60上升(8) + 突破120日高点(7) |
| 成长性 | 20% | 20 | ROE(8) + 利润增长(7) + 现金流(5) |
| 估值 | 15% | 15 | PE合理性(10) + 市值区间(5) |
| 分红 | 5% | 5 | 暂无数据（预留） |

### 初筛条件（v2.1放宽）
- PE: 0 < PE < **150**（v2.0是<100，成长股友好）
- 市值: > 50亿
- 价格: > 2元
- 排除ST/退市

### 二次筛选（季度数据加载后）
- ROE > **8%**（v2.0是10%）
- 负债率 < **75%**（v2.0是60%）
- 有数据才筛，无数据跳过

### 主升浪排除
- 250日涨幅 > 200% → 自动剔除（防高位接盘）

### 评分细项

**资金面（35分）：**
- 龙虎榜连续性：1次=4, 2日+=8, 3日+=12
- 大宗交易：1笔=3, 2笔+=5, 3笔+=8（折价加分）
- 放量：>2.0x=8, >1.5x=6, >1.2x=3
- MA60趋势上升：5

**趋势结构（25分）：**
- 价格 > MA250：10
- MA60上升：8
- 突破120日高点（98%内）：7，接近（95%内）：4

**成长性（20分）：**
- ROE：>15%=8, >10%=6, >8%=4
- 利润增长：>30%=7, >15%=5, >0%=3
- 现金流为正：5

**估值（15分）：**
- PE：<15=10, <25=8, <40=5, <80=3, <150=1
- 市值50-800亿：5, 800-3000亿：3

## 第二池：成长爆发池（pool2_screener.py）

详见 `references/pool2-rules.md`

### 核心区别
- 包含科创板和创业板
- 不排除亏损股
- 评分：资金35% + 成长30% + 趋势20% + 行业15%
- 行业热度关键词匹配

## 缓存策略（重要）

### 核心原则
**休市期间数据不变，全部缓存后不再重新拉取。**

### 缓存文件
```
data/
├── stocklist.json       # 股票列表（当天有效）
├── pool2_stocklist.json # 第二池列表（含科创板）
├── quarterly.json       # 季度财务数据（长期有效）
├── weekly.json          # 周数据：LHB+DZJY+K线
├── kline_year.json      # 一年K线（回测用）
├── history.json         # 历史排名
└── portfolio.json       # 当前持仓
```

### 缓存规则
- 股票列表：当天有效（`days_since < 1`）
- 季度数据：长期有效，财报季刷新
- 周数据：7天有效，含K线/LHB/DZJY
- K线补全：发现缺失时自动补全并保存

### 断点续传
长任务（如`cache_year_data.py`）支持断点续传：
- 进度保存到`progress.json`
- 已完成的不重复拉
- 中断后再跑自动接着来

## 持仓管理规则

### 第一池
- 持有综合分Top 5
- 等额分配（各20%）或按分数加权
- 跌出Top 20 → 卖出
- 基本面恶化 → 直接淘汰

### 第二池（不同）
- 每2~4周重新筛选
- 分层仓位：A级10-15%, B级5-10%, C级2-5%
- 硬止损：跌破10日均线、-10%亏损
- 分段止盈：+30%出1/3, +60%再出1/3
- 板块退潮 → 全出

## 回测系统

### backtest.py
- 从最新选股结果取Top N
- 用K线数据反推1周/2周/1月收益
- 对比沪深300基准

### cache_year_data.py
- 缓存全市场一年K线（~300天）
- 断点续传，支持中断恢复
- 用于后续周/月级别回测

### 首次回测结果（2026-06-21，v2.1第一池Top10）

| 周期 | 组合 | 沪深300 | 超额 |
|------|------|---------|------|
| 1周 | +10.3% | +4.6% | +5.7% ✅ |
| 2周 | +2.1% | +0.8% | +1.3% ✅ |
| 1月 | +1.6% | +3.3% | -1.7% ❌ |

结论：短期跑赢，中期持平。策略偏动量型，行业集中度高（有色金属）。

## Pitfalls

### CSV代码前导零丢失
pandas读CSV时代码列默认为int64，`000426`变成`426`。**必须**：
```python
df = pd.read_csv(file, dtype={"代码": str})
df["代码"] = df["代码"].str.zfill(6)
```

### DataFrame索引bug
`filtered.loc[keep_idx]`用enumerate产生的整数位置会KeyError。**用mask**：
```python
keep_mask = pd.Series(True, index=filtered.index)
for idx, row in filtered.iterrows():
    if should_exclude:
        keep_mask[idx] = False
filtered = filtered[keep_mask]
```

### 缓存策略核心
用户原话："现在休市，数据是不变的。你缓存好全部股票，压根就不需要重新跑。"
→ 休市期间纯缓存操作，不拉API。
