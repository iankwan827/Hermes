# 买卖提示规则

> 创建时间：2026-06-21
> 保存位置：`~/Pictures/chatgpt选股系统.md`（完整版）

## 设计原则

系统只输出"提示"，不做自动交易。A股突发事件（停牌、公告、监管函等）评分系统不一定能完全理解，人保留最终决定权。

## 第一池（稳健池）买入提示

满足**全部**：
1. 进入稳健池 Top10
2. 连续2周留在 Top10（避免一周游）
3. 总评分 > 80分
4. 未出现重大利空

```
【稳健池买入提示】
股票：XXX
评分：87
连续2周位于Top10
建议纳入持仓观察
```

## 第一池卖出提示

满足**任意**：
1. 跌出 Top20
2. 连续4周评分下降
3. 出现重大利空
4. 财报恶化（利润、现金流明显变差）

```
【稳健池卖出提示】
股票：XXX
评分从88降至72
跌出Top20
建议调出持仓池
```

## 第二池（成长池）买入提示

建议满足：
- **条件A**：进入成长池 Top10
- **条件B**：资金启动（龙虎榜机构/游资净买入，或连续放量3天+）
- **条件C**：趋势启动（突破60日平台/创120日新高/站上60日均线）

```
【成长池买入提示】
股票：XXX
评分：91
机构净买入 放量突破平台
```

## 第二池卖出提示（最重要）

满足**任意一条**：
1. 跌出成长池 Top20
2. 连续两周评分下降超过10%（如 91→84→75）
3. 资金撤退（龙虎榜连续净卖出/大宗连续折价减持）
4. 趋势破坏（跌破20日均线/跌破60日均线）

```
【成长池卖出提示】
股票：XXX
评分从91降至74
连续两周下降
跌破20日均线
```

## 换仓提示

当持仓A评分下降，同时更高评分B连续两周出现：

```
【换仓提示】
建议：减持A 增持B
原因：评分差距16分
连续两周维持
```

## 自动化逻辑汇总

| 池 | 触发 | 动作 |
|----|------|------|
| 稳健池 | 连续2周Top10 | 买入提示 |
| 稳健池 | 跌出Top20 | 卖出提示 |
| 成长池 | Top10+资金启动+趋势启动 | 买入提示 |
| 成长池 | 跌出Top20/资金撤退/趋势破坏 | 卖出提示 |
| 通用 | 持仓评分持续低于替代标的 | 换仓提示 |

系统输出格式：
```
本周新增买入候选：3只
本周新增卖出候选：2只
本周换仓建议：1只
```
