# 痣位置直断速查

> 来源：第四课（痣相三板斧）+ 第二三课补充

## 一、天干法（必定有痣，地支占空亡可能无）

| 天干 | 痣位置 | 口诀 |
|------|--------|------|
| 甲 | 背部 | 甲背 |
| 乙 | 胸部 | 乙胸 |
| 丙 | 肩膀 | 丙肩 |
| 丁 | 肩膀 | 丁肩 |
| 戊 | 面部 | 戊面 |
| 己 | 面部 | 己面 |
| 庚 | 腰部/膝部 | 庚腰/庚膝 |
| 辛 | 腰部/膝部 | 辛腰/辛膝 |
| 壬 | 腹部/四肢 | 壬腹 |
| 癸 | 腹部/四肢 | 癸腹 |

**口诀**：甲背乙胸丙丁肩，戊己面上庚辛膝，壬癸腿部及四肢

### 天干法要点
- 天干法必定有痣（地支占空亡可能无）
- 痣的定义：痣、痘子、小疱瘾、小黑点、小雀斑、血痣等小印记，统称"痣"
- 可以用多种方法交叉验证同一部位（金木相克、辛金、土、伤官/偏印年干），符合两条以上就肯定有

## 二、地支法（三句口诀定痣位）

| 地支 | 痣位置 | 细分 |
|------|--------|------|
| 子午卯酉 | 胸部 | 子午正中，卯酉在乳房两侧（含腋窝下面） |
| 辰戌丑未 | 肚部 | 辰戌上部，丑未下部 |
| 寅申巳亥 | 阴部 | 巳亥在器官处，寅申在腹股沟（大腿根） |

**口诀**：子午卯酉痣在胸，辰戌丑未痣在肚，寅申巳亥痣在阴

### 地支法要点
- **越靠近日支的应验越明显**（日支代表生殖器官）
- 时支和年支上就稍微远一点
- 月柱和日柱上有空亡会影响断事，但客观事实没有影响
- 如果找不到，可能有刑（刻老疤）
- 子午卯酉前面几乎都能找到，找不到可能是跟小时候的睡姿有关（趴着睡/仰着睡）
- 人体可以翻过来用——前面找不到，看后面对应位置
- 巳亥在器官处男女士有别：男的在会阴/阴囊/阴茎，女的在会阴/外阴
- 所有口诀全部不分男女

### 地支法特殊断法
| 地支 | 断语 |
|------|------|
| 辰戌 | 时柱：有哥无弟，有弟本人带残疾；先克父 |
| 丑未 | 时柱：有弟无哥；先克母 |

## 三、土=棕色印记（第三种验证法）

- 土五行在五行里面是棕色
- 身体上皮肤为棕色的就是印记
- 如果土多连在一起，可能就有太极痣
- 可与天干法、地支法交叉验证

## 四、年干十神法（第四种验证法）

如果年干的十神是以下情况，脸上有记号的可能性较大：
- **伤官**（最明显）
- **劫财**
- **偏印**

前面三个方法（天干法+地支法+土色法）足够用了，这个作为补充验证。

## 五、眼角印记——面相入门

眼角位置叫**夫妻宫**：

| 痣的数量 | 含义 |
|---------|------|
| 干净无痣 | 感情专一、长久 |
| 1个固定的 | 一段稳定的感情 |
| 2个变用的 | 两段感情 |
| 3个轮流的 | 三段感情 |
| 4个替换的 | 四段感情 |
| 其他/暗的小痣 | 短暂的爱情（日抛型） |

**注意**：痣只代表"标记"，具体事件需结合个人八字原局判断，不是所有人同一位置的痣代表同样的事。

## 六、使用话术

- ❌ 不要直接说"你有个痦子"（对方可能说"我没有痦子，但我那个地方确实有个小雀斑"）
- ✅ 应该说"类似于痦子、伤疤等小的印记"
- 结合对方的年龄、认知来描述部位
- 口诀全部不分男女
