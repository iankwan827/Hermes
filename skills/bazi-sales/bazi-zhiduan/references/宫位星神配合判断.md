# 宫位与星神配合判断方法

> 来源：第三课"宫位为主，星神为辅"原则的实操展开

## 核心问题

四柱宫位代表"位置"（哪里），十神代表"星"（谁）。当宫位和星不一致时，到底看哪个？

**答案：宫位为主，星神为辅。先看宫位状态，再用宫位上的十神判断该六亲的处境。**

⚠️ **易错点**：不是先找六亲星在哪，而是先看宫位！用户纠正："应该是以宫位为主吧"

## 一、判断框架（宫位为主）

### 核心原则：先看宫位，再看星

```
Step 1: 确定要断什么六亲
Step 2: 找到该六亲的宫位（年祖/月父/日配/时子）
Step 3: 看宫位本身的旺衰、冲克、空亡
Step 4: 看宫位上的十神是什么 → 用这个十神判断该六亲的处境
Step 5: 如果该六亲的星正好在宫位上 → 最准（宫星合一）
Step 6: 如果该六亲的星不在宫位上 → 以宫位为主，星为辅验证
```

### ⚠️ 关键区分：宫位天干 vs 整个宫位（第五课重点）

> 🎙️ 讲师原话："他在父亲宫位上，本来这个地方应该是癸水，但是做了金，金是生水的。所以呢，你虽然在心脏血液方面有一点点的数据异常，但是影响不大，因为这个父亲宫位有生助的神。"

**父亲宫位 = 月柱天干**（不是整个月柱）

| 概念 | 说明 |
|------|------|
| 父亲宫位 | **月柱天干**的位置 |
| 宫位上的十神 | 月柱天干是什么十神（如辛金=食神） |
| 作用关系 | 宫位天干对该六亲星的生克关系 |

**为什么是月柱天干？**
老师说"本来这个地方应该是癸水"——意思是按道理偏财（父亲星）应该出现在月柱天干的位置（父亲宫位），但实际上这个位置被其他十神占了。这是在讲**宫位天干上"坐"的是什么十神**，而不是整个柱的组合。

**判断方法：**
1. 找父亲宫位 → 月柱天干
2. 看月柱天干是什么十神（如辛金=食神）
3. 看这个十神对父亲星（偏财）的作用关系
4. 宫位天干**生**父亲星 → 父亲有助力，问题不大
5. 宫位天干**克**父亲星 → 父亲受压制，问题较大

### 宫位上的十神→该六亲的处境

| 宫位上的十神 | 该六亲的处境 |
|-------------|-------------|
| 正官/正印/正财 | 该六亲状态好，关系融洽 |
| 七杀 | 该六亲带来压力/冲突 |
| 伤官 | 该六亲与命主有口舌/叛逆 |
| 比肩/劫财 | 该六亲与命主竞争/争夺 |
| 食神 | 该六亲让命主舒服/受益 |
| 偏印 | 该六亲让命主压抑/约束 |
| 偏财 | 该六亲有意外助力 |

**具体例子**：

| 场景 | 判断 |
|------|------|
| 月柱（父母宫）有七杀 | 父母带来压力，与父母关系紧张 |
| 月柱有伤官 | 与父母有口舌，叛逆期长 |
| 月柱有正印 | 母亲缘分好，母亲保护命主 |
| 日柱（夫妻宫）有七杀 | 配偶带来压力，婚姻有冲突 |
| 日柱有比肩 | 配偶与命主竞争，各不相让 |
| 时柱（子女宫）有伤官 | 子女叛逆，与子女有口舌 |

### 宫位状态判断

| 宫位状态 | 该六亲的处境 |
|---------|-------------|
| 宫位旺相 | 该六亲有力，对命主帮助大 |
| 宫位衰弱 | 该六亲无力，对命主帮助小 |
| 宫位空亡 | 该六亲缘分薄，聚少离多 |
| 宫位被冲克 | 该六亲受伤害/变动/关系不稳 |
| 宫位被合 | 该六亲与命主有缘分/牵绊 |

## 二、六亲星速查（辅助验证用）

### 男命六亲星
| 六亲 | 正星 | 偏星 |
|------|------|------|
| 父亲 | — | **偏财** |
| 母亲 | 正印 | 偏印（枭神） |
| 兄弟 | 比肩 | 劫财 |
| 妻子 | 正财 | 偏财 |
| 子女 | 正官（头胎男） | 七杀（头胎女） |

⚠️ **易错点**：父星是偏财不是正财！用户纠正："父星是偏财你弄错了"

### 女命六亲星
| 六亲 | 正星 | 偏星 |
|------|------|------|
| 父亲 | — | 偏财 |
| 母亲 | 正印 | 偏印（枭神） |
| 兄弟 | 比肩 | 劫财 |
| 丈夫 | 正官 | 七杀 |
| 子女 | 食神（头胎女） | 伤官（头胎男） |

## 三、实战判断流程

**断某一个六亲的完整流程**：

```
Step 1: 确定要断什么六亲
Step 2: 找到该六亲的宫位（年祖/月父/日配/时子）
Step 3: 看宫位本身的旺衰、冲克、空亡
Step 4: 看宫位上的十神 → 用这个十神判断该六亲的处境
Step 5: 找该六亲的星在哪 → 辅助验证
Step 6: 综合判断
```

## 四、实例解析

**19870912男命**：
- 年柱：丁卯（伤官+劫财）
- 月柱：己酉（正财+正官）
- 日柱：甲子（日主+正印）
- 时柱：丁卯（伤官+劫财）

**断父亲**：
- Step 1: 父亲 → 看月柱（父母宫）
- Step 2: 月柱己酉（正财+正官）
- Step 3: 月柱被年支卯木冲 → 父母宫受冲，父母关系不稳定
- Step 4: 月柱有正财和正财 → 父母宫有财星和官星，父亲与财运/事业相关
- Step 5: 父星偏财不见 → 父亲信息弱，父亲缘薄
- Step 6: 综合 → 父亲缘薄，父母宫受冲，父亲与命主关系有波动

**断母亲**：
- Step 1: 母亲 → 看月柱（父母宫）
- Step 2: 月柱己酉（正财+正官）
- Step 3: 月柱被年支卯木冲 → 父母宫受冲
- Step 4: 月柱有正印？没有 → 看母星正印在哪
- Step 5: 母星正印在日支子水 → 母亲信息看日柱
- Step 6: 综合 → 母亲对命主有助力（子水生甲木），但子卯刑→与母亲有口舌

**断配偶**：
- Step 1: 配偶 → 看日柱（夫妻宫）
- Step 2: 日柱甲子（日主+正印）
- Step 3: 日支子水旺相 → 夫妻宫有力
- Step 4: 日柱有正印 → 配偶温和有文化，对命主有助力
- Step 5: 妻星正财在月柱 → 妻子信息看月柱
- Step 6: 综合 → 配偶温和有文化（宫位状态好），但妻星正财虚浮+被劫财克→妻子缘分薄

**断子女**：
- Step 1: 子女 → 看时柱（子女宫）
- Step 2: 时柱丁卯（伤官+劫财）
- Step 3: 时柱被日支子水刑 → 子女宫受刑
- Step 4: 时柱有伤官 → 子女叛逆，与子女有口舌
- Step 5: 子星正官在月柱 → 子女信息看月柱
- Step 6: 综合 → 子女宫有伤官（叛逆），但子星正官在月柱有力→子女有能力但与命主有口舌

## 五、第五课案例：宫位天干分析法（重点）

**案例：甲戌年 辛未月 己酉日 壬申时（司先生的儿子）**

### 断父亲（🌟 宫位天干分析法）

| 步骤 | 内容 | 说明 |
|------|------|------|
| ① 找父亲宫位 | **月柱天干** = 父亲宫位 | 不是看偏财在哪 |
| ② 看宫位上是什么 | 月柱天干 = **辛金（食神）** | 不是偏财癸水，是辛金"坐"在这个位置 |
| ③ 看宫位对父亲星的作用 | 辛金**生**癸水（偏财/父亲星） | 宫位对父亲有生助 |
| ④ 下结论 | 父亲心脏血液有异常，但**不严重** | 因为有生助化解 |

> 🎙️ 讲师原话："你作为他的父亲当然得有话讲了啊，他原局有正财就不论正财了啊，原局没偏财，偏财是癸水。他在父亲宫位上，本来这个地方应该是癸水，但是做了金，金是生水的。所以呢，你虽然在心脏血液方面有一点点的数据异常，但是影响不大，因为这个父亲宫位有生助的神。"

**核心逻辑：** 不是去数偏财有几个、旺不旺，而是看**月柱天干这个位置上的十神对父亲星（偏财癸水）起了什么作用**。月柱天干辛金生癸水→宫位帮了父亲→问题不大。
