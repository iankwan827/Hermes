# 婚姻断语速查

## 配偶星定位
- 男命：正财/偏财为妻星
- 女命：正官/七杀为夫星

## 夫妻宫（日支）核心断语

| 组合 | 断语 | 应验率 |
|------|------|--------|
| 日支同一字 | 性生活最协调美满 | 90% |
| 日支坐沐浴 | 性生活较重视 | 85% |

| 日支子午卯酉 | 性要求比较强 | 85% |

## 婚姻核心逻辑

### 男命婚姻
- 找老婆要选**喜欢的** → 宠爱才会食伤生财 → 婚姻和谐
- 看不顺眼 → 比劫克财 → 婚姻不稳

### 女命婚姻
- 找老公要找**优秀的** → 崇拜才会财生官 → 利于婚姻稳定
- 瞧不起 → 伤官见官 → 婚姻不稳

### 原理
- **财生官**：崇拜丈夫 → 丈夫得力 → 婚姻稳定
- **伤官见官**：瞧不起丈夫 → 丈夫受克 → 婚姻不稳
- **食伤生财**：宠爱妻子 → 妻子得力 → 婚姻和谐
- **比劫克财**：看不顺眼妻子 → 妻子受克 → 婚姻不稳

## 婚姻次数判断

### 夫妻宫被坏
- 看坏它的东西有几个 → 就有几次婚姻

### 夫妻星多现
- 有几个夫妻星 → 就有几次婚姻

### 夫妻宫逢穿
- 穿了夫妻星的那个字 → 必离婚或配偶死

| 官杀混杂 | 感情混乱，多婚 | 85% |

## 女命无官星直断

**条件**: 命局正官+七杀皆无（天干不见，地支藏干也不见）
**断语**: "要么没有婚姻/感情，要么谁来都可以"
**判断要点**:
- 有一个就不算"无官星"，需仔细检查天干+地支藏干
- 需结合大运流年看官杀运——大运走官杀运时可能有婚姻机会
- 无官星不等于无感情，只是感情模式与常人不同
