# 进阶断语速查

> 来源：Day72-99学习笔记，2026-06-25整理

## 一、十神与性格/能力

### 食伤相关
| 组合 | 断语 |
|------|------|
| 缺乏食伤 | 共情能力稍弱 |
| 印旺（尤其偏印） | 人容易冷漠，缺乏情感表达 |
| 食伤旺 | 喜欢创造，不断找新方法、新方向 |
| 食伤生财 | 宠爱才会食伤生财（男命找老婆要选喜欢的） |
| 比劫克财 | 看不顺眼就是比劫克财（男命婚姻不稳） |

### 偏印相关
| 组合 | 断语 |
|------|------|
| 偏印旺 | 喜欢用现成的，看看有没有人可以模仿 |
| 偏印旺 | 实在找不到模仿的对象，再创新 |

### 食伤vs偏印创造方式对比
| 十神 | 创造方式 |
|------|----------|
| 食伤 | 主动创造，不断找新方法、新方向 |
| 偏印 | 先模仿，找不到模仿对象才创新 |

## 二、婚姻断语

### 男命婚姻
| 组合 | 断语 |
|------|------|
| 财生官（崇拜丈夫） | 利于婚姻稳定 |
| 伤官见官（瞧不起丈夫） | 婚姻不稳 |
| 食伤生财（宠爱妻子） | 婚姻和谐 |
| 比劫克财（看不顺眼妻子） | 婚姻不稳 |

**核心逻辑**：
- 找老公要找优秀的 → 崇拜才会财生官 → 利于婚姻稳定
- 找老婆要选喜欢的 → 宠爱才会食伤生财 → 婚姻和谐

## 三、地支与人际关系

| 组合 | 断语 |
|------|------|
| 地支刑害多 | 与外界人际关系不好 |
| 地支刑害多 | 难建立良好的外部关系 |
| 地支刑害多 | 做事容易因为人际阻碍导致不顺畅 |

## 四、身旺vs身弱

| 日主状态 | 特征 |
|---------|------|
| 身旺 | 抗压能力强 |
| 身弱 | 定力差，容易受到外界影响 |
| 身弱 | 内心敏感，别人看来不算事的事，身弱的人很难接受 |
| 身弱 | 会无限放大痛苦，容易情绪崩溃 |

## 五、印星与情感

| 组合 | 断语 |
|------|------|
| 印旺 | 人容易冷漠，缺乏情感表达 |
| 印运 | 共情能力也会变弱 |
| 食伤弱+印旺 | 情感封闭，不易表达感情 |
