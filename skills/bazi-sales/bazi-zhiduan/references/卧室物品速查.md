# 卧室物品直断速查

## 核心原理
床下属于卧室私密空间，对应八字中日支（夫妻宫）与时支（子女宫）等地支宫位。

## 五行与床下物品对应

| 五行 | 核心属性 | 床下物品典型类型 |
|------|---------|----------------|
| 木 | 生长、条达 | 书籍、纸张、木质物品 |
| 火 | 热情、光明 | 电子产品、充电器、灯具 |
| 土 | 承载、稳定 | 重物、箱子、储物盒 |
| 金 | 收敛、变革 | 金属工具、刀剪、硬币 |
| 水 | 智慧、流动 | 鱼缸、雨衣、液体容器 |

## 神煞与床下物品

| 神煞 | 床下物品特征 |
|------|-------------|
| 桃花 | 情趣用品、香薰、装饰品 |
| 华盖 | 宗教书籍、佛珠、艺术品 |
| 驿马 | 行李箱、旅行用品、地图 |
| 天乙贵人 | 贵重物品、收藏品 |
| 羊刃 | 刀具、运动装备 |

## 判断方法
1. 看日支（夫妻宫）的五行属性
2. 看时支（子女宫）的五行属性
3. 看命局中的神煞组合
4. 综合判断床下可能有什么物品
