3. 命中的全部列出来，不中的跳过
4. 作为"过三关"的第一关验证

### 模式二：专题速断（客户问什么答什么）
客户报出八字后，直接问"看看感情"、"看看身体"、"看看财运"等具体问题时，不需要做全量过三关扫描，直接定位对应速查表+对应分析步骤：

| 客户问题 | 加载速查表 | 分析要点 |
|---------|-----------|---------|
| 看看感情/婚姻 | 婚姻断语速查 | 配偶星定位+夫妻宫+桃花+离婚铁口 |
| 看看身体/健康 | 健康断语速查 | 五行脏腑+旺衰+枭神夺食+手术血光 |
| 看看财运 | （待创建财运断语速查） | 财星状态+财库+食伤生财 |
| 看看性格 | 十天干性格速查 + 好色格局速查 | 日主天干直接查表+十神组合+日支本气断脾气+年干时干看表里 |
| 看看事业 | bazi-sales-steps事业六步法 | 日主→官杀→印星→喜用→大运→流年 |

**专题速断输出格式：**
1. 先列出相关星位（如感情列财星/夫妻宫，健康列五行旺衰）
2. 逐条对照速查表，命中的列出来
3. 给出总结性判断
4. 不需要做完整的格局/用忌分析（那是详细分析的事）

**⚠️ 专题速断 ≠ 过三关。** 专题速断是快速回答客户具体问题，过三关是全量验证建立信任。客户问"看看感情"就直接分析感情，不要反过来要求客户先做过三关。

## Pitfalls

1. **过三关不要写成详细分析**：用户要的是直断断语验证，不是旺衰/格局/用忌的详细推导
2. **所有速查表都要扫**：不只是28秘诀，十天干性格、痣位置、身材体型、面相特征、婚姻断语、健康断语、财运断语、神煞断语都要过一遍
3. **墓库相关断语要动态判断**：只有八字中出现辰戌丑未时才启用墓库相关断语
4. **直断规则按用途分类，不按主题分类**：无官星直断是过三关用的（放到28秘诀），不是婚姻专题（不要放到婚姻断语速查表）。判断一条直断该放哪个速查表时，看它在过三关哪个步骤用，不是看它涉及什么主题
5. **课堂资料查找路径**：八字课程提取的md文件在两个目录：`D:/hermes-agent/imge_v3/docs/`（录音转写+图片提取）和 `D:/hermes-agent/imge_v2/docs/`（哈希命名，对应关系查 `_rename_map.json`）。两个都是课堂资料，找课程内容两个目录都要查
6. **案例分析必须区分课件排盘和讲师口头案例**：课件里的排盘示例和讲师口头分析的实际案例可能是两个不同的八字。整理笔记时必须分开标注，不能混在一起。已发现：课件排盘（庚辰甲申戊寅庚申）和讲师分析（庚金日元/丁火月干时干/丑土月/水气地支）是两个不同八字。
