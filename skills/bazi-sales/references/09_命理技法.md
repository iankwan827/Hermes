## 一，身强身弱判断

> 断语来源：第二节课

**三个来源：**
- 得令：得月令本气生助
- 得地：得非月令地支生助
- 得助：天干有同类帮身

**同党：** 印枭、劫比
**异党：** 官杀、财才、食伤

**身强倾向：** 计划能力强、有组织力、领导力强、精力充沛
**身弱倾向：** 专业知识、技术能力、科学研究、艺术创造、精细工作

## 三，用神忌神喜用神

> 断语来源：第十七节课·用神忌神喜用神全解

### 五大核心概念

| 概念 | 定义 |
|------|------|
| 用神 | 核心"药方"，治命局失衡的关键五行 |
| 喜神 | 辅助用神的五行，生助用神 |
| 忌神 | 直接克用神的五行，病症根源 |
| 仇神 | 间接助忌神的五行，忌神的帮凶 |
| 闲神 | 中性，可转化为喜神或忌神 |

### 用神四大取法

**1. 扶抑取用法（最常用）**
- 身旺 → 取克泄耗为用（官杀克、食伤泄、财星耗）
- 身弱 → 取生助为用（印星生、比劫助）

**2. 调侯取用法（优先于扶抑）**
- 生于夏月（巳午未）→ 取水调候
- 生于冬月（亥子丑）→ 取火调候
- 生于四季（辰戌丑未）→ 取木/金/水调燥湿

**3. 通关取用法**
- 金木相战 → 取水通关
- 水火相战 → 取木通关
- 土水相战 → 取金通关

**4. 病药取用法**
- 土多金埋 → 病在土旺，药为木/金/水
- 木多火塞 → 病在木旺，药为金/火/土
- 水多木漂 → 病在水旺，药为土/木/火

### 十神喜忌对应

| 十神 | 为喜时 | 为忌时 |
|------|--------|--------|
| 官杀 | 事业顺，责任心强 | 压力过大，受小人侵害 |
| 财星 | 财运佳，理财有道 | 破财，财务纠纷 |
| 印星 | 学业佳，贵人多助 | 懒惰，依赖心重 |
| 食伤 | 才华显，创意佳 | 思绪杂乱，消极 |
| 比劫 | 朋友相助，逢贵人 | 破财，是非竞争 |

## 五，化气格与从格

> 断语来源：第二十三节课

**化气成功的五大铁律：**
1. 天干五合紧贴（日干与月干或时干）
2. 化神当令得时
3. 日主无强根
4. 化神旺而透干
5. 无克破化神

**假化气格三种情况：**
- 合而不化
- 化而不纯
- 化气后破

## 六，地支关系

> 断语来源：第十六节课

### 六合
子丑合土，寅亥合木，卯戌合火，辰酉合金，巳申合水，午未合火

### 三合局
申子辰（水局），亥卯未（木局），寅午戌（火局），巳酉丑（金局）

### 六冲
子午冲，丑未冲，寅申冲，卯酉冲，辰戌冲，巳亥冲

### 三会局
寅卯辰（东方木），巳午未（南方火），申酉戌（西方金），亥子丑（北方水）
力量是三合局的1.5倍，优先级最高

### 三刑
- 无恩刑：寅巳申（忘恩负义）
- 恃势刑：丑戌未（仗势欺人）
- 自刑：辰辰、午午、酉酉、亥亥（自我伤害）

### 六害
- 子未害，丑午害，寅巳害
- 卯辰害，申亥害，酉戌害
本质：破坏三合局，恩将仇报

### 暗合
- 亥中壬水与午中丁火暗合（丁壬合）
- 子中癸水与巳中丙火暗合（丙癸合）
本质：暗中勾结/秘密情感

### 关系优先级
三会局＞三合局＞六合＞六冲＞三刑＞六害＞六破＞暗合＞普通生克

### 六合规则
- 紧贴相合，隔位无力
- 合化条件：化神旺、透干、无冲克
- 六合优先级 > 生克

## 八，大运流年

> 断语来源：第二十五节课

| 大运类型 | 适合做什么 | 应验率 |
|----------|------------|--------|
| 官杀大运 | 求职、晋升、创业 | 95% |
| 印星大运 | 充电、考证、积累人脉 | 95% |
| 财星大运 | 拓展业务，投资 | 95% |
| 食伤大运 | 转型，做顾问 | 90% |

### 岁运并临

**定义：** 大运地支与流年地支相同，岁运重叠

**应事规律：**
- 岁运并临为喜用神 → 好事叠加，机缘爆发
- 岁运并临为忌神 → 灾祸叠加，冲击剧烈
- 岁运并临 + 忌神被冲克 → 生死信号（需原局配合）

**判断流程：**
1. 先看并临的五行属性 → 对应吉凶方向
2. 再看是忌神还是喜用神 → 定吉凶性质
3. 最后看冲克关系 → 定应期与剧烈程度

### 天克地冲（详见第三节）

天克地冲详情见第三节，此处强调其在岁运层面的判断：
- 冲克夫妻宫/配偶星 → 婚姻变动
- 冲克父母宫 → 父母灾祸
- 冲克日主本身 → 自身冲击
- 具体应事需配合十神与宫位判断
