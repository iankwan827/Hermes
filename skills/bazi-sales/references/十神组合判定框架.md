# 十神特殊组合判定框架

> 核心原则：先定格局，再看组合是否攻击/辅助格局核心
> 来源：用户教学 + 案例课蒸馏，2026-06-03确认

## 判定总流程

```
第一步：定格局（月令透干取格）
第二步：确定格局的核心十神
第三步：看其他十神是否攻击/辅助这个核心
第四步：只有直接作用于格局核心的，才算成立
```

## 格局混杂处理原则

> 当月令（格局根基）和天干（透出十神）形成混杂时，需要"去留"处理
> 月令可以是正也可以是偏，关键是看谁是根基谁是透出

| 月令（格局根基） | 天干（透出十神） | 格局状态 | 最喜的处理方式（去留） |
|------------------|------------------|----------|------------------------|
| 正官 | 七杀 | 官杀混杂，压力重重 | 喜食神制杀，或劫财合杀（留官） |
| 七杀 | 正官 | 官杀混杂，压力重重 | 喜食神制杀，或劫财合杀（留杀，官为杂） |
| 伤官 | 食神 | 食伤并见，才华内耗 | 喜正印贴身制衡，化克为用（佩印） |
| 食神 | 伤官 | 食伤并见，才华内耗 | 喜正印贴身制衡，化克为用（佩印） |
| 正印 | 偏印（枭） | 枭印齐来，思想矛盾 | 喜偏财克去天干偏印（留正印） |
| 偏印（枭） | 正印 | 枭印齐来，思想矛盾 | 喜偏财克去月令偏印（留正印） |
| 正财 | 偏财 | 正偏财混杂，求财矛盾 | 喜比劫克去偏财（留正财） |
| 偏财 | 正财 | 正偏财混杂，求财矛盾 | 喜比劫克去月令偏财（留正财） |

**核心逻辑：**
- 混杂的本质是"两个同类但不同的十神争一个位置"
- 去留的原则是**留清去浊**，让格局纯正
- 官杀混杂：留官去杀（官清杀浊）或留杀去官（杀有制化时）
- 食伤并见：用印来收束，让才华集中输出
- 枭印齐来：留正印去偏印（正印主学识，偏印主杂思）
- 正偏财混：留正财去偏财（正财主稳定收入，偏财主投机）

**应用要点：**
1. 先看月令本气藏干确定格局根基
2. 再看天干是否透出同类但不同的十神（如正官vs七杀）
3. 如果形成混杂 → 按上表找"去留"方式
4. 有合适的"去留"组合 → 格局转清，论吉
5. 没有"去留"组合 → 格局混杂，论凶或论压力

**销售话术应用：**
- 混杂无制化 → "您八字里有XX混杂，压力确实比较大"
- 混杂有制化 → "不过好在您八字有XX来化解，这就是您的优势"
- 引导成交 → "这种混杂格局，调理得当的话，反而比纯格更有爆发力"

## 替代分析方法（不成立时的处理）

不成立 ≠ 不分析，而是不贴组合标签，改为逐字分析各自功能和互动后果：

```
第一步：确定这两个十神各自在命局中扮演什么角色（按十神自身功能，不按格局核心）
第二步：看它们的互动（生/克/合/冲）改变了各自的力度
第三步：分析力度改变后，对命局其他环节的间接影响
```

### 关键示例

**七杀格中枭神夺食不成立，但需要警惕**：
食神在七杀格里是制杀的利器，偏印制掉食神后，七杀失去制化，间接导致七杀攻身加重——虽然不叫枭神夺食，但实际效果类似。

**七杀格中财星破印不成立，但需要警惕**：
印在七杀格里是化杀为用的关键，财破印后七杀失去转化通道，杀气直冲日主。

**食神格中财星破印不成立，反而利好**：
印在食神格里可能克制食神（偏印夺食），财破印反而解除了对食神的威胁。

**印格中比劫争财不成立，反而利好**：
财在印格里是克印的敌星，比劫争财反而削弱了财的力量，间接保护了印星。

## 成立时的核心断语

### 正官格
- **伤官见官**：伤官见官为大忌，口舌官非必难免（95%）。事业多波折，晚发为宜。
- **官杀混杂**：做事三心二意，朝三暮四，工作变动大（90%）。
- **财官相生**：财官相辅，事业有动力、财富与地位双丰收（95%）。

### 七杀格
- **食神制杀**：七杀有制化为权，无制则为祸（95%）。主有魄力、掌实权。
- **杀印相生**：自律+学习能力强（95%）。职位稳定步步高升。
- **羊刃驾杀**：武贵格，主掌实权、军警、执法。

### 食神格
- **枭神夺食**：心情抑郁焦虑，能力得不到发挥，劳动成果被窃取。主消化系统疾病。
- **食神生财**：靠技艺创意赚钱（95%）。聪明机灵，有艺术气息。

### 伤官格
- **伤官配印**：聪明+规划好，学术研究能力强（95%）。伤官佩印，贵不可言。
- **伤官生财**：聪明积极上进，有事业心，但也容易急躁。
- **伤官伤尽**：伤官伤尽，最为奇。

### 印格
- **财星破印**：在单位做稳定的工作上班比较好，适合体制内发展。

### 财格
- **比劫争财**：竞争激烈，财富难聚（90%）。不适合合伙，容易因身边人破财。
