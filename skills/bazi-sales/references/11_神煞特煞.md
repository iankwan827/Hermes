## 一，将军箭（男命血光）

> 断语来源：将军箭与阎罗关

### 核心口诀
> 酉戌辰时春不旺，未卯子时夏中亡
> 寅午丑时秋并忌，冬季亥申巳为殃
> 一箭伤人三岁死，二箭须教六岁亡
> 三箭九岁儿难活，四箭十二岁身亡

### 查法（以生月对照时辰）
- 春季（寅卯辰月）：酉、戌、辰时为一箭
- 夏季（巳午未月）：未、卯、子时为二箭
- 秋季（申酉戌月）：寅、午、丑时为三箭
- 冬季（亥子丑月）：亥、申、巳时为四箭

### 真假箭判断
| 条件 | 判断 |
|------|------|
| 时辰合口诀 + 日时相冲 + 无吉星 | **真箭**（大凶） |
| 时辰合口诀 + 无冲克 | **假箭**（小凶） |

### 危害公式
> 危害指数 = 煞数 × 冲克数 × (1 - 吉星数 × 0.3)

### 实战断语
- 将军箭+羊刃 → 必主刀兵之灾，轻则残疾，重则死亡
- 真箭无化解 → 逢冲箭之年必有金属类意外（刀/车祸/玻璃）
- 时箭日冲 → 伤自己；日箭时冲 → 伤骨肉

### 化解方法
1. 吉星化解（天德/月德/天乙贵人自动减煞）
2. 喜金者戴黄金小剪刀（刀口向下）
3. 草人替身法（十字路口焚化）
4. **职业规避**：忌军警、外科医生、厨师、机械操作

## 二，阎罗关（女命生死婚灾）

> 断语来源：将军箭与阎罗关

### 核心口诀
> 癸壬相连阎王到，丑寅相见女命愁
> 冲官伤子婚破碎，吉星一到解千忧

### 查法
- 通用：八字见癸壬相连；日丑时寅/日寅时丑；时柱见癸亥/壬子
- 女命专属：官星坐死绝之地；日支为辰戌+时柱见丑寅

### 真假关判断
| 条件 | 判断 |
|------|------|
| 合查法条件 + 冲克官星/食伤 + 无吉星 | **真关**（大凶） |
| 合查法条件 + 仅冲闲神/有吉星 | **假关**（小凶） |

### 轻重分级
| 级别 | 应事 |
|------|------|
| 一级（生死级） | 真关+忌神当道 → 重疾/意外死亡 |
| 二级（婚育级） | 真关+冲官星 → 离婚/丈夫意外；冲食伤 → 流产/不孕 |
| 三级（官非级） | 假关+冲财星 → 小额官非/破财 |

### 实战断语
- 阎罗关+伤官见官 → 女命必离婚
- 阎罗关+白虎煞 → 生育易大出血
- 阎罗关+天罗地网 → 易被囚禁（家暴/牢狱）

### 化解
1. 吉星化解（天乙贵人是女命阎罗关第一解药）
2. 晚婚（28岁后）避应期
3. 佩戴阿弥陀佛吊坠
4. 过奈何桥科仪（女命专属）

## 四、阳刃（血光之刃）

> 断语来源：第十八节课将军箭与阎罗关

### 阳刃查法

| 日干 | 阳刃地支 | 日干 | 阳刃地支 |
|------|----------|------|----------|
| 甲 | 卯 | 庚 | 酉 |
| 乙 | 寅 | 辛 | 申 |
| 丙 | 午 | 壬 | 子 |
| 丁 | 巳 | 癸 | 亥 |
| 戊 | 午 | | |

### 阳刃特质
- 刚烈暴戾，敢闯敢拼，有魄力
- 独立自主，不喜依赖他人
- 冲动鲁莽，易与人发生冲突
- 刀刃之灾：刀伤、手术、血光之灾

### 阳刃组合应事

| 组合 | 应事 |
|------|------|
| 阳刃+七杀 | 血光横死，刀兵之灾 |
| 阳刃+劫财 | 破财、争夺、意外伤害 |
| 阳刃+正官 | 竞争压力，官非诉讼 |
| 阳刃+桃花 | 情感纠纷，刀光剑影 |
| 阳刃逢冲 | 血光重重，必见开刀手术 |

### 阳刃化解
1. 有印制刃：印星能化阳刃凶性，转凶为权
2. 官杀制刃：正官七杀克制阳刃，转为权威
3. 阳刃+桃花化解：放阳刃方向摆放金属刀剪（刀口朝下）

## 五、桃花煞（咸池）

> 断语来源：第十八节课将军箭与阎罗关

### 桃花查法
- 申子辰在酉（年支见酉为桃花）
- 寅午戌在卯
- 巳酉丑在午
- 亥卯未在子

### 桃花特质
- 异性缘佳，魅力强
- 性爱开放，感情丰富
- 爱美爱打扮，善于社交
- 桃花过旺则：色情成瘾，感情混乱

### 桃花类型与应事

| 类型 | 特征 | 风险 |
|------|------|------|
| 墙内桃花（子午卯酉日支） | 婚姻内的浪漫，情感加分 | 低 |
| 墙外桃花（他柱见桃花） | 易有婚外情 | 中 |
| 桃花+沐浴 | 性观念开放浪漫 | 中 |
| 桃花+劫财 | 三角关系，情感纠纷 | 高 |
| 桃花+七杀 | 为情受伤，妇科/男科疾病 | 高 |
| 桃花+空亡 | 感情虚无，聚少离多 | 中 |

### 桃花化解
1. 桃花为忌：摆放金属葫芦收桃花
2. 桃花过旺：床头放仙人掌或桃木剑
3. 桃花+感情纠纷：床头放一杯盐水

## 六、孤鸾煞（孤独婚姻煞）

> 断语来源：第十八节课将军箭与阎罗关

### 孤鸾煞查法
日柱为以下八个之一：乙巳、丁巳、辛亥、戊申、壬寅、戊午、壬子、丙午

### 孤鸾煞特质
- 婚姻孤独，配偶关系疏离
- 性爱冷淡，缺乏亲密感
- 自我意识强，不善妥协
- 孤芳自赏，难以与人深交

### 孤鸾煞组合应事

| 组合 | 应事 |
|------|------|
| 孤鸾+寡宿 | 孤独终老，难有伴侣 |
| 孤鸾+阴阳差错 | 婚姻反复，离合不定 |
| 孤鸾+比劫 | 配偶被夺或争夺配偶 |
| 孤鸾+空亡 | 婚姻有名无实，聚少离多 |

### 孤鸾化解
1. 晚婚（28岁后）避早年冲动
2. 夫妻宫合星化解：找日支相合的伴侣
3. 床头放夫妻合照或红绳

## 七、寡宿（孤独之煞）

> 断语来源：第十八节课将军箭与阎罗关

### 寡宿查法
- 男命：年支见亥为寡宿
- 女命：年支见丑为寡宿
- 完整：寅卯辰见巳，巳午未见申，申酉戌见亥，亥子丑见寅

### 寡宿特质
- 独立孤僻，不善社交
- 喜欢独处，不依赖他人
- 婚姻缘分薄，晚婚或不婚
- 晚年孤独，子女缘分浅

### 寡宿组合应事

| 组合 | 应事 |
|------|------|
| 寡宿+孤辰 | 极度孤独，无伴侣缘分 |
| 寡宿+华盖 | 性近僧道，清高孤独 |
| 寡宿+桃花 | 表面热情，内心孤独 |
| 寡宿+空亡 | 孤独加重，可能独居 |

### 寡宿化解
1. 多参加社交活动，主动扩大交际圈
2. 住宅朝南，保持阳光充足
3. 床头放合照或邀请朋友来家聚会

## 十二，神煞实战应用

**组合原则：**
- 吉+吉 = 大吉（天乙+文昌→学业事业双丰收）
- 吉+凶 = 中和（天乙+羊刃→有贵人化灾）
- 凶+凶 = 大凶（羊刃+劫煞→血光破财）
- 用神优先：神煞为用神则吉，为忌神则凶

## 十三、28式健康篇完整断语

> 断语来源：理华千山派28式·健康篇

| 断语 | 含义 |
|------|------|
| 羊刃逢冲，血光重重 | 阳刃被冲克，主刀伤、血光、手术 |
| 枭神夺食，病死之虞 | 偏印克食神，主重病甚至死亡 |
| 伤官挂了角（年时干为伤官），不瘤腿就跛脚 | 年柱和时柱天干同时为伤官，主肢体伤残 |
| 柱见酉、亥，短寿 | 八字地支见酉金和亥水，且无制化，主寿命短 |
| 辰、午、酉、亥全，自刑性烈 | 四柱同时见辰午酉亥，自刑引发官非重病，防寿夭 |
| 戊甲克重，头面伤 | 戊土和甲木相克，且无化解，主头面部受伤 |
| 丙丁多者，头发稀 | 丙丁火旺而无制，主头发稀疏或秃顶 |

### 28式健康篇速记口诀
```
羊刃逢冲血光来，枭神夺食病难逃
伤官挂角肢体残，酉亥齐聚寿命短
辰午酉亥自刑凶，戊甲相克头面伤
丙丁过旺头发稀，岁运引发防灾殃
```
