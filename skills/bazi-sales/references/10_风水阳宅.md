# 风水 · 阳宅

---

## 一、八字看阳宅核心原理

> 断语来源：第二十五节课

- 八字是内因（基因），风水是外因（环境）
- 通过八字可断先天风水，调后天风水
- 核心：五行平衡

**对应关系：**
- 天干 → 主外部环境（前方、表面）
- 地支 → 主内部环境（居住、睡眠）
- 宫位 → 定方位

## 四、床下物品预测

> 断语来源：第十七节课·床下物品全解

### 核心理论
- 床下属卧室私密空间 → 对应日支（夫妻宫）与时支
- 地支主藏 → 对应床下等隐蔽空间
- 旺衰主导 → 命局中旺相的五行/十神，代表床下物品主要类型

### 实战五步法

**第一步：** 定位核心宫位（日支 + 时支为主）
**第二步：** 分析五行旺衰 → 确定物品主要类型
**第三步：** 解读十神意象 → 判断藏物动机与物品功能

**第五步：** 参考神煞暗示 → 补充物品特殊属性

## 六、婚姻风水关联

> 断语来源：第二十五节课

| 日柱状态 | 婚姻风水判断 | 调整建议 |
|----------|------------|----------|
| 日柱为喜用+无冲克 | 夫妻房风水佳，婚姻稳定 | 保持现状 |
| 日柱为忌神+天克地冲 | 夫妻房风水差，必应婚姻危机 | 调整床位，避免正对门口 |
| 日支被穿/冲 | 配偶健康出问题，或夫妻分房睡 | 床头朝向喜用神方向 |
| 日支藏喜用 | 配偶带来好风水，助事业财运 | 善用配偶优势 |
| 日柱空亡 | 夫妻缘分较薄，中年易有波动 | 床头放合和符或贵人照片 |

### 婚姻风水速查

| 问题 | 风水原因 | 化解方法 |
|------|----------|----------|
| 婚姻不稳定 | 床对门口/厕所 | 调整床位 |
| 配偶健康差 | 日支被刑冲克害 | 床头朝向喜用神方向 |

## 八、八字断风水三步骤

> 断语来源：第二十五节课

### 步骤1：八字基础分析
1. 排盘定四柱、大运流年
2. 分析五行旺衰（找出过旺、过弱五行）
3. 确定喜用神与忌神（风水调整的唯一标准）
4. 标记关键刑冲合害（找出风水隐患点）

### 步骤2：风水信息解读
1. 宫位断法：看各宫位旺衰与喜忌→断对应区域风水吉凶
2. 五行断法：某五行过旺→对应方位有问题（如木旺→东方有高楼）；某五行过弱→对应方位缺失（如水弱→北方无水源）
3. 十神断法：印星→学业/母亲/房屋质量；财星→财运/妻子/厨房；官杀→事业/丈夫/外部压力
4. 干支组合断法：天克地冲→对应方位有剧烈变动；三合局→对应方位有良性组合

### 步骤3：风水调整方案
1. 方位调整：喜木住东/东南房；喜火住南房；喜金住西/西北房；喜水住北房；喜土住中央/西南/东北房
2. 环境布局：补喜用神，泄忌神
3. 细节优化：最旺地支为最佳睡眠方位；忌神旺方位避免做主卧/书房

### 避坑指南
1. **误区一：风水能改命** → 真相：风水只能调整运势，无法改变八字格局（如苹果树无法变梨树）
2. **误区二：只看方位不看喜忌** → 真相：同一方位对不同八字吉凶不同（如南方火位对火旺者为凶）
3. **误区三：只调外部不调内部** → 真相：地支（内部环境）影响更直接（如卧室风水比客厅重要）
4. **误区四：频繁调整风水** → 真相：风水调整以稳定为主，岁运变化时再微调
