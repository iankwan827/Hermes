# 经验教训记录

## 2024年经验

### 这次模拟的经验（19870912男命）

1. **必须先确认排盘** - 生成断语后，先让客户确认四柱排盘是否正确，再进行下一步

2. **校准要分多次** - 每次只发一段话，等客户确认"是"后再发下一段，不要一次发太多

3. **从断语出发** - 每次说话都要从客户的断语文档里选信息，不是照搬模板案例

4. **用第一人称体验** - 说"你是不是..."让客户自己对照，不是说"你是这样的人"

5. **加具体例子** - "路上看到不公平的事"、"认理不认人"，让客户能联系实际

6. **不要直接问问题** - 不要问"你做什么工作"，而是根据断语推测说出

7. **说信息等回应** - 说出断语信息让客户确认，等客户在回复中透露断语里没有的新信息

8. **信任度判断** - 客户说"是的""对" = 信任度高，可以深入；客户态度冷淡 = 继续校准

9. **客户纠正要听** - 客户说"不是这样"或者有其他反馈，要及时调整

10. **客户纠正话术** - 当客户纠正你的话术时，说明关系已经很亲近，信任度很高
