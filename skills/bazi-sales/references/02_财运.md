# 财运

---

## 核心逻辑

八字看财运以 **日主强弱 + 财星状态 + 财库动静 + 食伤生财 + 岁运引动** 为五大支柱，高应验率集中在"身财平衡、财库冲开、食伤生财、岁运财旺"等组合。

---

## 一、财星基础概念

### 正财与偏财

| 类型 | 定义 | 代表含义 |
|------|------|---------|
| **正财** | 日主所克的异性五行（如甲木克己土） | 稳定收入、工资薪水、固定资产、正当职业 |
| **偏财** | 日主所克的同性五行（如甲木克戊土） | 意外之财、投资收益、奖金红利、副业收入 |

> 财星为日主"所掌控之物"，正财主稳定，偏财主变动，两者共同构成财富体系。

### 日主与财星的关系

| 关系类型 | 断语原文 | 白话解释 | 应验率 |
|---------|---------|---------|--------|
| 身强财旺 | 身强财旺，富贵自来 | 日主能量充足，能承受大量财富，容易富贵 | 95% |
| 身弱财多 | 身弱财多，富屋贫人 | 日主能量不足，承受不了太多财富，看似富有实则贫困 | 90% |
| 身财两停 | 身财两停，一生富足 | 日主与财星能量平衡，财富与能力匹配，一生富足 | 95% |
| 财星无根 | 财星无根，虚浮不实 | 财星没有地支根基，财富来得快去得也快，难积累 | 90% |
| 财星有根 | 财星有根，财源稳定 | 财星有地支本气或余气，财富来源稳定，容易积累 | 95% |

### 财库（蓄财关键）

四大财库：辰（水库）、戌（火库）、丑（金库）、未（木库），为财星的"储存容器"。

**核心断语：**
- 财有库，发则能存；财库冲开，大发其财；财库重叠，富可敌国
- 命带财库能留住财富，岁运冲开财库时会爆发财富；财库多则储存能力强，容易成为巨富

## 二、财运分析步骤

### 第一步：排盘定财星（应验率 100%）

1. 排出八字命盘，确定日主（出生日天干）
2. 找出正财、偏财（日主所克的五行）
3. 标注财星位置（年柱、月柱、日柱、时柱）

| 财星位置 | 含义 |
|---------|------|
| 年柱财星 | 祖上有财，少年得财 |
| 月柱财星 | 青年得财，事业顺利 |
| 日柱财星 | 中年得财，婚姻带财 |
| 时柱财星 | 晚年得财，子女有财 |

### 第二步：判断日主强弱（应验率 95%）

1. 看日主得令（月令是否为日主旺地）
2. 看日主得地（地支是否有日主本气）
3. 看日主得势（天干是否有比肩劫财帮扶）
4. 综合判断：得令得地得势为身强，反之则身弱

> 日主强弱决定"担财能力"，身强能担财，身弱难担财

### 第三步：分析财星状态（应验率 90%）

1. 看财星旺衰（是否得令得地得势）
2. 看财星是否被克（比劫夺财、枭神夺食）
3. 看财星是否被合（财星被合走，难聚财）
4. 看财星是否透干藏支（透干主外露，藏支主丰厚）

**断语：** 财宜藏，藏则丰厚；财宜透，透则慷慨

### 第四步：查看财库与食伤（应验率 90%）

1. 看是否有财库（辰戌丑未），财库是否被冲开
2. 看食伤（食神伤官）是否旺相，能否生财（食伤为财源）

**断语：** 食伤生财，富贵自天来；无食无财，一生贫寒

### 第五步：结合岁运判断应期（应验率 95%）

1. 看大运是否走财旺之地（如日主为木，走土运为财旺）
2. 看流年是否引动财星或财库（如流年冲财库，当年发财）
3. 看岁运是否有比劫夺财（需防破财）

**断语：** 大运走财地，十年大发；流年冲财库，当年暴富

| 信号 | 含义 |
|------|------|
| 走财旺大运 | 十年内财富增长快，适合投资和创业 |

| 走财库大运 | 财库冲开，财富爆发，适合扩大规模 |
| 走官杀大运 | 财生官，官护财，适合职场晋升和事业发展 |

### 流年发财信号（应验率 90%）

| 信号 | 含义 |
|------|------|
| 流年冲财库 | 当年财富爆发，容易获得意外之财 |
| 流年财星旺 | 当年财运好，赚钱容易，适合积极求财 |
| 流年食伤生财 | 当年靠才华赚钱，适合开展新项目 |

### 应期判断技巧

1. 原局有财库 → 岁运冲开为应期
2. 原局食伤弱 → 岁运食伤旺为应期
3. 原局身弱 → 岁运比劫帮身为应期
4. 原局财星弱 → 岁运财星旺为应期

> **断语：** 原局有信号，岁运引动为应期

## 六、避坑指南

**问：八字无财星就一定贫穷吗？**
答：不一定！如果有食伤（财源）且旺相，依然能通过才华赚钱；如果无财无食伤，才容易贫穷。（应验率 90%）

**问：财库冲开就一定发财吗？**
答：不一定！需满足：①日主身强能担财；②财库中有财星。如果身弱或财库空亡，冲开也难发财。（应验率 90%）

**问：比劫旺就一定破财吗？**
答：不一定！如果有官星制比劫，则能化解比劫夺财的风险；如果无官星制比劫，才容易破财。（应验率 95%）

**问：偏财旺就一定适合经商吗？**
答：不一定！偏财旺且为喜用神，适合经商；如果偏财旺为忌神且无制化，容易因为投机而破财。（应验率 90%）

**问：大运走财地就一定发财吗？**
答：不一定！需结合原局和流年：①原局身强能担财；②流年引动财星或财库；③无可比劫夺财或财星被合。（应验率 90%）

**问：如何判断财富层级？**
答：看三点：①财星旺衰（旺则财富多）；②财库数量（多则储存能力强）；③食伤生财力度（强则财源广）。三者皆强则为巨富，一强两弱则为小富，三者皆弱则为贫穷。（应验率 90%）

## 七、理财建议

| 类型 | 建议 |
|------|------|
| 财星为用，旺相透干 | 理财观念好，宜稳扎稳打积累，适合长期投资 |
| 比劫旺而无制 | 不宜冒险投资，守成为主，避免与他人合伙 |
| 财星虚浮无根 | 非爆发型，宜长期定投，不宜追求快钱 |
| 食伤生财格 | 适合靠技艺、创意赚钱，宜发展副业或自由职业 |
| 从财格 | 适合商业投资，宜把握运势扩张规模 |

## 八、核心口诀

> 身强财旺富贵来，身弱财多反为灾；
> 财有库，发则能存，财库冲开富贵来；
> 食伤生财财源广，比劫夺财破财快；
> 正财稳定偏财动，经商投资看偏财；
> 大运财旺十年富，流年冲库当年发；
> 八字无财看食伤，食伤旺相也发财。
