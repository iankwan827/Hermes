## 一、两头挂命理断语

> 断语来源：第五节课

两头挂 = 年干和时干出现同一十神

| 十神 | 断语 |
|------|------|
| 正印/偏印 | 印绶两头挂，必定慈善人 |
| 伤官 | 伤官两头挂，亲情剩不下 |
| 食神 | 食神两头挂，吃喝走天下 |
| 七杀 | 七杀两头挂，到老无后/官非定无后 |
| 偏财/正财 | 财星两头挂，慷慨离家人 |
| 比肩/劫财 | 比劫两头挂，损财是非来 |
| 正官 | 正官两头挂，富贵又绵长 |
| 偏印（枭神） | 枭神两头挂，寡言人狡诈 |

### 重点解读

**正印两头挂：** 善良慈祥，有爱心，责任感强，气质清雅；女性异性缘好但婚姻可能不顺（因印克食伤，不利子息）；适合文化、教育、宗教、慈善等领域；好古、好文艺、好易学、好医学，易离群索居

**伤官两头挂：** 聪明伶俐，口才好，思维敏捷，但易伤亲人，言辞犀利；女性婚姻不顺，难有稳定伴侣；与家人缘分薄

**七杀两头挂：** 一生多灾多难，易招官非诉讼，事业起伏大；子嗣困难；性格刚毅果决，但易冲动树敌

**食神两头挂：** 一生口福好，能吃百家饭，技艺精湛；善于社交，走到哪里都受欢迎；适合餐饮、厨艺、娱乐、表演等行业

**财星两头挂：** 慷慨大方，不吝啬钱财，乐于助人，但也易破财；可能远离家乡发展；男性偏财易贪恋女色，女性偏财易成第三者

**比劫两头挂：** 财来财去，难以积累，易因朋友或合伙破财；身边小人多，易招口舌是非，与人竞争激烈；与兄弟姐妹缘分薄

**正官两头挂：** 事业稳定，福禄长久，社会地位高

### 速记口诀

> 印绶慈善人，伤官亲情疏；
> 食神吃天下，七杀灾无后；
> 财星慷慨离，比劫是非来；
> 正官富贵久，枭神多计谋。

## 二、十干日元性格

### 甲木（阳木）
> 断语来源：第八节课

- **核心意象**：参天大树，向阳生长，代表着生机勃勃的开拓精神与向上的生命力。
- **性格描述**：甲木人如同森林中的参天大树，生来带有仁慈与正直的骨气。正面而言，他们拥有极强的恒心与毅力，认定的目标往往会不折不扣地执行到底，行事刚强正直，富有责任感与领导风范。然而，过于坚硬的特质也是他们的双刃剑，负面表现为固执己见，不愿听从他人劝告，在逆境中因不服输而显得"宁折不弯"，即便面对挫折也常常不懂示弱，容易导致人际关系上的僵局或因自我施压过大而陷入困境。
- **人生方向**：适合从事行政管理、建筑工程、教育或大型企划，需要独立决策且能发挥其开拓领导能力的角色。
- **代表情境**：一位在职场中坚持原创理念、即便面对上级压力也不愿修改方案的部门主官，其骨子里的傲气与担当正是甲木的写照。

### 乙木（阴木）
> 断语来源：第八节课

- **核心意象**：藤萝花草，柔韧弯曲，象征着在环境中寻求平衡与发展的智慧。
- **性格描述**：乙木如同花草藤蔓，能够轻易地在缝隙中生长。正面看，他们具备极强的环境适应力，性格温柔变通，擅长以柔克刚，情感细腻且洞察力强，能够敏锐地捕捉他人情绪，是天生的外交家。然而，过度依赖环境或外界支持是其弱点，负面表现为性格上的优柔寡断，面对决策时容易受到他人干扰，由于过度关注细节而显得敏感多疑，在缺乏安全感时极易产生依赖心理，难以独立支撑大局。
- **人生方向**：非常适合从事文案策划、艺术设计、销售咨询或各类需要沟通协调的服务性行业。
- **代表情境**：在复杂职场中游刃有余、总能化解同事矛盾的协调者，乙木人展现出的"以退为进"恰是其核心竞争力。

### 丙火（阳火）
> 断语来源：第十二节课

- **核心意象**：太阳之火，热烈光明，代表着普照大地、给予温暖的能量释放。
- **性格描述**：丙火人如炽热太阳，个性开朗、坦率且充满活力。正面而言，他们是人群中的焦点，积极主动，拥有极强的感染力与领导才能，做事讲究效率，光明磊落，不屑于背后算计。但其负面特质也源于火的燥热，往往表现为性格暴烈、急躁，做事缺乏耐心，容易在冲动之下作出决定，且由于热情过盛，有时会不自觉地忽略他人的感受，言语犀利或行事鲁莽，容易在职场或家庭中引发无谓的冲突。
- **人生方向**：适合进入公关传播、市场营销、演艺行业或任何需要展现个人魅力的舞台，其热度能迅速带动团队氛围。
- **代表情境**：在团队中大声呼吁、鼓舞士气的主管，即便工作进程受阻也能第一时间爆发热情解决问题。

### 丁火（阴火）
> 断语来源：第十节课

- **核心意象**：烛火/星光，万家灯火，代表着内敛、温暖与文明的传承。
- **性格描述**：丁火如同静谧夜晚的烛光，心思缜密，温柔中蕴含着极强的坚韧。正面看，他们非常有修养，文明善感，擅长思考与内省，是团队中稳健的幕后智囊，总能在关键时刻给人提供温暖的抚慰。负面而言，丁火人内心活动极其丰富且复杂，容易变得敏感多疑，面对选择时往往犹豫不决，自我怀疑严重。由于火势微小，他们常常会感到被环境掩盖或被他人忽视，从而产生孤独感或自卑情绪。
- **人生方向**：适合从事学术研究、会计审计、艺术创作或需要深度思考与精密规划的幕后工作。
- **代表情境**：一位深夜还在认真整理方案细节、默默为团队扫除隐患的资深助手，其静默中的力量正是丁火的本质。

### 戊土（阳土）
> 断语来源：第十一节课

- **核心意象**：高山厚土，稳定包容，象征着厚德载物、不可动摇的信条。
- **性格描述**：戊土如高山，给人一种稳如泰山的安全感。正面而言，他们诚信可靠，责任感极强，遇到重大危机时总能顾全大局，是组织中最坚实的依靠，能够承载压力并协调各方矛盾。然而，厚重的特质往往也带来了负面影响，他们过于固执守旧，缺乏灵活变通的机动性，容易陷入思维定势，对于新事物或突发情况往往反应缓慢，这种"安稳至上"的哲学有时会阻碍个人与团队的发展空间。
- **人生方向**：适合从事金融投资、建筑不动产、行政监管或法务工作，这些领域需要极高的稳定性与原则性。
- **代表情境**：一个公司里工作了十年、被同事公认为"靠谱先生"的管理者，面对市场波动时坚持按原则办事，这就是戊土的坚持。

### 己土（阴土）
> 断语来源：第十一节课

- **核心意象**：田园之土，滋养万物，代表着勤劳耕耘、平实稳重。
- **性格描述**：己土是良田之土，具有极强的包容性与忍耐力。正面看，他们务实勤奋，懂得在平凡中积累，能够通过调和人际关系来促成合作，性格平和，不争强好胜。但这种过度的温和也容易导致性格中的矛盾，负面表现为内心复杂、反复纠结，虽然勤劳但往往缺乏决断力，难以在关键时刻果敢出击。他们容易被细节牵绊，从而错失良机，常常在"要不要改变"之间陷入长期的自我消耗。
- **人生方向**：适合从事财务、农业、仓储、护理或任何需要精细维护与长期积累的行业。
- **代表情境**：一个在团队中默默耕耘、总是能把琐事处理得井井有条，但却迟迟不敢主动申请升迁的资深职员。

### 庚金（阳金）
> 断语来源：第十二节课

- **核心意象**：刀剑之金，刚健锐利，代表着破旧立新、斩断阻碍的魄力。
- **性格描述**：庚金人如同精钢利刃，刚毅果断。正面而言，他们拥有极强的行动力与正义感，遇到不平之事敢于发声，在事业上敢拼敢闯，具备大刀阔斧的革新能力，是天生的先锋者。但这种锐气也容易演变成负面表现，即刚愎自用，认为只有自己的路径才是对的。他们言辞犀利，说话常常不留情面，好胜心极强，容易与周围人产生摩擦，显得过分冷酷或强硬，缺乏圆融之道。
- **人生方向**：适合军警、司法、工程技术、刀刃行业或任何需要高执行力与竞争力的领导职位。
- **代表情境**：一位在企业重组中大刀阔斧裁撤低效部门、不论同事舆论如何坚持执行变革的职业经理人。

### 辛金（阴金）
> 断语来源：第十二节课

- **核心意象**：珠玉之金，精致珍贵，代表着对完美与品质的极致追求。
- **性格描述**：辛金如同华贵的珠宝，细腻敏锐，气质脱俗。正面看，他们拥有过人的审美眼光，对生活品质要求极高，行事风格文雅、精致，在复杂环境中总能保持优雅。然而，这种追求完美的性格在负面表现中极为突出，往往变得挑剔计较，眼里容不得沙子。由于内心敏感，他们极易被他人的评价所伤，对外界压力反应剧烈，容易陷入自我怀疑，对他人的过失也难以宽容。
- **人生方向**：适合艺术鉴赏、高端时尚、珠宝设计、美容整形或各类创意行业。
- **代表情境**：一名对成品细节要求近乎苛刻、为了一个像素的偏差可以反复修改多次的顶尖设计师，是辛金人的典型写照。

### 壬水（阳水）
> 断语来源：第十四节课

- **核心意象**：江河湖海，奔腾不息，象征着广阔的智谋与无限的可能性。
- **性格描述**：壬水人如同江河，胸怀宽广，思维极其活跃。正面而言，他们聪明睿智，反应极快，具备洞察大趋势的能力，在困难面前能够迅速找到解决路径，行事勇敢果断，不被困境束缚。然而，由于水性流动，负面表现为容易冲动鲁莽，心性不稳定，常常"三分钟热度"，因为缺乏长期的耐心，往往在项目临近成功时因产生厌倦而放弃，导致前期积累前功尽弃。
- **人生方向**：适合商业拓展、互联网贸易、物流航运或任何需要动态判断与大格局布局的行业。
- **代表情境**：一个能够敏锐捕捉行业风口、迅速创立新项目并快速实现扩张的创业者，其奔腾的思维与勇气即是壬水表现。

### 癸水（阴水）
> 断语来源：第十五节课

- **核心意象**：雨露晨雾，至柔至弱，代表着润物无声、深沉细腻的潜能。
- **性格描述**：癸水如春雨，看似柔弱，实则蕴含极强的渗透力。正面而言，他们聪明睿智，情感世界异常丰富，擅长观察与潜伏，行事温和却有韧性，能够在不经意间解决复杂问题。但负面特征在于其多愁善感，过度的思考导致优柔寡断，面对压力时容易退缩。由于心思过于敏感多疑，他们常常会对环境产生不信任感，导致错失表达自我的良机，难以走出内心封闭的角落。
- **人生方向**：适合从事心理咨询、情报分析、艺术文学、研究类工作或需要暗中运作的统筹角色。
- **代表情境**：一位总是能敏锐洞察同事内心需求、在背后默默解决人际纷争的贴心伙伴，其无声的力量正是癸水特征。

## 四、日支十神性格

> 断语来源：第十五节课·日支十神

日支为夫妻宫，代表配偶的性格与相处模式。日支坐不同十神，呈现截然不同的性格特征：

| 日支十神 | 性格特征 |
|----------|----------|
| **日坐正官** | 责任心强，注重规矩，有社会地位观念；温和自律，尊重传统，但有时过于保守 |
| **日坐七杀** | 有魄力，敢闯敢拼，执行力强；脾气急躁，控制欲强，容易冲动 |
| **日坐正印** | 善良包容，学历高，有爱心；依赖性强，不善表达，有时过于保守 |
| **日坐偏印** | 心思细腻，第六感强，有专长；多疑敏感，性格偏执，缺乏热情 |
| **日坐食神** | 乐观开朗，口福好，才华横溢；不争名利，自由散漫，缺乏上进心 |
| **日坐伤官** | 聪明伶俐，表达能力强，有创新精神；叛逆不服管，口无遮拦，易得罪人 |
| **日坐正财** | 务实稳重，重视家庭，理财观念强；小气计较，缺乏浪漫，有时过于现实 |
| **日坐偏财** | 慷慨大方，社交能力强，善于投资；花钱大手脚，感情易有波折 |
| **日坐比肩** | 独立自主，意志坚强，伙伴意识强；固执己见，竞争心强，合伙易有纷争 |
| **日坐劫财** | 勇敢果断，有魄力，敢于冒险；冲动好斗，口舌是非多，财务易有纠纷 |

### 速记口诀
```

正印善良太保守，偏印多疑心思细

正财务实重家庭，偏财慷慨花不停
比肩独立意志坚，劫财冲动好斗争
```

## 五、年干与时干的内外性格
> 断语来源：第四节课·断事实操流程

**核心原理：**
- **年干** = 内心世界，藏着真实的自己（不易外显的内在性格）
- **时干** = 外在表现，呈现给外人的样子（社交中展现的一面）

**判断方法：** 年干/时干落在哪个十神，就直接查该十神的性格含义。

| 十神 | 年干（内在性格） | 时干（外在表现） |
|---|---|---|
| **正印** | 内心善良包容，依赖性强，不善表达 | 表面温和有爱心，给人可靠感 |
| **偏印** | 内心多疑敏感，有隐秘想法 | 表面独立有个性，略显冷漠 |
| **食神** | 内心乐观享乐，追求自在 | 表面开朗随和，人缘好 |
| **伤官** | 内心叛逆不服，聪明敏感 | 表面言辞犀利，不喜约束 |
| **正财** | 内心务实计较，重实际 | 表面稳重顾家，善于理财 |
| **偏财** | 内心慷慨大方，渴望新鲜 | 表面社交活跃，出手阔绰 |
| **正官** | 内心自律守规，有责任感 | 表面稳重靠谱，受人信任 |
| **七杀** | 内心有魄力，急躁易怒 | 表面果断强势，有威严感 |
| **比肩** | 内心独立自主，不愿求人 | 表面平等随和，不喜争斗 |
| **劫财** | 内心争强好胜，占有欲强 | 表面直接坦率，行动力强 |

**十神性格参照：** 各十神详细性格定义见本章第二节「十干日元性格」。

**举例：**
- 年干七杀 + 时干正印 → 内心：有魄力但脾气急；外在：温和有爱心
- 年干食神 + 时干劫财 → 内心：乐观享乐；外在：争强好胜
- 年干正官 + 时干伤官 → 内心：守规矩有责任感；外在：不羁有创意
