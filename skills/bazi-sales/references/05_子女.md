## 一、子女星与子女宫

> 断语来源：第二十四节课

**男命：** 正官 = 女儿，七杀 = 儿子
**女命：** 食神 = 女儿，伤官 = 儿子

**子女宫 = 时柱**
- 时干 → 长子长女外在表现
- 时支 → 次子次女内在性格

## 二、子女缘分判断

### 星宫同旺
> 子女星旺相 + 子女宫为喜用神 → 子女优秀孝顺，晚年幸福

### 星宫相克
> 子女星与子女宫刑冲克害 → 缘分薄，关系不和睦

### 星宫空亡
> 子女星或子女宫空亡 → 子女可能夭折、流产，或聚少离多

## 七、优生优育

> 断语来源：第二十四节课

### 最佳生育年龄

| 命格 | 最佳生育年龄段 | 说明 |
|------|--------------|------|
| 食伤旺相（女命） | 23-30岁 | 食伤为子女星，旺则子女健康；30岁前生育质量最佳 |
| 官杀清（男命） | 28-35岁 | 官杀为子女星，清纯有力；子女优秀 |
| 印星过旺（男女命） | 30-38岁 | 印星克食伤/官杀，早年易流产；晚育可规避 |
| 子女宫为喜用 | 25-33岁 | 子女宫为喜用神，子女缘分好；此阶段生育子女孝顺 |

### 孕前调理建议

| 八字特征 | 调理方向 |
|----------|----------|
| 印星旺克食伤（女命） | 补气血，暖宫驱寒；少吃生冷食物 |
| 官杀旺克食伤（女命） | 疏肝解郁，调理气血；保持心情舒畅 |
| 日坐阳刃（男女命） | 孕前检查子宫/前列腺；注意安胎 |
| 子女宫空亡 | 备孕期间积德行善；床头放贵人照片 |

### 剖腹产选择

| 命格特征 | 建议 | 原因 |
|----------|------|------|
| 日坐阳刃+子午卯酉冲 | 倾向剖腹产 | 胎位不正概率高，剖腹产可避开冲克 |
| 子女宫逢冲+克 | 考虑剖腹产 | 顺产风险大，剖腹产可择时避开凶时 |
| 羊刃重重+无制化 | 建议剖腹产 | 产厄风险高，择时生产更安全 |
| 食伤旺+无刑冲 | 可顺产 | 子女缘分好，产程顺利 |

### 择时生产原则
- 尽量避开与命局形成天克地冲的时辰
- 选择子女宫为喜用神的时辰
- 避开三刑（寅巳申、丑未戌）、六冲（子午、卯酉等）时辰
