## 一、身材好坏判断

> 断语来源：第九节课

### 五行与身材

| 五行 | 旺 | 弱/过旺 |
|------|-----|---------|
| 木 | 身高偏高，四肢修长 | 身高偏矮，四肢纤细 |
| 土 | 体型丰满（燥土=壮实，湿土=虚胖） | 偏瘦，脾胃弱 |
| 火 | 体型紧致不松散 | 过旺则偏瘦；过弱则松散无型 |
| 金 | 身材挺拔，骨骼清晰 | 偏瘦或佝偻 |
| 水 | 体型圆润有肉，皮肤细腻 | 虚胖（水肿）或干瘪 |

### 十神与身材

**好身材：**
- 食神旺 → 心宽体胖，三围饱满
- 正印旺为用 → 体型匀称
- 财星旺为用 → 肌肉结实

**差身材：**
- 枭神夺食 → 消化差，体型干瘪
- 伤官过旺 → 体型纤瘦
- 官杀过旺身弱 → 偏瘦，精神差

## 四、肝胆健康（丁火系统）

> 断语来源：第十节课·丁火详解

### 高风险组合
- 金木交战（庚甲透干+申卯冲）→ 肝硬化、肝损伤
- 火多木焚（丙丁火多+木弱无水）→ 肝炎、肝癌
- 水多木漂（水旺+木弱无根）→ 肝腹水
- 木旺无泄 → 脂肪肝、情绪病

### 低风险组合
- 木气适中+火适度泄 → 肝疏泄正常
- 木弱有水扶 → 肝气虚但无损伤

## 六，女性健康：流产/剖腹产

> 断语来源：第十一节课·戊土详解

### 核心标志：阳刃

**日坐阳刃（应验率90%+）**
日柱为丙午、丁巳、戊午、己巳、壬子、癸亥 → 子宫刀伤风险极高，易刮宫/流产/剖腹产

**时坐阳刃（应验率80%+）**
时柱地支为阳刃 → 子女宫带刀，流产几率大，剖腹产可能性高

**日时双阳刃（应验率95%+）**
日时同时见阳刃 → "日时双阳刃，必生产厄"，非流产即剖腹产

### 倾向判断

**倾向流产：** 日坐阳刃 + 无官杀克制 → 易流产难保胎

**倾向剖腹产：** 日坐阳刃 + 有官杀克制；日时卯酉/子午冲 → 胎位不正，必剖腹产

### 速记口诀
> 日坐阳刃子宫伤，时带阳刃产见刀
> 日时双刃叠，必定生产厄

## 十、胃病判断

> 断语来源：第八节课

### 胃病高风险组合（9种类型）

| 序号 | 组合 | 胃病类型 | 表现 |
|------|------|----------|------|
| 1 | 土旺或土弱 | 胃病 | 脾胃功能失调 |
| 2 | 木旺土弱 | 胃病 | 肝气犯胃，消化不良 |
| 3 | 土弱金旺 | 伤胃 | 肺金过旺克脾胃 |
| 4 | 水多土荡 | 胃病、胃出血 | 土气被水冲散 |
| 5 | 辰戌土被它支合化成别的五行 | 胃炎 | 土气被转化 |
| 6 | 辰戌相冲 | 胃受伤 | 外伤导致胃损伤 |
| 7 | 戊土弱，得旺火生，火多土焦 | 胃炎、胃溃疡 | 热证胃病 |
| 8 | 柱中水多而旺，土与火弱 | 胃炎、胃下垂 | 湿气重、胃动力不足 |
| 9 | 戊土弱遭木局克破 | 刀伤之灾，易因胃病或其它病开刀 | 需外科手术 |

### 胃病调理建议

| 胃病类型 | 调理方向 |
|----------|----------|
| 土旺无制 | 疏肝理气，少吃辛辣油炸 |
| 木旺克土 | 疏肝和胃，多吃绿色蔬菜（养肝） |
| 土弱金旺 | 健脾补肺，少吃生冷 |
| 水多土荡 | 健脾祛湿，少喝水、少吃水果 |
| 火多土焦 | 清热降火，多吃清淡食物 |
| 戊土弱遭木克 | 补火暖胃，少吃寒凉 |

## 十一、肾功能/肾病

> 断语来源：第九节课

### 高风险肾病组合

| 类型 | 特征 | 肾病表现 | 风险等级 |
|------|------|----------|----------|
| **土旺克水型** | 戊己土旺，壬癸水弱，无木疏通 | 肾炎、肾功能下降，严重者肾衰竭 | 极高 |
| **水弱火旺型** | 壬癸水少，丙丁火多，尤其水生于夏 | 肾阴虚、泌尿系统感染 | 高 |
| **水寒金冷型** | 壬癸水旺但寒，尤其冬月生，庚辛金旺 | 肾阳虚、慢性肾病 | 中高 |
| **金多水浊型** | 庚辛金旺，壬癸水相对较弱 | 肾结石、膀胱结石 | 中高 |
| **水旺无木型** | 壬癸水旺，缺甲乙木疏通 | 泌尿系统功能紊乱 | 中 |
| **水气虚耗型** | 壬癸水不弱但被耗泄过多 | 肾气不足、易疲劳，腰膝酸软 | 中 |

### 肾病判断核心口诀
```
水主肾兮癸水藏，膀胱壬水应端详
水旺肾寒尿频数，水弱肾虚腰膝伤
土旺克水肾必损，火旺水涸阴虚彰
金多水浊生结石，木旺水亏糖尿病
```

### 肾功能保护建议

| 体质类型 | 保护方法 |
|----------|----------|
| 土旺克水 | 健脾化湿（茯苓、薏米）；酉时（17-19点）养肾 |
| 水弱火旺 | 滋阴补肾（枸杞、熟地）；少吃辛辣 |
| 水寒金冷 | 温补肾阳（羊肉、桂圆）；冬季重点保暖 |
| 金多水浊 | 清热利湿（冬瓜、赤小豆）；少吃高嘌呤食物 |

## 十三、宫位与健康

> 断语来源：第十三节课

### 年柱（祖辈/早年）与健康

| 年柱状态 | 健康关联 |
|----------|----------|
| 年柱被冲克 | 祖辈健康问题或遗传疾病倾向 |
| 年柱纳音被月柱纳音克 | 祖辈有健康问题遗传 |
| 年柱为忌神 | 早年体质差，易生病 |
| 年柱为喜用神 | 早年身体健康，精力充沛 |

**健康预警：** 年柱被冲克的五行，对应脏腑在早年（0-30岁）需重点关注

### 日柱（自身/中年）与健康

| 日柱状态 | 健康关联 |
|----------|----------|
| 日柱被冲克 | 自身健康在中年（30-50岁）易出问题 |
| 日支被穿害 | 内脏器官慢性疾病，尤其夫妻宫对应脏腑 |
| 日柱为忌神 | 中年压力大，易有身心疾病 |
| 日柱为喜用神 | 中年身体健康，事业顺利 |

**健康预警：** 日柱被冲克时，流年再冲→突发疾病或意外；夫妻宫脏腑对应需警惕

### 时柱（子女/晚年）与健康

| 时柱状态 | 健康关联 |
|----------|----------|
| 时柱被冲克 | 晚年（50岁后）健康出问题，子女也有健康隐患 |
| 时支为墓绝 | 晚年体力差，慢性病缠身 |
| 时柱为喜用神 | 晚年子女孝顺，身体尚可 |
| 时柱空亡 | 与子女健康缘分薄，或子女体弱 |

**健康预警：** 时柱为凶神且被冲→晚年手术或意外风险高

### 宫位健康应期速查

| 宫位 | 年龄段 | 被冲克时的健康预警 |
|------|--------|-------------------|
| 年柱 | 0-30岁 | 早年遗传疾病、体质差 |
| 月柱 | 15-40岁 | 青年期消化/肝胆/胸肺问题 |
| 日柱 | 30-50岁 | 中年内脏/夫妻宫对应脏腑问题 |
| 时柱 | 50岁后 | 晚年下肢/泌尿/生殖系统问题 |

> **注意：** 以上为综合判断，具体疾病需结合十神+五行+地支关系综合分析
