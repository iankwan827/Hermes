# 六亲递推速查表

## 核心规则

**每一代的偏财 = 这一代的父亲，正印 = 这一代的母亲。逐层递推。**

口诀：偏财父、正印母，往上推就找它的偏财和正印。

## 推导方法

### 第一步：定直接六亲

以日主十神关系直接定父母：

```
偏财 = 父亲（我克者，同性）
正印 = 母亲（生我者，异性）
```

### 第二步：从父亲递推祖父母

找到父亲（偏财），然后看偏财本身的偏财和正印：

```
爷爷 = 父亲的偏财 = 日主的偏印
奶奶 = 父亲的正印 = 日主的伤官
```

### 第三步：从母亲递推外祖父母

找到母亲（正印），然后看正印本身的偏财和正印：

```
外公 = 母亲的偏财 = 日主的伤官
外婆 = 母亲的正印 = 日主的七杀
```

### 第四步：继续递推曾祖辈

找到爷爷（偏印），然后看偏印本身的偏财和正印：

```
曾祖父 = 爷爷的偏财 = 日主的比肩
曾祖母 = 爷爷的正印 = 日主的劫财
```

## 使用注意

1. **递推方向：** 偏财线往上推=父系祖先，正印线往上推=母系祖先
2. **男命女命差异：** 以上表格为男命。女命的子女星互换（伤官=儿子，食神=女儿；七杀=女儿，正官=儿子），夫妻星也互换（正财=丈夫，偏财=情人）
3. **六亲在原局的位置：** 年柱=祖上/长辈，月柱=父母/兄弟，日支=配偶，时柱=子女
4. **六亲星在原局的状态：** 旺/衰/有根/无根/入墓/空亡，决定了这个六亲的强弱
5. **岁运对六亲的影响：** 当岁运克、冲、刑某六亲星时，该六亲有灾；当岁运生扶某六亲星时，该六亲有喜
6. **六亲生死判断：** 不能单看十神，需结合：六亲星是否入墓逢冲、所坐之柱是否被天克地冲、岁运是否同时克该六亲星且无解救
