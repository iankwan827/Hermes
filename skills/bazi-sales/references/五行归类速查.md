# 五行归类速查

> 分析八字时，先搞清楚事物属什么五行，再套五行生克

## 常见事物五行归类

| 五行 | 属于这个五行的事物 |
|------|-------------------|
| 金 | 黄金、贵金属、金属、**股票、金融、银行、保险、理财**、白色、西方、秋天、肺、大肠、骨骼、牙齿 |
| 木 | 股市指数（部分说法）、植物、木材、家具、绿色、东方、春天、肝、胆、筋、眼睛 |
| 水 | 水利、航运、物流、酒水、饮料、黑色、北方、冬天、肾、膀胱、耳、血液 |
| 火 | 电子、能源、电力、互联网、科技、红色、南方、夏天、心、小肠、舌、眼睛 |
| 土 | 房地产、农业、建筑、陶瓷、黄色、中央、长夏、脾胃、肌肉、嘴唇 |

## ⚠️ 常见误区

- **股票/金融 = 金**（不是木！）
  - 火克金 → 所以火旺年份金价跌、金融板块跌、A股跌
  - 不是"金克木导致股市跌"
- 股市指数有时被归为木（因为"涨"有木的意象），但金融板块核心属金
- 分析时以**金融属性**为主，不要纠结"指数属木"的说法

## 应用示例

**丙午年（2026）火旺：**
- 火克金 → 金价跌、金融板块跌、A股跌 ✅
- 不是"金克木导致股市跌" ❌

## 易学/命理的五行归属（争议点）

易学到底属火还是属水，存在流派分歧：

**属水的理由（主流）：**
- 玄学 = 水。"玄"字本身属水，玄学是隐学、暗学
- 水主智、主隐、主未见之事。命理是预测未发生的事，正合水性
- 命理需要逻辑推算、数据推理——这是水的"智"，不是火的"明"
- 风水、八字、奇门遁甲、紫微斗数，都属于术数/玄学系统 → 水

**属火的理由：**
- 教学、传播、著书立说 → 火（公开、明亮、表达）
- 文化产业运营、开课招生、做IP → 火
- "火"主礼、主文明、主传播

**实操拆分：**
- 学易/算命/看风水/做预测 → 水（玄学本体）
- 开课/出书/做自媒体/传播 → 火（文化包装）

**对八字分析的影响：**
- 如果客户从事易学相关行业，要区分是做预测（水）还是做传播（火）
- 做预测 = 水方向，适合命局喜水的人
- 做传播 = 火方向，适合命局喜火的人
