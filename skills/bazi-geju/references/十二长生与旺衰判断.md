## 三、十二长生在旺衰判断中的应用

### 3.1 十二长生等级分类

| 等级 | 状态 | 力量 | 对旺衰的影响 |
|------|------|------|-------------|
| **旺** | 帝旺 | 最强 | 强力帮身 |
| **相** | 临官（禄） | 很强 | 帮身 |
| **中** | 长生、沐浴、冠带 | 中等 | 有一定帮身 |
| **弱** | 衰、病、死 | 弱 | 帮身有限 |
| **空** | 墓、绝、胎、养 | 极弱/无 | 几乎不帮身 |

### 3.2 得地判断标准

**得地 = 日主在地支踩到长生到帝旺之位（长生、沐浴、冠带、临官、帝旺都算）**

| 判断 | 结果 |
|------|------|
| 地支见长生/沐浴/冠带/临官/帝旺 | 得地 ✓ |
| 地支见衰/病/死/墓/绝/胎/养 | 不得地 ✗ |

### 3.3 得助判断标准

**得助 = 命局中有印星或比劫生助日主（天干+地支都看）**

| 五行关系 | 十神 | 是否得助 |
|---------|------|---------|
| 同五行（如甲见寅卯） | 比劫 | ✓ 得助 |
| 生我者（如甲见亥子） | 印星 | ✓ 得助 |
| 我生者（如甲见巳午） | 食伤 | ✗ 不算得助 |
| 克我者（如甲见申酉） | 官杀 | ✗ 不算得助 |
| 我克者（如甲见辰戌丑未） | 财星 | ✗ 不算得助 |

## 四、旺衰判断完整流程

```
第一步：得令？→ 月令是否旺/相
第二步：得地？→ 地支是否见帝旺/临官/长生
第三步：得助？→ 天干或地支有印星/比劫
第四步：综合 → 三项占几？
  - 占3 → 身旺
  - 占2 → 偏旺或中和（需看具体力量）
  - 占1 → 偏弱或中和
  - 占0 → 身弱
```

### ⚠️ 注意事项

1. **阳天干用哪个版本都一样**，不用担心版本差异
2. **阴天干优先用版本2（现代常用）**，版本1做参考
3. **得助看天干+地支整体**，不是只看天干透干
4. **得地看十二长生等级**，帝旺/临官/长生才算强得地
5. **旺衰判断不是非黑即白**，卡在边界时需综合其他维度（格局、调候等）

## 五、案例验证

### 示例：甲木日主见丑土

| 维度 | 判断 | 依据 |
|------|------|------|
| 得地 | ✅ | 丑在甲木十二长生中为冠带（长生到帝旺范围内）→有根 |
| 得助 | ✗ | 丑是土，甲木克土（财星），不是印星也不是比劫→不得助 |

**说明：** 得地看十二长生位置（长生到帝旺都算），得助看五行生助关系（只有印星和比劫才算）。两者标准不同，可能一个成立一个不成立。
