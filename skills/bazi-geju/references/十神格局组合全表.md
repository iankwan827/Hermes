# 十神格局组合全表

> 核心原则：先定格局，再看组合是否攻击/辅助格局核心。生优先克。

---

## 一、正官格（核心：正官）

### 成立的组合

| 组合 | 判定条件 | 断语 |
|------|----------|------|
| **伤官见官** | 伤官直接克正官（无财星通关） | 口舌官非必难免（95%）；事业多波折（90%） |
| **财官相生** | 财星生正官，官得财助 | 事业有动力、财富与地位双丰收（95%） |
| **官杀混杂** | 七杀与正官同透或力量相当 | 事业方向多变，需中年后稳定（90%） |
| **官印相生** | 正官生正印，印生身 | 有贵人提携，职位稳定步步高升（95%） |

### 不成立的组合

| 组合 | 为什么不成立 |
|------|-------------|
| 枭神夺食 | 食神不是正官格的核心 |
| 伤官配印 | 伤官不是正官格的核心矛盾 |
| 食神制杀 | 七杀不是正官格的核心 |
| 比劫争财 | 财不是正官格的核心 |
| 财星破印 | 印不是正官格的核心 |

### 生优先克示例
- 丁火伤官→生己土正财→生酉金正官：伤官见官**不成立**（有财通关）
- 丁火伤官直接克酉金正官（无财）：伤官见官**成立**

## 九、生优先克原则详解

### 核心逻辑
- 当多个十神形成流通链时，**生的关系优先于克的关系**
- 能量顺着生的方向走，克的力量被化解
- 只有当生的链条被打断，克才直接作用

### 流通链示例

| 流通链 | 结果 | 组合判定 |
|--------|------|----------|
| 伤官→财→官 | 伤官不克官 | 伤官见官**不成立** |
| 官→印→身 | 官不克身 | 官印相生**成立** |
| 杀→印→身 | 杀不克身 | 杀印相生**成立** |
| 食神→财→官 | 食神不克官 | 食神制杀**不成立** |
| 伤官→印→身 | 伤官不克身 | 伤官配印**成立** |

### 断裂链示例

| 情况 | 结果 | 组合判定 |
|------|------|----------|
| 伤官直接克官（无财通关） | 伤官克官 | 伤官见官**成立** |
| 枭神直接克食神（无比劫通关） | 枭神夺食 | 枭神夺食**成立** |
| 财星直接克印（无比劫护印） | 财星破印 | 财星破印**成立** |
