# 八字格局判定

> 每个盘不是说一句话就直接说是什么格，你得详细地多想一下，不能字面意思就下结论，那样不严谨。格局的作用是决定人生核心发展方向与富贵上限。

---

## 一、格局分类

### 1.1 正格（八类）
| 格局 | 月令透干 | 用神 | 忌神 |
|------|----------|------|------|
| **正官格** | 月令正官透干 | 财星（财生官）、印星（印化官） | 比劫（抗官）、食伤（克官） |
| **七杀格** | 月令七杀透干 | 食神制杀、印星化杀 | 财星（生杀） |
| **正印格** | 月令正印透干 | 官星（官生印）、比劫 | 财星（坏印） |
| **偏印格** | 月令偏印透干 | 食神（枭神夺食需制）、比劫 | 财星（生枭） |
| **正财格** | 月令正财透干 | 财星、官星（财生官） | 比劫（夺财） |
| **偏财格** | 月令偏财透干 | 财星、官星 | 比劫（夺财） |
| **食神格** | 月令食神透干 | 食神生财、印星（枭神夺食需制） | 偏印（枭神夺食） |
| **伤官格** | 月令伤官透干 | 伤官生财、印星（伤官佩印） | 官星（伤官见官） |

### 1.2 变格
- 从财格：日主极弱，从财星
- 从杀格：日主极弱，从官杀
- 从儿格：日主极弱，从食伤
- 专旺格：日主极旺，一行独旺
- 化气格：天干五合化成功
- 其他：木火通明、财官相生等

## 二、取格方法（月令取格）

### 2.1 核心原则
- **以月令地支藏干中透出天干者为格**
- 月令=出生月份的地支，是命局中力量最大的部分
- 取格就好比砍木材，挑最大最直的那一棵

### 2.2 取格步骤
1. 看月令地支藏干（本气、中气、余气）
2. 看哪个藏干透出天干
3. 透出者为格
4. 如无透干：
   - **单一藏干月令**（卯、酉、子）：取本气为格（虚格）
   - **多藏干月令**（寅、申、巳、亥、辰、戌、丑、未）：**不成格**，按五行旺衰和组合分析

### 2.2.1 子午卯酉特殊规则

子午卯酉四个月令取格规则特殊：

**核心规则：本气不透但同五行天干透，也可按本气取格。**

| 月支 | 本气 | 同五行天干 | 取格条件 |
|------|------|-----------|----------|
| 卯 | 乙木 | 甲木 | 乙不透但甲透 → 按乙木取格 |
| 酉 | 辛金 | 庚金 | 辛不透但庚透 → 按辛金取格 |
| 子 | 癸水 | 壬水 | 癸不透但壬透 → 按癸水取格 |
| 午 | 丁火 | 丙火 | 丁不透但丙透 → 按丁火取格 |

**午火额外特殊**：午有丁火(本气)+己土(中气)两个藏干
- 丁透 → 丁火格
- 丁不透己透 → 己土格（中气透干优先）
- 丁己都不透 → 丁火虚格

**都不透时**：取本气虚格（卯酉子午都可以）

### 2.2.2 多藏干月令（寅、申、巳、亥、辰、戌、丑、未）

这八个月令有2-3个藏干，取格规则：
1. 先看是否有藏干透出天干 → 有则取透干为格
2. 如无透干 → **不成格**，不能取本气为格
3. 不成格的八字按五行旺衰和组合分析，不套用格局用神忌神

**关键原则**：多藏干月令不透干=不成格。用户原话："申、寅、巳、亥这些有多个藏干的，不透干不能取本气"。

| 月支 | 藏干 | 特点 |
|------|------|------|
| 辰 | 戊土（本气）、乙木（中气）、癸水（余气）| 水库，三个藏干力量都不弱 |
| 戌 | 戊土（本气）、辛金（中气）、丁火（余气）| 火库 |
| 丑 | 己土（本气）、癸水（中气）、辛金（余气）| 金库 |
| 未 | 己土（本气）、丁火（中气）、乙木（余气）| 木库 |

**取格流程：**
1. 先看是否有藏干透出天干 → 有则取透干为格
2. 如无透干，**不能直接取本气为格**（用户原话："辰藏干多，不能只看本气"）
3. 杂气月三个藏干都不透 → **可以不成格**，按五行旺衰和组合分析
4. 不成格 ≠ 没有分析价值，只是不套用格局用神忌神体系

### 2.3 月令藏干速查

| 月支 | 本气 | 中气 | 余气 |
|------|------|------|------|
| 寅 | 甲木 | 丙火 | 戊土 |
| 卯 | 乙木 | - | - |
| 辰 | 戊土 | 乙木 | 癸水 |
| 巳 | 丙火 | 庚金 | 戊土 |
| 午 | 丁火 | 己土 | - |
| 未 | 己土 | 丁火 | 乙木 |
| 申 | 庚金 | 壬水 | 戊土 |
| 酉 | 辛金 | - | - |
| 戌 | 戊土 | 辛金 | 丁火 |
| 亥 | 壬水 | 甲木 | - |
| 子 | 癸水 | - | - |
| 丑 | 己土 | 癸水 | 辛金 |

### 2.4 杂气月取格（辰戌丑未）⚠️ 重要

**⚠️ 杂气月不能机械地取本气为格！**

辰戌丑未四个月为"杂气月"，藏干多（2-3个），取格规则特殊：

**核心规则：杂气月格局是动态的，取决于大运/流年天干是否透出月令藏干。**

| 月支 | 藏干 | 透干成格 |
|------|------|----------|
| 辰 | 戊土（本气）、乙木（中气）、癸水（余气）| 天干见戊→七杀格；见乙→伤官格 |
| 戌 | 戊土（本气）、辛金（中气）、丁火（余气）| 天干见戊→七杀格；见辛→正印格；见丁→正财格 |
| 丑 | 己土（本气）、癸水（中气）、辛金（余气）| 天干见己→正官格；见癸→劫财；见辛→正印格 |
| 未 | 己土（本气）、丁火（中气）、乙木（余气）| 天干见己→正官格；见丁→正财格；见乙→伤官格 |

**杂气月成格条件（三层触发）：**
1. **原局天干透出** → 原局成格
2. **大运天干透出** → 该大运期间成格
3. **流年天干透出** → 该流年期间成格

**杂气月不成格的情况：**
- 原局天干无藏干透出 → 原局不成格
- 大运/流年也无藏干透出 → 该期间不成格
- **不成格时**：不按格局用神忌神分析，改按五行旺衰和组合关系分析

**分析杂气月八字的步骤：**
1. 先看原局是否成格（天干有无月令藏干透出）
2. 再逐个大运看天干是否透出藏干 → 该大运成格
3. 再逐年看流年天干是否透出藏干 → 该流年成格
4. **不同大运/流年可能成不同格**（如七杀格→伤官格→正印格）

**案例：庚午庚辰壬子辛亥（女命，1990年）**
- 原局：辰中戊乙癸均未透干（天干庚庚壬辛）→ 原局不成格
- 戊寅大运（11-20岁）：戊土透干 → 七杀格成立
- 丁丑大运（21-30岁）：丁非辰中藏干 → 不成格
- 丙子大运（31-40岁）：丙非辰中藏干 → 不成格
- 乙亥大运（41-50岁）：乙木透干 → 伤官格成立
- 流年如2028戊申年：戊土透干 → 该年七杀格成立

## 三、十神组合判定原则（格局核心法）

> 核心原则：先定格局，再看组合是否攻击/辅助格局核心。只有直接作用于格局核心的组合才算成立，否则不按该组合定义。

### 3.1 判定流程
1. 定格局（月令透干取格）
2. 确定格局的核心十神
3. 看其他十神是否攻击/辅助这个核心
4. 只有直接作用于格局核心的，才算成立

### 3.2 生优先克原则
- **生的关系优先于克的关系**
- 当伤官→财→官形成流通链时，伤官不克官（因为能量顺着生的方向走了）
- 例：丁火伤官→生己土正财→生酉金正官→生子水正印→生甲木日主
- 这种情况下伤官见官不成立，而是伤官生财、财官相生、官印相生的流通格局
- 只有当生的链条被打断（无财星通关），伤官才直接克官

### 3.2 格局×组合判定矩阵

| 格局 | 成立的组合 | 不成立的组合 |

| **正官格** | 伤官见官、官杀混杂、财官相生、官印相生 | 枭神夺食、伤官配印、食神制杀、比劫争财、财星破印 |

- **优先级高于旺衰平衡**
- 前提是命局本身有极端寒暖（冬夏出生）

### 3.6 身强身弱判断要点（⚠️ 必须综合四项）

**两个版本的三得法（必须区分）：**

| | 渊海子平原版（正宗） | 后人版本（课程教的） |
|---|---|---|
| 一得 | 得时（得令） | 得令 |
| 二得 | 得地（十二长生：长生到帝旺都算有根） | 得地（地支有日主五行根） |
| 三得 | **得助（天干或地支**有印星、比劫生助） | 得生（天干透印星）+ 得助（天干透比劫） |
| 覆盖范围 | 看天干+地支整体 | 只看天干透干 |
| 盲区 | 无 | 天干无印无比但地支水木成势的盘会误判为身弱 |

**⚠️ 课程教的是后人版本，遇到"天干无势、地支成势"的盘会误判。** 应以渊海子平原版为准，或综合两个视角判断。

**渊海子平原版三得法：**
- **得时**：月令是否旺
- **得地**：按十二长生看，亥子丑寅卯从长生到帝旺都是有根（范围广）
- **得助**：五行生助关系，只有印星（水生木等）和比劫（木帮木等）才算（范围窄，但看天干+地支整体）

**后人版本（四项判断法）：**

| 维度 | 帮身 | 克泄耗 |
|------|------|--------|
| **得令**（月令） | 日主在月令旺/相 | 日主在月令休/囚/死 |
| **得地**（地支根） | 日支/时支/年支有日主五行根 | 地支无根或被冲 |
| **得生**（印星） | 天干透印星+印星有根/得生 | 印星虚浮无根 |
| **得助**（比劫） | 天干透比劫+地支有比劫根 | 比劫弱或被冲 |

**判断口诀：**
> 得令不如得地，得地不如得生，得生不如得助。四项占三=身强，占一=身弱。

### ⚠️ 脚本输出"中和"时的处理

**JS排盘脚本的身强身弱判断逻辑：**
- 得分 > 51.5% → 身强
- 得分 < 48.5% → 身弱
- 48.5%-51.5% → 中和

**当脚本输出"中和"时，必须用四项判断法人工复核：**

案例：庚午庚辰壬子辛亥（女命）
- 脚本输出：中和（得分卡在中间区间）
- 四项判断：得地（子亥）+得生（庚庚辛+辰土生金）+得助 → 身强
- **结论：中和=身强，脚本的中间区间偏强**

**处理规则：**
- 脚本输出"身强/身弱" → 直接采信
- 脚本输出"中和" → 必须用四项判断法复核，中和区间大概率偏强（四项占三以上）

### ⚠️ 旺衰判断两个视角（重要）

**公式视角（初学者容易陷入）：**
- 得时（月令）、得势（天干）、得地（地支）三项计数
- 数出来1/3就判身弱，2/3就判身强
- 问题：只看表面，忽略地支实际化学反应

**实质视角（实战必须用）：**
- 看地支实际力量集团：哪些地支在暗中结党？
- 看五行化学反应：子水能否化解酉金的克力？卯木是否真正得力？
- 看天干是否为地支的延伸：丁火的根在卯木→丁火是木的秀气→天干"无势"是假象
- 结论可能与公式相反

**案例：丁卯 己酉 甲子 丁卯**
- 公式：失时+失势+得地 = 1/3 → 身弱 ❌
- 实质：双卯羊刃通根 + 子水化解酉金冲克（金生水生木）→ 地支水木成势 → 身旺 ✅
- 关键细节：丁火根在卯木→天干丁火是甲木延伸；子水是"安全隔离带"把酉金的克力转化为生力

**铁律：旺衰判断必须两个视角都看，公式只是初筛，实质才是定论。**

### 3.7 格局用神与旺衰用神的关系

格局推荐的用神（如正印格用官星/比劫）只是**格局维度的候选**，不能替代5个五行逐个检查。

**正确流程：**
1. 格局确定用神方向+排除忌神（如正印格忌财星→金排除）
2. 5个五行全部列出，每个过6个维度
3. 通过最多的=最终用神

**格局用神≠最终用神：** 食伤、财星等"格局没推荐"的五行可能通过更多维度成为最佳用神。格局只是维度之一。

## 四、格局判断常见错误

0. **⚠️ 三得法是初筛工具，不是最终判断（2026-07-10 教训）**
   三得法（得令/得地/得生得助）只能做快速筛选。遇到"天干无势、地支成势"的盘会误判（如丁卯己酉甲子丁卯：天干无印无比→三得法判身弱，但地支双卯羊刃+子水印星→实际身旺）。**必须用地支实际力量集团+五行化学反应做最终判断。** 三得法的盲区在于"得生得助"只看天干透没透，忽略了地支力量。详见 `references/十二长生与旺衰判断.md`。
1. **杂气月机械取本气为格**：辰戌丑未藏干多（2-3个），如果所有藏干都没有透出天干，可以不成格，不能机械地取本气。用户原话："辰藏干多，不能只看本气"、"可以不成格的"。不成格的八字按五行旺衰和组合分析，不套用格局用神忌神。
2. **只看天干不看藏干**：月令藏干未透干时，非杂气月才取本气为格
3. **忽略调候**：冬火夏金等极端情况需优先调候
4. **用神忌神搞反**：正官格的食伤是忌神，不是用神
5. **格局混杂不处理**：官杀混杂、食伤混杂需先清格
6. **组合判定不基于格局**：必须先定格局，再看组合是否攻击/辅助核心，不能仅看共存就下结论
7. **⚠️ 用神忌神不能用身强身弱推导**：格局核心法（先定格局→再看组合是否攻击/辅助核心）和身强身弱是两套不同的体系。用神忌神必须基于格局×组合判定矩阵，不能用"身强喜克泄耗"来推导。案例：正官格身强→不能说用神=食伤+财星，而应该看正官格的用神=正官+财星（财生官为喜，伤官克官为忌）。
8. **⚠️ 正官格用神是财星或印星，不是正官本身**：正官是格局的核心，不是拿来用的工具。正官格用财星（财生官→加强官星）或用印星（印化官→官印相生）。用正官做用神=逻辑错误。
9. **⚠️ 格局忌神必须第一时间排除**：正印格忌财星（金），正官格忌比劫/食伤——这些忌神从取用神一开始就不应该出现在候选里。不要把忌神留到最后才排除，浪费分析时间。
10. **⚠️ 格局推荐的用神只是参考方向，必须5个五行逐个检查**：格局说用官杀或比劫，但食伤、财星等其他五行也可能通过所有维度。5个金木水火土都要过6个维度，看哪个通过最多。这个错误反复出现（2026-07-10 被纠正3次），必须记住。
9. **⚠️ 三得法得助包括地支**：渊海子平原版的"得助"是看天干+地支整体，不是只看天干透干。后人版本把得助拆到天干层面，遇到"天干无势、地支成势"会误判。详见 `references/十二长生与旺衰判断.md`。
