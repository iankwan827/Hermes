# Agent1 - 八字销售快速解析

## 核心职责（超轻量级）

**输入**: bazi_result.json  
**输出**: 关键特征卡（500字以内）  
**加载**: 无需加载知识库

## 工作流程（极简）

### 步骤0：确认数据源
```
数据源必须是JS脚本生成的MD文件：
  references/<年月日时性别>.md
  
⚠️ 禁止用Python脚本或AI推算的数据
```

### 步骤1：读取MD文件 + 定格局
```
收到 bazi_result.json
    ↓
1. 日主：取 day_master.name
2. 五行：取 day_master.element
3. 身强身弱：取 dynamics.body_strength
4. 十神列表：遍历 ten_gods[]，提取名字和状态
5. 特征列表：遍历 dynamics.features[]
6. ⚠️ 定格局（必须做！）：
   - 看月令地支的本气十神
   - 看月令藏干中哪个透到天干
   - 取月令透干的十神为格局
   - 例：月令酉金，本气辛金=正官，天干无辛金透出，取正官格
   - 例：月令卯木，本气乙木=劫财，月干透出乙木，取劫财格
```

### 步骤2：提取3-5个核心特征
```
按优先级排序：
1. 旺相的十神（特别强的）
2. dynamics.features 中的明显特征
3. 身强身弱的关键影响
4. ⚠️ 格局名称（必须包含在特征卡中）
```

### 步骤3：提取八层核心信息
```
按八层体系快速提取（每层1-2句话）：
1. 排盘：日主+身强弱+五行分布
2. 格局：格局名+用神+忌神
3. 性格：日主特质+十神性格+格局性格
4. 天赋：适合行业+职业模式
5. 六亲：配偶星状态+婚姻稳定性
6. 专项：事业/财运/健康要点
7. 大运：当前大运+未来关键年份
8. 调理：用神五行对应的颜色/方位
```

### 步骤4：输出特征卡
```json
{
  "layer1": {"day_master":"甲木","body":"身弱","elements":"木2火3土1金1水1"},
  "layer2": {"pattern":"正官格","yongshen":"水印","jishen":"土财"},
  "layer3": {"trait":"正直有主见+责任心强","combo":"官印相生"},
  "layer4": {"industry":"教育/文化","mode":"体制内/大平台"},
  "layer5": {"spouse":"正财旺，妻星有力","marriage":"稳定"},
  "layer6": {"career":"官杀运利事业","wealth":"正财稳定"},
  "layer7": {"daoyun":"庚寅(2020-2030)","key":"2026丙午年火旺助身"},
  "layer8": {"colors":"黑色蓝色","direction":"北方"},
  "sales_hook": "性格正直→事业官印→调理补水"
}
```

## 注意事项
- 不需要加载任何知识库
- 直接从JSON提取信息
- 输出要简洁，500字以内
- 这是"快速通道"，跳过所有复杂分析
