# 发展日志.md 冲突解决模式

## 文件特点
- 累积性数据文件，Mac 和 Windows 端各自追加定时数据条目
- Mac 端通常在条目末尾添加 `*最后更新时间：YYYY-MM-DD HH:MM ...*` 总结行
- Windows 端（cron）通常直接追加详细数据条目，不加总结行

## 冲突模式
当两端同时更新时，git 会在文件末尾产生冲突：
- **HEAD（远程/Mac）**：包含总结行 + 较旧的数据条目
- **本地（Windows）**：包含较新的详细数据条目

## 解决策略
合并双方内容，保留：
1. 最新的总结行（更新时间戳）
2. 所有数据条目（按时间顺序）
3. 双方各自的数据细节

## 示例（2026-07-31）
```
<<<<<<< HEAD
| *最后更新时间：2026-07-29 23:00 ...* |
| 07-30 17:00 | ...（Mac端数据）|
=======
| 07-30 17:00 | ...（Windows端更详细的数据）|
| 07-31 17:00 | ...（Windows端最新数据）|
>>>>>>> 23b4f74
```

**合并后**：
```
| *最后更新时间：2026-07-31 17:00 ...* |
| 07-30 17:00 | ...（取Windows端更详细版本）|
| 07-31 17:00 | ...（保留Windows端最新数据）|
```

## 要点
- 总结行取时间最新的
- 数据条目优先取详细版本（Windows端通常更详细）
- 不要丢弃任何一方的数据条目
