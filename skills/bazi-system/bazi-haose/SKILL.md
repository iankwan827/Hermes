# 八字好色格局判断

## 用途

根据排盘数据，判断情欲旺盛程度、感情模式。

---

## 判断维度

### 一、五行特征类（不分男女）

**1. 命局水旺**
- 核心逻辑：水主肾，主情欲，水旺则欲望旺盛
- 典型表现：情欲汹涌，如江河湖海之水奔流

**2. 金水两旺**
- 核心逻辑：金生水，加剧情欲与多情属性
- 典型表现：多情多欲，女命更突出（美貌身材但情伤）
- 判断标准：命局超过四个金水就算金水两旺

**3. 日支为子水（无克无收）**
- 核心逻辑：日支主内心追求，子水为"情欲桃花"
- 典型表现：情欲在心中占比极高，需求强烈

**4. 地支巳亥多见（相冲）**
- 核心逻辑：巳为火（情），亥为水（欲），驿马相冲
- 典型表现：走哪撩哪，一生多风流事

### 二、特殊组合类

**1. 地支合局多**
- 核心判断点：合局主人缘好、心软好说话
- 表现特征：对外多情，易引发伴侣反感

**2. 男无正财+偏财旺 / 女无正官+七杀旺**
- 核心判断点：缺乏"正缘星"，偏星主导感情
- 表现特征：多情寡义，对婚姻兴趣低，结婚后难安分

### 三、女命专属格局

**1. 官杀混杂且旺+食伤有力**
- 核心条件：官杀（男人）多，食伤（欲望）旺
- 表现结果：感情丰富，易红杏出墙，文艺从业者更易中招
- 这也是女明星的格局——食伤是才华艺术表达，观众缘又旺，容易走红

**2. 官杀混杂且身弱**
- 核心条件：官杀旺但日主弱，意志力不足
- 表现结果：易被诱惑，陷入情欲相关事端

### 四、男命专属判断

**1. 正偏财旺且混杂**
- 核心特征：天干透正财+偏财，地支财星成势，无论喜忌
- 表现结果：异性缘泛滥，对配偶挑剔、见异思迁
- 逻辑：男命以财星代表配偶，正偏财混杂=感情不专

**2. 偏财成势无制**
- 核心特征：仅见偏财，偏财旺而正财被克/合化，无印星比劫制
- 表现结果：重情欲轻责任，偏好露水情缘

**3. 身旺食伤生财**
- 核心特征：日主强旺，食伤透干生财星
- 表现结果：精力旺盛、主动撩拨，擅长甜言蜜语
- 细分：食神生财→温和多情；伤官生财→大胆直接

**4. 身旺劫财夺财**
- 核心特征：日主强旺，劫财透干/成势，紧贴财星
- 表现结果：争夺异性、偏好刺激，抢他人伴侣

### 五、男命专属组合

**1. 日支坐桃花（子午卯酉）无克合**
- 核心特征：日支为桃花星，未被冲克，财星不弱
- 表现结果：内心极度看重情欲，婚后易藏私房情

**2. 地支财星逢合多**
- 核心特征：正偏财与比劫、官杀多合
- 表现结果：与多个异性暧昧纠缠

---

## 核心总结

**核心锚点**：以"财星"为唯一核心线索（男命）

| 组合 | 表现 |
|------|------|
| 身旺+财星/食伤旺 | 主动好色 |
| 身弱+财旺官杀混 | 被动滥情 |
| 正偏财混杂 | 多偶 |
| 纯偏财无制 | 放纵 |
| 食伤生财 | 善撩拨 |
| 劫财夺财 | 好争夺 |
