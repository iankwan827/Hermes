# 八字分析常见错误 (Pitfalls)

## 🚫 流程类（最优先）

### P0: 审核前输出终版
分析写完后（Step 2结束）→ 必须先执行 Step 3 审核 → 审核通过才能输出。**绝对不能先输出再审核。** 流程：写分析→审核→修正→重审→确认无误→输出终版。

### P1: 过三关≠直断验证
用户定义的"过三关"= 格局判定+用神忌神+日主强弱（Phase 2-3详细分析）。28秘诀直断是bazi-zhiduan skill，与用户定义的"过三关"不同。

## 🔴 十神/格局类（高频错误）

### P2: 十神搞混
甲木见丁火=伤官（阳见阴），不是食神。写分析时必须对照排盘结果，不能凭记忆写。

### P3: 格局判定必须看月令藏干本气
格局从月令取，看的是**月令地支藏干本气**对应的十神，不是月干透出的十神。

**错误做法**：月干透出乙木正财→就说正财格
**正确做法**：月支丑→本气己土→对日主辛金=偏印→印星当令→正印格（正偏印混杂）

核心规则：
- 月令地支的本气藏干 = 格局核心
- 月干透出的是"配角"，不是格局判定依据
- 月令本气不透时，仍取月令本气十神为格
- ⚠️ 羊刃格容易漏判：阳干的羊刃在帝旺位（甲卯、丙午、庚酉、壬子），如果月令正好是日主的羊刃，必须取羊刃格

**实例**：辛金日主，月支丑（本气己土=偏印），年干戊土正印+时干戊土正印→正印格，正偏印混杂。不能因为月干乙木正财就说正财格。

### P3d: 用户纠正格局后必须全文一致（严重！回退错误）
用户纠正格局判定后，**必须检查分析文本的所有其他部分是否还引用了旧的错误格局**。不能只改格局那一段，性格/事业/婚姻等Phase都可能引用格局名称。

**典型错误**：用户纠正"不是比肩格，是正印格"→改了Phase 2格局段→但Phase 6性格分析第7点还在写"比肩格的底色"。

**正确做法**：用户纠正格局后→全文搜索旧格局名称→全部替换为新格局→检查每个引用点是否逻辑自洽。

### P3b: 身强命造流年火旺不一定吉
火旺对身强+印旺命造的连锁反应：

**火 → 生土 → 印更旺 → 克食伤 → 食伤是财的源头 → 财源枯竭 → 财不行**

分析流年时不能只看"官杀透出=事业机遇"，必须检查：
1. 流年五行是否加强了忌神（特别是印星）
2. 火旺→土旺→水（食伤）受制→财源被断
3. 身强命造不怕官杀克身，但怕印星更旺

**实例**：2026丙午年，辛金身强+正印格+印极旺。丙火正官+午火→火旺生土→印更旺→克食伤癸水→财不行。表面看官杀透出有事业机会，实际进账不理想。

### P3c: 辰戌冲与枭神夺食判断
辰戌冲可以打开墓库释放藏干（如辰中癸水食神透出），但需检查大运是否有枭神（偏印）透出：
- 有枭神透出→枭神夺食，食神刚冒头就被压回去
- 但**如果不是食神格**，影响不严重（食神不是格局核心，丢了不伤大局）
- 原局印旺已压食伤→大运枭神只是加剧了本来就在发生的事

### P4: 用神忌神必须格局法推导
脚本只输出十神，不输出格局。脚本自动判定的"用/忌"列经常出错。正确流程：先定格局→根据格局推导用神忌神→所有后续分析以此为准。

### P5: 偏印格是凶格
偏印格以财星制枭为第一核心用神（不是忌神），食伤为第二辅助用神。忌神是印星（病根）、官杀（官生印）。比劫看情况：身强时帮身致旺+夺财为忌；身弱时比劫可通关化枭夺食。

### P6: 五行优先于十神
分析时先看五行力量对比（物理层），再看十神关系（应用层）。五行层面已经决定结果时，十神只是贴标签。

## 🟡 参数/脚本类

### P7: JS脚本参数格式
5个参数：`node scripts/generate_bazi_analysis.js <年> <月> <日> <时> <性别>`。时=小时（0-23），不传分钟。⚠️ 子时(23-23:59)算第二天子时（日期+1，hour=0），脚本已自动处理。

### P8: JS脚本路径
- Windows: `E:/Users/Administrator/AppData/Local/hermes/skills/bazi-sales`
- Mac: `~/.hermes/profiles/main/skills/bazi-sales`
- 定位脚本: `find ~/.hermes -name "generate_bazi_analysis.js" 2>/dev/null`

### P9: 脚本性别bug（严重！十神全错）
脚本始终输出"女命"（gender参数无效）。四柱天干地支不受影响，但**十神全部错误**——因为十神取决于日主阴阳+性别。例如戊土对辛金：男命=正印，女命=比肩。**必须手动重算十神**，不能用脚本输出的十神。

手动重算方法：确认性别→确定日主阴阳→按"同性=比肩/食神/偏财/正官/偏印，异性=劫财/伤官/正财/七杀/正印"规则逐柱重算。速查：`references/十神速查表.md`。

## 🟢 分析内容类

### P10: 流年年份必须准确计算
2024=甲辰，2025=乙巳，2026=丙午...2030=庚戌。年份算错会导致完全错误的结论（特别是墓库分析）。

### P11: 流年必须结合大运
流年分析不能只看流年本身，必须结合当前大运。先确定当前大运→检查大运地支→再看流年地支→综合判断。

### P12: 墓库触发条件
只有当原局/大运/流年的地支出现辰戌丑未时才分析墓库。三者都没有则说明"无辰戌丑未，跳过墓库分析"。

### P13: 专题Skill加载条件
- 空亡：始终分析（加载 bazi-kongwang）
- 墓库：辰戌丑未出现时（加载 bazi-muku）
- 大运流年：Phase 8（加载 bazi-dayun-liunian）
- 女命生育：gender=F 时（加载 bazi-fukeshengyu）

### P14: 不成立的组合
格局×组合判定中"不成立"的组合，不是假装它们不存在，而是换一种分析方式——逐字分析各自功能和互动后果（替代分析方法），不贴组合标签。

## 🔵 环境/文件类

### P15: 不要删项目文档
- `D:/hermes-agent/ARCHITECTURE.md` 是核心架构说明书

### P16: Windows删除文件
MSYS2/Git Bash的 `rm` 是永久删除，不进回收站。需要安全删除用PowerShell `Remove-Item`。

### P17: Hermes CLI编码问题
Node.js exec调用hermes有编码问题，正确方案：写bash脚本做中间层（run_duanyu.sh），prompt写到临时文件，bash的 `$(cat file)` 读取传给hermes。
