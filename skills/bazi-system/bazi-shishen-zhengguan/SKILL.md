# 正官专题

## 核心定义

- **阴阳**：异性相克（克我），阳见阴/阴见阳
- **本质**：温和的约束，如老师管学生
- **性格**：稳重、有责任感、讲规矩、自律、传统
- **代表**：正夫（女命）、上司、法律、名誉
- **为用时**：事业稳定、有贵人、守规矩
- **为忌时**：压力大、受限、缺乏自由
