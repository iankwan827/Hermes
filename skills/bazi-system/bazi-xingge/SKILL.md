# 八字性格分析系统

## 功能定位

这是一个**综合性格分析指导系统**，用来：

1. **快速识别性格维度** - 了解要分析哪些要素
2. **选择合适的skill** - 自动推荐使用哪个十神skill
3. **多角度性格分析** - 日元、十神、五行、地支等全方位
4. **性格速查** - 快速获取性格特征和行为表现

## 核心分析维度

### 一、日元性格（命盘中心）

日元代表命主本身，是性格的核心基础。

10个日元各有独特的性格特征和行为模式。

**用法：** 先看日元确定性格基调

### 二、十神性格（命盘影响因素）

十神代表不同的人生角色和性格侧面。

一个人的性格是多个十神综合作用的结果。

**用法：** 
- 命盘中哪个十神最强 → 性格最突出的部分
- 哪个十神最弱 → 性格最缺乏的部分
- 多个十神组合 → 复合性格特征

### 三、年干时干（表里分析）

- **年干** = 内心世界、真实性格
- **时干** = 外在表现、社交面貌

**用法：** 了解一个人"表里是否如一"

### 四、五行特征

各五行的命盘配置会影响性格倾向：

- **水旺** → 情欲旺、多情善感
- **火旺** → 热情外向、容易急躁
- **木旺** → 有主见、容易固执
- **金旺** → 刚毅果决、容易冷酷
- **土旺** → 稳重厚重、容易呆板

### 五、地支关系

地支的刑冲合害影响内心稳定度和行为表现。

## 使用流程

### 标准流程

```
1. 得到排盘结果
   ↓
2. 确定日元 → 了解基础性格（推荐使用对应十神skill）
   ↓
3. 分析十神强弱 → 了解性格各侧面（使用相应十神skills）
   ↓
4. 比对年干时干 → 了解表里性格差异
   ↓
5. 观察五行配置 → 了解性格倾向
   ↓
6. 综合分析 → 得出完整性格图谱
```

### 快速判断

如果只有5分钟，按优先级：

1. **第一看：日元** - 快速了解核心性格
2. **第二看：十神强弱** - 了解性格特点
3. **第三看：年干时干** - 了解表里差异

## 关键概念

### 旺衰影响性格

同一个十神：
- **为旺为用** → 性格优势突出，表现积极面
- **为旺为忌** → 性格过度，表现消极面  
- **为衰为用** → 性格缺乏，需要补强
- **为衰为忌** → 性格较弱，影响不大

### 性格不是命运

八字描述的是倾向和特点，不是决定。同一性格的人因环境、教育、选择的不同而有完全不同的人生。

### 性格描述需具体化

不能只说"你性格急躁"，要说"你平时做决定很快，但容易后悔；你赶时间时容易焦躁，甚至会着急上火"。

## 性格分析的应用

### 感情方面
- 了解自己和伴侣的性格差异
- 预测可能的冲突点
- 学会互补和包容

### 事业方面
- 了解自己的职业倾向
- 选择合适的工作类型
- 预测职场人际关系

### 人际关系
- 理解别人的性格特点
- 找到相处的方式
- 避免不必要的冲突

### 自我认知
- 理解自己的优缺点
- 发挥优势、改进不足
- 活得更自洽
