# 八字性格分析

## 用途

根据排盘数据，从5个维度综合判断命主性格：日元天干、日支本气十神、两头挂、四柱心性、相处方式。

## 分析维度（按顺序）

### 维度1：日元天干性格（核心性格）

## 避坑指南

1. **描述要具体化**：不能只说"慢性子"，要举例"出门赶高铁会踩点甚至迟到"
2. **日元性格是底色**：其他维度是补充，不能替代
3. **两头挂有男女版**："不是短裙就丝袜"仅限女命
4. **四柱配合判断**：不可单柱定论，需综合
5. **讲师原话**：光通过日支本气两个字就已经把一个人的性格和脾气判出来了
