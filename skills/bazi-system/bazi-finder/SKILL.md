# 八字定位Agent

## 职责

根据用户问题类型，加载bazi-sizhu skill，告诉分析Agent该重点看哪个柱位。

## 输入

- bazi.json（排盘数据）
- 问题类型（用户问什么）

## 输出

分析方向说明，格式：

```
【分析方向】
问题类型：六亲
重点柱位：年柱（祖辈）、月柱（父母兄弟）、日柱（自己配偶）、时柱（子女）
分析要点：...
```

---

## 问题类型 → 柱位映射

### 问六亲
```
重点柱位：年柱（祖辈家族）、月柱（父母兄弟）、日柱（自己配偶）、时柱（子女下属）
分析要点：
- 年干主父系，年支主母系
- 月柱=父母宫
- 日支=夫妻宫，怕冲克
```

### 问事业
```
重点柱位：月柱（事业平台）、日柱（自身能力）、时柱（事业成果）
分析要点：
- 月柱=事业平台、职场人际
- 七杀=关系紧张；正官=关系融洽
- 时柱=副业产出、管理
```

### 问财运
```
重点柱位：月柱（正财工资）、日柱（财库核心）、时柱（偏财积蓄）
分析要点：
- 年柱偏财透出=长辈给零花钱/房产
- 日柱正财=床头柜放现金
- 偏财=别人赠与
```

### 问健康
```
重点柱位：年柱（头面五官）、月柱（胸背心肺）、日柱（腰腹五脏）、时柱（下肢腿脚）
分析要点：
- 八字从上到下=从头到脚
- 金木相克看伤疤
- 甲木在任何位置都代表头
```

### 问婚姻/配偶
```
重点柱位：日柱（自己配偶）
分析要点：
- 日支=夫妻宫，怕冲克
- 配偶星（正财/正官）的位置和旺衰
```

### 问性格
```
重点柱位：年柱（公众人设）、月柱（社交性格）、日柱（真实本我）、时柱（深层隐秘）
分析要点：
- 天干主外，地支主内
- 年月为外，日时为内
```

### 问穿搭/风格
```
重点柱位：年柱（公开形象）、月柱（日常穿搭）、日柱（私密审美）、时柱（深层隐秘审美）
分析要点：
- 年干定风格色调，年支定面料质感
- 十神修正
```

### 问好色/情欲
```
重点柱位：日柱（内心追求）、时柱（深层欲望）
分析要点：
- 日支为子水=情欲桃花
- 财星/官杀的旺衰
```

### 问身材/胸部
```
重点柱位：月柱（胸部系统）
分析要点：
- 月柱代表胸部系统，涵盖肩部至腰部
- 食伤星与胸部关联
```

### 问大运/运势
```
重点柱位：全盘结合大运
分析要点：
- 大运为"地利"，流年为"天时"
- 看大运对原局格局和用神的化学反应
```

```json
}
```
