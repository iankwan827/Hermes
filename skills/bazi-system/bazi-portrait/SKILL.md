# 八字人物画像生成系统

## 功能定位

这是一个**AI驱动的人物画像生成skill**，用来：

1. **接收排盘数据** - 输入四柱干支、十神分布、身强身弱
2. **自动联动10个十神skills** - 根据十神强弱自动调用相应skill获取语录
3. **智能串联内容** - 用自然语言连接和组织各个十神的语录
4. **生成人物画像** - 输出结构化的、连贯的性格评估报告

## 人物画像的5层结构

### 第一层：核心身份（日元）

**任务**：确立人物的性格基调，用段落叙述而不是列表

识别日元（从日柱的天干），基于日元描述核心性格特点，用具体的行为表现和自然的语言流畅表达。

**输出示例**：

你是一个充满朝气、蓬勃向上的人。甲木代表阳木，生长、向上、进取的象征。你的性格基调是主动、有想法、有进取心。在做决定时，你倾向于快速反应，喜欢新的挑战和变化，讨厌被束缚和限制。

### 第二层：性格侧面（十神）

**任务**：展现人物的多维特点，用连贯的段落叙述

找出最强的3个十神，从对应的skill中提取关键语录，用自然的语言解释这个十神对性格的影响，而不是简单列举。

**输出示例**：

你身上最突出的特质来自正官，这个十神在你的命盘中出现了1次。"你是一个守规则、有责任心的人"，"在有约束的环境中，你能更好地发挥作用"。这意味着你倾向于寻求规则和秩序，责任心强，值得信任，同时也容易被权力结构吸引。

与此同时，你的命盘中还有正财，这给了你一份不同的特质。正财代表的是务实和理性。虽然正官驱动你去追求秩序和责任，但正财让你的判断更加实际。你在经济上讲究原则，不会冲动消费。这也意味着虽然你守规则，但你有自己的判断标准，不是盲目服从。

### 第三层：行为表现（实际样子）

**任务**：把抽象性格具体化为行为，用段落叙述连贯的场景表现

结合日元和最强的十神，推导出在不同场景下的具体表现。用自然的因果关系连接，而不是列举。

**输出示例**：

在感情中，你是一个矛盾的伴侣。正官的守规则天性让你期待稳定的承诺而不是短期关系，你讲求誓言和承诺，希望伴侣能理解你的想法。但同时，正财的现实特质让你很在意生活的实际方面，对家庭的经济稳定有要求，不会为了感情而放弃理性。偏印给了你独特的思维方式，使得你在感情中显得有些冷静，有自己的想法，不太会甜言蜜语。综合起来，你是一个可靠但显得有些冷淡的伴侣，你需要找到一个既能理解你的独立性，又不会被你的冷静伤害的人。

在事业中，正官驱动你去追求规则和秩序，你适合需要严谨和责任的工作。正财让你的职业选择更加实际，你会选择能带来稳定收入的工作。偏印给了你不同的视角，让你能看到别人看不到的东西。这个组合最适合的职业是那些需要既要守规则又要有创新思维的工作——比如法律、财务管理或者企业改革。

### 第四层：内心世界（表里分析）

**任务**：看清真实自我vs社交面具，用段落叙述分析

比对年干和时干，分析内心特点和外在表现，评估表里一致度。特别注意：如果年干和时干都是同一个十神，这种现象叫"两头挂"，表示此人表里如一。

**特殊情况 - 两头挂**（年干和时干相同）：

当年干和时干都是同一十神时，这个人的内心和外在完全一致。比如两头都是食神，这个人就是表面内心都厚道随性；两头都是比肩，就是自信心都很高。这种人没有伪装，看起来是什么样，就是什么样。这是一种很直率的性格，优点是诚实，缺点可能是容易被人看透而不够神秘。

**普通情况 - 年干和时干不同**：

综合分析年干（内心特质）和时干（外在表现）两个十神的性格特点，说明这两个特质如何在这个人身上共同作用。不是简单地对比差异，而是找出两个十神的共同点或互补关系，以及它们如何塑造了这个人的整体性格。

**输出示例（差异型）**：

你的年干是丙火，时干是辛金。内心的你热情、外向、喜欢表现，真实想法很直接。但展现出来的你冷静、理性、有原则，不轻易表达感情。这两个特质的结合，使得你既有热情的驱动力，又有理性的约束力。你在冷静的外表下隐藏着热情，这让你显得成熟稳重，但同时也可能让伴侣感觉不到你的关心。你需要学会在适当的时候展现内心的热情，这样身边的人才能更理解你。

**输出示例（互补型）**：

你的年干是伤官，时干是正财。伤官代表的创造力和突破精神，与正财代表的务实和理性结合在一起，使得你既有创新的想法，又能把它们落地成实际的成果。内心的你充满创意和反叛精神，但展现出来时，你会用现实的、经济的角度去表达。这让你成为一个既有梦想又很脚踏实地的人，你的朋友们会觉得你既聪慧又可靠。

**输出示例（两头挂情况）**：

你的年干和时干都是食神，这是一种特殊的现象叫"两头挂"，表示你的内心和外在完全一致。你是一个表里如一的人，看起来是什么样，就是什么样。无论在陌生人还是熟人面前，你都表现得很一致。你是一个很诚实、很直率的人，不会伪装自己。这让别人很容易理解你，也容易被你的真诚打动。但同时，这也意味着你容易被人看透，没有神秘感，有时候会显得有些不够深沉。

### 第五层：综合评价（总结和建议）

**任务**：给出明确的行动方向，用自然的段落叙述优势、风险和建议

总结优势（来自强十神），指出风险（来自十神的消极面），推荐适配的环境，给出实际可行的发展建议。

**输出示例**：

你最大的优势是责任心强和务实理性。你的正官品质让你适合需要信任度的职位，在稳定的关系中表现突出。你的正财让你不容易因冲动而犯错，从长期看能稳定地积累成果。你的偏印给了你独特的视角和解决问题的不同方式，你有主见，不容易被人忽悠。

但你需要注意的是，过于守规则可能会让你容易错过创新的机会。你被框在既定的规则内，有时候不敢突破。你在感情中表现得有些冷淡，虽然内心渴望陪伴，但外表的理性掩盖了这一点，可能让伴侣感觉不到你的热情，产生误会。

最适合你的工作环境是金融、法律、行政等需要规范的领域，有明确目标和流程的组织，能让你发挥专业性和责任心。在感情上，你需要找一个能理解你内在热情的伴侣，与偏印或食神背景的人配合较好。你需要学会表达，在亲近的人面前放松，不要让冷静的外表隐藏了真实的自己。在人际方面，你在职业和正式场合表现最好。

我的建议是，保持你的责任心这个优势，但同时允许自己在适当的时候打破规则，不是所有规则都值得遵守。充分展现你的想法，不要总是保持沉默。在感情和工作中找到平衡，你的深思熟虑是很大的优势，但也要学会相信直觉。多与不同十神背景的人交流和学习，这会开阔你的视野，让你看到不同的人生可能性。

## 关键指导

### 在第2层（十神分析）中

从对应的十神skill中精选2-3条最相关的语录，但不要堆砌语录列表。用自然的语言解释这个十神对性格的具体影响，让语录成为支撑观点的证据，而不是列举。要生活化地表达，用具体的行为和例子说明，严格基于实际排盘数据中出现的十神。避免空泛的描述，要具体到人的实际行为表现。

### 在第3层（行为表现）中

这一层的关键是用自然的因果关系连接各个十神的影响。因为某个十神的特质，所以在感情中会有什么表现；因为另一个十神，在事业中又会有什么特点。不是分别描述各个十神，而是整体地推导出这个人在不同场景中的真实表现。比如，"你是一个可靠但有些冷淡的伴侣"，这是从正官的责任心、正财的务实，以及偏印的独特思维综合推导出来的整体印象，而不是三个特点的并列。

### 识别和处理年干时干的各种情况

在第四层中，一定要先检查年干和时干的关系。有三种情况：

**情况1：两头挂（年干和时干相同）**

立即识别为"两头挂"现象，重点强调"表里如一"。根据是哪个十神的两头挂，描述其性格特点：
- 两头都是食神 → 表里都厚道随性
- 两头都是比肩 → 表里都自信
- 两头都是伤官 → 表里都聪慧、反叛
- 两头都是正财 → 表里都务实、稳重
- 其他十神类推

不要强调差异，而是强调这个人的直率、诚实和容易被人理解的特点。

**情况2：对立型（两个十神性质完全相反）**

比如年干是伤官（创新反叛），时干是正官（守规则）。这种组合代表内心和外在的巨大冲突。要说明这个人的内在矛盾、挣扎，以及如何在两种倾向中平衡。

**情况3：互补型（两个十神性质互补）**

比如年干是伤官（创意），时干是正财（务实）。这种组合代表内心的想法能被现实约束，形成一个平衡的人格。要说明这两个特质如何共同作用，产生既有梦想又脚踏实地的性格。

**核心原则**：无论哪种情况，都要综合分析两个十神，而不是简单列举。找出它们的关系（相同、对立还是互补），然后用自然的语言描述这个人因为这个组合而形成的整体性格。

### 在第5层（综合评价）中

要总结出至少3个来自强十神的核心优势，同时指出至少2个需要注意的风险点，并说明具体的现象表现和改善方式。环境建议要具体而不是模糊的，要说明工作、感情和人际中分别最适合什么。发展建议要是用户能够实际执行的，不是空泛的鸡汤。

## 重要提醒

这份画像的可读性和流畅性至关重要。避免任何形式的列表、编号、符号或结构化的标记。整个报告应该读起来像是对一个人的深入了解和分析，而不是一份表格或问卷。段落之间要有逻辑递进，句子之间要连贯自然，就像在讲一个关于这个人的故事。

性格是倾向而不是决定，个人努力和环境变化会改变表现，年龄和经历也会改变某些特征。这份画像用于参考和自我认知，不用于刚性的决策判断。基于排盘数据进行分析，如果排盘数据不准确，结果可能会有偏差。

这是一个**串联skill**，通过智能调用其他10个skill，将离散的语录和分析组织成连贯的、结构化的、有深度的人物画像。关键在于**串联的质量** - 不是堆砌信息，而是用自然语言和逻辑链接，让最终的画像读起来像是对一个真实的人的理解。
