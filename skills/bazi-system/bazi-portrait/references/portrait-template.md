# 人物画像生成 - 示例模板

本文档展示人物画像生成的标准格式和内容结构。

## 人物画像的5层结构

### 层级1：核心身份（日元）
**作用**：建立人物的性格基调

```
你是一个[日元特征]的人。
你的核心性格特征是[具体描述]。

这意味着在做决定时，你倾向于[行为特点]。
```

**典型语录来源**：日元本身的含义而非十神

---

### 层级2：性格侧面（十神）
**作用**：展现人物的多维特点

```
最强十神【正官】- 出现1次
├─ 描述：你在正官方面的表现很突出
├─ 语录1："你是一个守规则、有责任心的人"
├─ 语录2："在有约束的环境中，你能更好地发挥作用"
└─ 含义：正官旺，你倾向于寻求规则和秩序

次强十神【正财】- 出现1次
├─ 描述：正财为次要特征
├─ 语录："你处理钱财很有分寸"
└─ 含义：现实和务实的一面

第三十神【偏印】- 出现1次
├─ 描述：隐藏的智慧特质
├─ 语录："你有独特的想法和思维方式"
└─ 含义：不多显露但很有深度
```

**数据来源**：对应十神skill中的语录库

---

### 层级3：行为表现（实际样子）
**作用**：把抽象的性格具体化为行为

```
【在感情中】
- 因为正官强，你在感情中：
  • 期待稳定和承诺
  • 会主动承担责任
  • 可能显得有些保守
- 因为正财存在，你还会：
  • 很在意生活的实际方面
  • 对家庭的经济稳定有要求

【在事业中】
- 正官使你：
  • 遵守规则，按部就班
  • 适合需要责任心的工作
  • 容易被权力结构吸引
- 正财使你：
  • 很务实，不好高骛远
  • 能稳定地累积财富

【在人际中】
- 整体表现：
  • 你是一个可靠的人
  • 他人觉得你有分寸感
  • 你容易被信任

【在生活中】
- 你的日常特点：
  • 生活有规律
  • 消费理性
  • 很重视家庭和稳定
```

**生成方式**：综合第一层和第二层，用"因为...所以..."的逻辑链接

---

### 层级4：内心世界（表里分析）
**作用**：看清真实自我vs社交面具

```
【真实的你】（年干代表）
- 年干：甲木
- 真实性格：有想法、有主见、希望自由

【展现出来的你】（时干代表）
- 时干：辛金
- 社交面具：冷静、理性、有原则

【表里对比】
- 表里一致度：中等
- 内心的热情 vs 外表的冷静
- 这可能让人误解你的真实想法
- 建议：适度展现内心，增加被理解的可能性
```

**数据来源**：年干和时干的特征

---

### 层级5：综合评价（总结）
**作用**：给出明确的建议和方向

```
【核心优势】
✅ 责任心强（正官）
   → 适合需要信任度的职位
   → 在稳定关系中表现突出
   
✅ 务实理性（正财）
   → 不容易因冲动而犯错
   → 长期看能积累成果
   
✅ 思维独特（偏印）
   → 有独特视角和解决方案
   → 不从众，有主见

【需要注意】
⚠️ 可能过于守规则
   → 容易错过创新机会
   → 在需要突破时显得保守
   
⚠️ 感情可能显得冷淡
   → 表里反差大
   → 需要主动表达

⚠️ 容易被权力吸引但也容易受约束
   → 要明确自己真正要什么

【最适合的环境】
🎯 工作
   - 金融、法律、行政等需要规范的领域
   - 有明确目标和流程的组织
   - 能发挥专业性的工作

🎯 感情
   - 找一个能理解你内在热情的人
   - 与偏印或食神的人配合较好
   - 需要多表达和沟通

🎯 人际
   - 在职业和正式场合表现最好
   - 建议在亲近的人面前放松
   - 不要让冷静的外表隐藏了真实

【发展建议】
1. 保持你的责任心，但允许自己有时候打破规则
2. 充分展现你的想法，不要总是沉默
3. 在感情和工作中找到平衡
4. 你的深思熟虑是优势，学会相信直觉
5. 与不同十神背景的人交流，开阔视野
```

## 人物画像的特点

### 准确性保证
- ✓ 基于排盘数据
- ✓ 来自353条实战语录
- ✓ 多维度交叉验证

### 可读性特征
- ✓ 从抽象到具体的逻辑链
- ✓ 用具体例子说明
- ✓ 避免堆砌信息

### 实用性体现
- ✓ 明确的优势分析
- ✓ 可行的建议
- ✓ 适配的环境描述

---

## 生成画像的核心逻辑

```
排盘结果
  ↓
日元分析 (第1层)
  ↓
十神强弱排序 (第2层)
  ↓
逻辑推导行为表现 (第3层)
  ↓
年干时干对比 (第4层)
  ↓
综合得出建议 (第5层)
  ↓
完整人物画像
```

---

## 使用这份画像的建议

1. **自我认知**：对照自己，看是否符合
2. **他人理解**：给朋友/伴侣看，加深理解
3. **发展方向**：按建议调整，改进不足
4. **决策参考**：在重大选择时参考相关特点
5. **人际指导**：理解与他人的差异，改善关系

---

## 画像的局限性

- 性格是倾向，不是决定
- 个人努力和环境变化会改变表现
- 年龄和经历会改变某些特征
- 用于参考，不用于刚性决策
