# 八字穿搭风格判断

## 用途

根据年柱天干地支+十神，判断穿衣风格、色调、面料。

## 核心原理

**年柱是公众形象对外显——正式场合的穿搭、别人见你时的第一印象。**

- **天干为表**：定整体风格、主色调、气质轮廓
- **地支为里**：定面料质感、版型细节、底层偏好

## 五、使用原则

### 十神叠加修正
- 正官正印更收敛
- 七杀伤官更外放
- 财星重质感
- 比劫重休闲

### 喜忌影响
- 年柱为喜用神 → 主动强化风格
- 年柱为忌神 → 驾驭不佳或刻意回避

### 分层逻辑
- 年柱 → 公开形象（陌生人第一印象、正式场合）
- 月柱 → 日常社交层（同事熟人面前通勤/日常穿搭）
- 日柱 → 私密本我层（居家独处、亲密关系中的真实审美）
- 时柱 → 深层隐秘层（小众私密审美，仅亲近者可见）

### 特别说明
- 后天职业、环境、阅历对穿搭影响显著，命理仅为象法参考
- 年柱仅代表公开形象，卧室穿搭不在其列
- 如果年柱十神是忌神，会刻意回避该风格
- 癸水日元和食伤弱的人：适应能力强，对穿搭不太讲究，衣柜可能都是黑白灰
