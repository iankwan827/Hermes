# 八字断事流程

## 核心原则

**宫位为主，星神为辅。先看宫位状态，再用宫位上的十神判断该六亲/事件的处境。**

---

## 核心问题

四柱宫位代表"位置"（哪里），十神代表"星"（谁）。当宫位和星不一致时，到底看哪个？

**答案：宫位为主，星神为辅。先看宫位状态，再看宫位上的十神。**

---

## 断事流程（6步）

```
Step 1: 确定要断什么（六亲/事件）
Step 2: 找到对应的宫位（年祖/月父/日配/时子）
Step 3: 看宫位本身的旺衰、冲克、空亡
Step 4: 看宫位上的十神 → 用这个十神判断该六亲/事件的处境
Step 5: 找该六亲的星在哪 → 辅助验证
Step 6: 综合判断
```

---

## 一、宫位上的十神→该六亲的处境

| 宫位上的十神 | 该六亲的处境 |
|-------------|-------------|
| 正官/正印/正财 | 该六亲状态好，关系融洽 |
| 七杀 | 该六亲带来压力/冲突 |
| 伤官 | 该六亲与命主有口舌/叛逆 |
| 比肩/劫财 | 该六亲与命主竞争/争夺 |
| 食神 | 该六亲让命主舒服/受益 |
| 偏印 | 该六亲让命主压抑/约束 |
| 偏财 | 该六亲有意外助力 |

**具体例子**：

| 场景 | 判断 |
|------|------|
| 月柱（父母宫）有七杀 | 父母带来压力，与父母关系紧张 |
| 月柱有伤官 | 与父母有口舌，叛逆期长 |
| 月柱有正印 | 母亲缘分好，母亲保护命主 |
| 日柱（夫妻宫）有七杀 | 配偶带来压力，婚姻有冲突 |
| 日柱有比肩 | 配偶与命主竞争，各不相让 |
| 时柱（子女宫）有伤官 | 子女叛逆，与子女有口舌 |

---

## 二、宫位状态判断

| 宫位状态 | 该六亲的处境 |
|---------|-------------|
| 宫位旺相 | 该六亲有力，对命主帮助大 |
| 宫位衰弱 | 该六亲无力，对命主帮助小 |
| 宫位空亡 | 该六亲缘分薄，聚少离多 |
| 宫位被冲克 | 该六亲受伤害/变动/关系不稳 |
| 宫位被合 | 该六亲与命主有缘分/牵绊 |

## 三、六亲星速查

### 男命六亲星

| 六亲 | 正星 | 偏星 |
|------|------|------|
| 父亲 | — | **偏财** |
| 母亲 | 正印 | 偏印（枭神） |
| 兄弟 | 比肩 | 劫财 |
| 妻子 | 正财 | 偏财 |
| 子女 | 正官（头胎男） | 七杀（头胎女） |

### 女命六亲星

| 六亲 | 正星 | 偏星 |
|------|------|------|
| 父亲 | — | 偏财 |
| 母亲 | 正印 | 偏印（枭神） |
| 兄弟 | 比肩 | 劫财 |
| 丈夫 | 正官 | 七杀 |
| 子女 | 食神（头胎女） | 伤官（头胎男） |

## 四、关键区分：宫位天干 vs 整个宫位

**父亲宫位 = 月柱天干**（不是整个月柱）

| 概念 | 说明 |
|------|------|
| 父亲宫位 | **月柱天干**的位置 |
| 宫位上的十神 | 月柱天干是什么十神（如辛金=食神） |
| 作用关系 | 宫位天干对该六亲星的生克关系 |

**判断方法：**
1. 找父亲宫位 → 月柱天干
2. 看月柱天干是什么十神（如辛金=食神）
3. 看这个十神对父亲星（偏财）的作用关系
4. 宫位天干**生**父亲星 → 父亲有助力，问题不大
5. 宫位天干**克**父亲星 → 父亲受压制，问题较大

## 五、实例解析

**19870912男命**：
- 年柱：丁卯（伤官+劫财）
- 月柱：己酉（正财+正官）
- 日柱：甲子（日主+正印）
- 时柱：丁卯（伤官+劫财）

**断父亲**：
- Step 1: 父亲 → 看月柱（父母宫）
- Step 2: 月柱己酉（正财+正官）
- Step 3: 月柱被年支卯木冲 → 父母宫受冲，父母关系不稳定
- Step 4: 月柱有正财和正官 → 父母宫有财星和官星，父亲与财运/事业相关
- Step 5: 父星偏财不见 → 父亲信息弱，父亲缘薄
