# 八字看财运

> 来源：十神体系 + 讲师财运专题

## 一、十神与财运对应

| 十神 | 财运类型 | 核心特征 | 赚钱方式 |
|------|----------|----------|----------|
| 正财 | 稳定收入 | 稳定、务实、工资型 | 固定工作、工资、不动产收益 |
| 偏财 | 意外之财 | 投机、灵活、爆发型 | 投资、中奖、兼职、意外横财 |
| 食伤生财 | 才华赚钱 | 食伤是财根，靠才华吃饭 | 创意、技术、口才、手艺变现 |
| 比劫夺财 | 破财合伙 | 争抢、合伙失败 | 合伙破财、朋友借钱不还、竞争失利 |

### 讲师语录

> 🎙️ "正财 = 稳定工作，上班拿工资。"
>
> 🎙️ "偏财 = 彩票、意外之财、投机。"
>
> 🎙️ "食伤生财 = 食伤是财根，靠才华赚钱。"
>
> 🎙️ "比劫夺财 = 感情易有第三者，合伙易破财。"

## 二、财运层次判断：四要素

> 🎙️ **讲师：** "看财运记好了，真正能上几千万以上的必须有**架构**，有**力量**，有**护卫**，有**大运**。架构就是格局，有格局必然人生有成就，有了架构再有力量代表有事业必然高度，有护卫在于财星为自己专享，有大运引动就是发财的时机。"

| 要素 | 含义 | 判断标准 |
|------|------|----------|
| **架构**（格局） | 八字格局清晰、有层次 | 有正格、成格、破格→格局决定人生天花板 |
| **力量** | 财星及生财力量的旺衰 | 财星有根有力，食伤生财有力 |
| **护卫** | 财星为自己专享，不被争夺 | 财星不被比劫夺、不被官杀泄、日主能担财 |
| **大运** | 大运引动发财时机 | 行财运、食伤运→发财时机到来 |

### 财运层次速断

- **大富**：架构 + 力量 + 护卫 + 大运 → 四者齐备，千万以上
- **中富**：有架构 + 有力量 + 大运配合 → 百万级别
- **小富**：有财星但力量不足或缺护卫 → 稳定小康
- **穷命**：无财星或财星为忌、被比劫夺 → 求财辛苦

## 三、财星合身：天生与财神爷有缘

> 🎙️ **讲师：** "财星合身：财星和自己相合，天生求财运势就很好。"

### 财星合身的含义

- 财星与日干相合（天干五合或地支六合）
- 命主天生与财有缘，求财容易
- 财主动找上门，不用太费力就能赚钱
- 财星合身且为用神 → 财运极佳
- 财星合身但为忌神 → 被财所困、因财生灾

### 财星合身类型

| 合类型 | 表现 |
|--------|------|
| 财星合日干（天干） | 财主动靠近，求财容易 |
| 财星合日支（地支） | 家庭内部有财，配偶带财 |
| 财星合身有力 | 财运旺盛，赚钱能力强 |
| 财星合身无力 | 有财但担不住，来得快去得快 |

## 四、成不了大事业的特征

### 1. 财星争合日元

> 🎙️ **讲师：** "财星挣合日元者赚钱的商机较多，若财星争抢着合日元，命主就有种吃着碗里瞧着锅里的感觉。"

- 财星多且争抢着合日元 → 赚钱机会多但心不定
- 吃着碗里瞧着锅里 → 什么都想要，最后什么都没抓住
- 财星争合 → 容易错失良机、贪多嚼不烂

### 2. 八字阴寒湿气太重

> 🎙️ **讲师：** "八字阴寒湿气太重者做事比较消极，缺乏积极向上的激情欲望。"

- 阴寒湿气重 → 做事消极、缺乏激情
- 没有积极向上的欲望 → 求财动力不足
- 表现：懒散、拖延、提不起劲、缺乏野心
- 化解：行火运/暖局运可改善

## 五、身强身弱与财运

### 核心原则：身旺能担财，身弱财压身

| 身强身弱 | 财运表现 | 解读 |
|----------|----------|------|
| 身旺财旺 | 财运极佳 | 能力强 + 机会多 → 大富之命 |
| 身旺财弱 | 有能力但机会少 | 有能力赚钱但缺机会，需行财运 |
| 身弱财旺 | 财多身弱 | 想赚钱但扛不住，心有余力不足 |
| 身弱财弱 | 求财辛苦 | 能力不足 + 机会少 → 劳碌命 |

### 财多身弱详解

> 🎙️ 讲师："财多身弱 = 想赚钱但扛不住。"

- 日主弱而财星旺 → 财多身弱
- 表现：赚钱机会在眼前但抓不住
- 容易为钱所困、因财生灾
- 财多身弱者不宜走财运 → 越走越累
- 化解：走印运/比劫运 → 增强自身力量后再求财

### 讲师语录

> 🎙️ "身弱不担财，财再多也是别人的。"
>
> 🎙️ "身旺的人扛得住财，身弱的人被财压垮。"

## 六、实战断财运流程

```
第一步：判断身强身弱 → 决定能否担财
第二步：看财星类型 → 正财（稳定）还是偏财（意外）
第三步：看财星力量 → 有根有力 vs 无根虚浮
第四步：看护卫情况 → 比劫夺财？官杀泄财？
第五步：看大运引动 → 何时行财运/食伤运
第六步：综合判断 → 财运层次（大富/中富/小富/穷命）
```

---

## Pitfalls

- **身弱不担财**：财多身弱是大忌，越多越累
- **比劫夺财**：合伙、朋友借钱要小心
- **财星争合**：机会太多反而抓不住，贪多嚼不烂
- **阴寒湿气**：八字偏寒者求财动力不足，需暖局
- **食伤生财**：必须食伤有根，否则只是空想
- **大运引动**：命中有财但大运不配合，也是白搭
- 财星为用则吉，为忌则凶——不能孤立看财星旺衰
- 财运层次必须四要素（架构+力量+护卫+大运）齐备才能上大富
