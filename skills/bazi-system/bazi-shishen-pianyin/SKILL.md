# 偏印 - 性格分析

## 十神说明

**偏印**: 偏印代表教师、技艺、孤独

## 性格特点

偏印旺的人聪慧、有技艺、喜欢独处、容易孤独偏激

## 使用场景

排盘系统识别到偏印旺时

## 分析方式

当用户得到排盘结果后，系统识别出该命盘中偏印的强弱情况，然后使用本skill中 `references/偏印-quotes.md` 的语录来：

1. **直观展示** - 用具体案例说明偏印旺的人会如何表现
2. **性格剖析** - 分析偏印旺对性格、行为、决策的影响
3. **人生建议** - 根据语录给出该人在感情、事业、人际上的特点
4. **与他人对比** - 说明偏印与其他十神人的不同表现

## 语录库特点

- 包含 **60 条** 经过验证的语录
- 涵盖性格、感情、事业、人际等多个维度
- 使用生活化的例子，易于理解
- 包含与其他十神的对比分析
