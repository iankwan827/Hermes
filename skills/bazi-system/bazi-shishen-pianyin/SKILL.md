# 偏印专题

## 核心定义

- **阴阳**：同性相生（生我），阳见阳/阴见阴
- **本质**：冷淡的资助，如继母养子
- **性格**：内敛、多疑、专研、有创造力、适合玄学
- **代表**：偏门老师、专长、技艺、宗教、玄学
- **为用时**：有独特才华、适合技术/玄学
- **为忌时**：思想偏激、性格古怪、枭神夺食（克制食神）
- **枭神夺食**：大凶组合，才华被压制、做事反复
