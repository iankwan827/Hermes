# 劫财专题

## 核心定义

- **阴阳**：异性同类（同我），阳见阴/阴见阳
- **本质**：竞争的伙伴，如兄弟争利
- **性格**：豪爽、冲动、喜欢冒险、朋友多、义气
- **代表**：姐妹、合伙人、竞争、破财
- **为用时**：得意外帮助、有魄力、敢闯
- **为忌时**：破财、感情有第三者、冲动惹祸
