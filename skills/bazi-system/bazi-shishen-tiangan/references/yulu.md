- **Day13** 3. 卯是日出之门，酉是日落之门，日升月落，日落月升，光线暖昧，此冲又为 桃花咸池之中，此冲主地域迁移，背信弃义，忧愁多劳，或有色情纠纷。在病理 上主要会出现胃病、肝病、出汗、恶寒、开刀。 卯酉相冲，酉中辛金克卯中乙木，在感情上指人多会有艳事或外遇或情感纠纷。 在病体上指肝胆及肺部或筋骨之疾病，若日、时卯酉相冲，主有刺骨之痛，会有 动手术、流血、开刀剖腹产。 卯酉相冲，再见天干癸乙壬，主男女私情。卯酉为日出日落之门户，水火沐浴之 所，为咸池桃花所居之地。癸为玄武癸亥水主偷窃，乙为六合乙卯木主私情，壬 为天后壬子水为淫女，故合主男女私情。
- **Day60** 4. 丙申，丁酉，虽然都是火金组合，但在克金的作用还是有差别的，丁酉如果 遇到辛金，庚金，克金会比丙申克的更直接，更厉害。
