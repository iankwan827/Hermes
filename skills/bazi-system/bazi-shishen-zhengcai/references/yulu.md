# 正财语录集

## 性格（1条）

- **Day49** 1. 正神指正财，正官，正印，食神。 正神多的男人一般脾气比较温和，脾气比较好，能够控制情绪，做事有原则底 线，不会做出太出格的事情，不用太担心什么赌博，家暴，熏酒，打人之类的事 情。 不过正神多的男生，一般也会缺乏一些生活情趣，一板一眼。

- **Day35** 2. 食伤男谈恋爱的心态是，我喜欢你就要对你付出钱财，感情，一切以你为主， 食伤男会有些舔狗，在女朋友面前会脾气比较好，尤其是食神生正财的，但食伤 男也容易不稳定，容易喜新厌旧，喜欢别人。

## 事业（2条）

- **Day27** 5. 财星合身： 财星和自己相合，就是八字命局当中的正财或偏财与出生日的天干相合。 这种八字的人，就是属于天生与财神爷有缘分的人，天生求财运势就很好。 这样的人不仅求财容易，而且不管是在工作还是生意中，都更加顺利，不会缺钱 花。 一生财源滚滚，不用为财运发愁。同时容易获得意外之财，所以，这样的人也是 属于求财比较容易的人。
- **Day28** 2. 枭神有制为偏印，主服务、所以综合为带有技术含量的服务行业，或者用技 术、知识从事服务别人的职业。 用财星驾驭枭神的组合中，用偏财与枭神都是同性相克的，有根为真时，能制住 枭神，层次就高。 用正财去驾驭枭神时，当日主为阴干时，正财为合克枭神，只要力量不是很弱， 都能合克住。 当日干为阳干时，则阴干财星来克阳干枭神，会有一定的难度，但财星是吉神， 虽弱，但只要为真，就能制克住枭神，但是格局层次不高。
