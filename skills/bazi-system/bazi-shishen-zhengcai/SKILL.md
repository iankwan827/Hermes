# 正财专题

## 核心定义

- **阴阳**：异性相克（我克），阳见阴/阴见阳
- **本质**：稳定的收获，如工资收入
- **性格**：节俭、务实、家庭感强、重视稳定
- **代表**：正妻（男命）、稳定收入、不动产
- **为用时**：财运稳定、重视家庭、务实
- **为忌时**：物质欲望低、过于保守
