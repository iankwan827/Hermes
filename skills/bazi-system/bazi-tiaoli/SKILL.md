# 八字调理方案

> 核心：用神喜忌 → 五行补泄 → 行事策略 → 择时风水 → 知行合一
> **框架skill，具体细节由其他skill提供**

## 一、五行补泄方案

### 原则
- **身弱** → 补用神五行（印星/比劫方向）
- **身旺** → 泄忌神五行（食伤/财星/官杀方向）
- **调候** → 补调候用神（冬补火、夏补水）
- **格局忌神** → 首要回避

### 1. 五行 × 颜色

| 五行 | 主色 | 辅色 | 忌色 |
|------|------|------|------|
| 金 | 白、银 | 金、香槟 | 红、紫（火克金） |
| 木 | 绿、青 | 浅绿、翠 | 白、金（金克木） |
| 水 | 黑、蓝 | 深蓝、灰 | 黄、棕（土克水） |
| 火 | 红、紫 | 橙、粉 | 黑、蓝（水克火） |
| 土 | 黄、棕 | 咖啡、驼色 | 绿、青（木克土） |

**用法**：喜用神五行 → 多用该色；忌神五行 → 避免该色。

### 2. 五行 × 数字

| 五行 | 吉数 | 忌数 |
|------|------|------|
| 金 | 4、9 | 2、7（火数） |
| 木 | 3、8 | 4、9（金数） |
| 水 | 1、6 | 5、0（土数） |
| 火 | 2、7 | 1、6（水数） |
| 土 | 5、0 | 3、8（木数） |

**用法**：手机号尾数、楼层选择、车牌号等。

### 3. 五行 × 方位

| 五行 | 方位 | 适宜发展城市方向 |
|------|------|------------------|
| 金 | 西方 | 西部地区（如成都、西安） |
| 木 | 东方 | 东部地区（如上海、杭州） |
| 水 | 北方 | 北部地区（如北京、天津） |
| 火 | 南方 | 南部地区（如广州、深圳） |
| 土 | 中央 | 中部地区（如武汉、郑州） |

**用法**：工作生活方位、床头朝向、办公桌位置。

### 4. 五行 × 饮食

| 五行 | 适宜食物 | 代表食物 |
|------|---------|---------|
| 金 | 辛辣、白色食物 | 萝卜、梨、莲藕、鸡胸肉 |
| 木 | 酸味、绿色食物 | 绿叶菜、醋、柠檬、芽菜 |
| 水 | 咸味、黑色食物 | 黑豆、黑芝麻、海带、紫菜 |
| 火 | 苦味、红色食物 | 红枣、番茄、牛肉、辣椒 |
| 土 | 甘味、黄色食物 | 小米、南瓜、红薯、玉米 |

**用法**：食补方向，注意过犹不及，适量即可。

### 5. 五行 × 饰品

| 五行 | 材质 | 形状 | 注意 |
|------|------|------|------|
| 金 | 金属、玉石 | 圆形 | 忌火旺之人戴 |
| 木 | 木质、草编 | 长条形 | 忌金旺之人戴 |
| 水 | 水晶、珍珠 | 波浪形 | 忌土旺之人戴 |
| 火 | 红宝石、玛瑙 | 三角形 | 忌水旺之人戴 |
| 土 | 陶瓷、琥珀 | 方形 | 忌木旺之人戴 |

**用法**：日常佩戴、家居摆件。

### 6. 五行 × 行业

| 五行 | 适宜行业 |
|------|---------|
| 金 | 金融、银行、珠宝、机械、汽车、法律、军警 |
| 木 | 教育、文化、出版、医药、园艺、服装、家具 |
| 水 | 物流、旅游、传播、航运、饮料、水产、咨询 |
| 火 | 电子、传媒、餐饮、美容、娱乐、能源、互联网 |
| 土 | 房地产、建筑、农业、矿业、仓储、中介、石材 |

**用法**：职业选择、投资方向。身弱用木→选木属行业；身旺需泄→选克泄耗的行业。

## 二、行事策略

### 核心原则
> 用神年份主动出击，忌神年份保守防守，闲神年份正常节奏。

### 1. 用神大运/流年 → 顺势而为

| 用神类型 | 行事要点 |
|----------|---------|
| 用印星 | 利学习考试、求贵人、考试升职、拜师学艺、签订合同 |
| 用比劫 | 利合作合伙、朋友帮忙、团队协作、竞争上岗 |
| 用食伤 | 利创作表达、创业创新、才艺展示、子女相关 |
| 用财星 | 利投资理财、买卖交易、谈合作、谈感情 |
| 用官杀 | 利升职加薪、官方事务、考公考编、品牌建设 |

### 2. 忌神大运/流年 → 守正待时

| 忌神类型 | 回避事项 |
|----------|---------|
| 忌印星 | 不宜过度依赖、避免懒散、不要频繁换方向 |
| 忌比劫 | 不宜合伙、避免冲动消费、远离损友 |
| 忌食伤 | 不宜口舌争辩、避免叛逆冲动、低调行事 |
| 忌财星 | 不宜大额投资、避免贪心投机、不借钱给人 |
| 忌官杀 | 不宜冒进、避免惹是非、遵守规则 |

### 3. 各阶段行事导向

| 阶段 | 策略 | 关键词 |
|------|------|--------|
| 早年运（1-16岁） | 看印星→父母教育环境 | 养正气 |
| 青年运（17-32岁） | 看食伤/官杀→学业事业起步 | 立根基 |
| 中年运（33-48岁） | 看财星/官杀→事业财运高峰 | 收成果 |
| 晚年运（49岁+） | 看印星/比劫→健康子女福报 | 安晚景 |

### 4. 十神行事原则

| 十神为用 | 行事 | 十神为忌 | 回避 |
|----------|------|----------|------|
| 正官 | 踏实本分、听从安排 | 正官 | 避免体制约束、不走仕途 |
| 七杀 | 以攻代守、主动挑战 | 七杀 | 避免对抗、远离小人 |
| 正印 | 读书进修、求师问学 | 正印 | 避免依赖、独立思考 |
| 偏印 | 钻研技艺、冷门领域 | 偏印 | 避免偏激、减少胡思乱想 |
| 比肩 | 合作共赢、并肩同行 | 比肩 | 避免竞争、独立发展 |
| 劫财 | 借力发力、借势而行 | 劫财 | 避免合伙、谨慎交友 |
| 食神 | 享受生活、培养才艺 | 食神 | 避免放纵、控制食欲 |
| 伤官 | 锐意进取、创新突破 | 伤官 | 避免口舌、收敛锋芒 |
| 正财 | 稳健理财、勤劳致富 | 正财 | 避免贪财、不赌博 |
| 偏财 | 适度投机、广结善缘 | 偏财 | 避免贪心、不借债投资 |

## 三、择时建议

### 核心原则
> 大事看流年大运，小事看月份时辰。用神到位时择吉，忌神当令时回避。

### 1. 结婚择时

| 条件 | 建议 |
|------|------|
| 男命 | 选财星为用且到位的年份；避开比劫旺的年份 |
| 女命 | 选官星为用且到位的年份；避开伤官旺的年份 |
| 通用 | 选合日支的流年；避开冲日支的流年 |
| 避开 | 桃花过旺年份（易有第三者）、官杀混杂/比劫夺财年份 |

### 2. 开业/创业择时

| 条件 | 建议 |
|------|------|
| 身弱 | 选印星/比劫旺的年份开业（有人帮、有靠山） |
| 身旺 | 选食伤/财星旺的年份开业（精力旺、利求财） |
| 通用 | 官杀为用→选有贵人提拔的年份；食伤为用→选有创意灵感的年份 |
| 避开 | 忌神到位年份、大运交接年份（不稳定） |

### 3. 搬家/购房择时

| 条件 | 建议 |
|------|------|
| 喜用方向 | 朝喜用神方位搬家；选喜用神五行的楼层 |
| 搬家月份 | 选印星或比劫旺的月份（安稳、有人帮忙） |
| 避开 | 冲太岁年份、忌神当令月份 |

**楼层五行参考**：
- 1、6层 → 水
- 2、7层 → 火
- 3、8层 → 木
- 4、9层 → 金
- 5、10层 → 土

### 4. 投资/理财择时

| 条件 | 建议 |
|------|------|
| 用神为财星 | 财星到位年份可大胆投资 |
| 用神为食伤 | 食伤生财年份适合创业型投资 |
| 忌神为财星 | 不宜大额投资、保守理财 |
| 忌神为比劫 | 不宜合伙投资、避免冲动消费 |

### 5. 求职/考试择时

| 条件 | 建议 |
|------|------|
| 用印星 | 利考试升学、学历提升 |
| 用官杀 | 利考公考编、升职面试 |
| 用食伤 | 利创意类考试、才艺展示 |
| 忌官杀 | 不宜体制内竞争、低调行事 |

## 四、风水环境调整

### 原则
> 用神五行的方位和元素加强，忌神五行的方位和元素减弱。

### 1. 办公/家居方位

| 用神 | 有利方位 | 摆放建议 |
|------|---------|---------|
| 金 | 西方 | 放金属摆件、白色装饰 |
| 木 | 东方 | 放绿植、木质家具 |
| 水 | 北方 | 放鱼缸、流水摆件 |
| 火 | 南方 | 放灯光、红色装饰 |
| 土 | 中宫 | 放陶瓷、石材摆件 |

### 2. 卧室调整

| 调整项 | 喜用神五行方向 |
|--------|--------------|
| 床头朝向 | 朝喜用神方位 |
| 被褥颜色 | 喜用神主色 |
| 窗帘 | 喜用神辅色 |
| 灯光 | 用神为火→暖光；用神为水→冷光 |

### 3. 办公室调整

| 调整项 | 建议 |
|--------|------|
| 办公桌位置 | 面朝喜用神方位；背靠实墙 |
| 桌面摆件 | 用神五行对应材质（金→金属、木→绿植等） |
| 背景墙 | 喜用神颜色 |
| 植物 | 用神为木→绿植；用神为水→水培植物 |

### 4. 商铺/公司风水

| 调整项 | 建议 |
|--------|------|
| 大门朝向 | 朝喜用神方位 |
| 招牌颜色 | 喜用神主色 |
| 收银台位置 | 喜用神方位或中宫 |
| 装修色调 | 以喜用神五行为主 |

### 5. 注意事项

- **过犹不及**：补泄要适度，忌补过头（如喜水但水太多反成灾）
- **动态平衡**：流年变化，调整方案也要随之微调
- **结合实际**：风水调整是辅助，不能替代自身努力
- **十神对应**：每个十神对应特定五行，调理时要考虑十神层面的影响（如用正官→也要考虑财星是否能生官）

## 五、五元素关联速查

### 五行 × 十神 × 调理

| 十神 | 五行属性（以日主甲木为例） | 调理方向 |
|------|--------------------------|---------|
| 正官（辛金） | 金 | 补金→白色、西方、金属行业 |
| 七杀（庚金） | 金 | 补金→同上（但七杀偏刚） |
| 正印（癸水） | 水 | 补水→黑色、北方、物流旅游 |
| 偏印（壬水） | 水 | 补水→同上（但偏印偏冷） |
| 比肩（甲木） | 木 | 补木→绿色、东方、教育文化 |
| 劫财（乙木） | 木 | 补木→同上（但劫财偏动） |
| 食神（丙火） | 火 | 补火→红色、南方、电子传媒 |
| 伤官（丁火） | 火 | 补火→同上（但伤官偏烈） |
| 正财（己土） | 土 | 补土→黄色、中央、房地产 |
| 偏财（戊土） | 土 | 补土→同上（但偏财偏散） |

> **注意**：具体日主的十神五行对应不同，以上仅为示例。实际调理需根据排盘结果确定。

### 五行生克与调理

| 关系 | 调理含义 |
|------|---------|
| 用神生喜神 | 两者同时补，形成良性循环 |
| 用神克忌神 | 补用神的同时自然压制忌神 |
| 忌神克用神 | 需要化解（印化杀、食伤制杀） |
| 忌神泄用神 | 减少忌神出现的环境 |

> "调理不是迷信，是让你的生活环境和行为方向跟你的命理能量同频。"
> "用神到位的时候要抓住机会，忌神当令的时候要学会蛰伏。"
> "颜色方位这些是辅助，最核心的是心态和行为的调整。"
> "身弱的人不要硬撑，找合伙人（比劫）、找靠山（印星）才是正道。"

## Pitfalls

- 调理方案必须基于正确的用神判定，用神判错则全盘皆错
- 补泄要适度，过犹不及（如喜水但水太多反成灾）
- 风水调整是辅助手段，不能替代个人努力
- 流年变化，调理方案要随之微调，不能一成不变
- 男女命调理有差异（如男命重点看财星、女命重点看官杀）
- 调候优先级高于旺衰，冬生人即使身弱也要先考虑调候
