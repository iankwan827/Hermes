# 八字分析写作指导

## 核心原则

分析报告不是语录拼盘，是**有逻辑的推理过程**。每一段都要回答：这个特征→导致什么行为→产生什么结果。

## 写作框架

### 1. 开篇定调（1-2句）

用一句话概括命主的核心特征，像写人物简介。

示例：
- "丁火日主，食神透出且旺，是个内心丰富但表面淡定的人。"
- "甲木身强，七杀透干有制，是个有魄力但压力也不小的人。"

### 2. 性格分析（3-5句）

不要罗列特质，要**讲故事**。用"所以"、"因此"、"这导致"串联。

错误写法：
> 食神旺，性格温和，有才华，口福好，适合艺术。

正确写法：
> 食神旺的人，能量释放温和，不张扬但有深度。她做事情凭感觉，喜欢就全力以赴，不喜欢就提不起劲。这种人适合需要创造力的工作，比如写作、设计、教育——因为她们的才华是内敛型的，厚积薄发。

### 3. 感情/事业分析（3-5句）

要结合具体组合，不能只说"食神旺→如何"。

示例组合分析：
> 她的食神虽然旺，但没有财星引导（食伤生财），所以才华虽然有，但很难变现。加上食神克了官星（食伤见官），感情上容易挑剔对方，总觉得自己值得更好的。建议找一个能让她崇拜的对象，否则容易"瞧不起就是伤官见官"。

### 4. 建议/提醒（1-2句）

给出可操作的建议，不要空洞的"注意身体"。

示例：
> 食神旺的人最怕枭神夺食，如果大运走偏印，要特别注意才华被压制、心情低落的情况。这段时间适合低调积累，不适合高调表现。

## 常见写作错误

| 错误 | 正确做法 |
|------|----------|
| 堆砌语录，一条接一条 | 用因果关系串联，像讲故事 |
| 只说结论不说原因 | 先说八字特征，再说行为表现，最后说结果 |
| 每个十神独立分析 | 要看十神之间的互动（食神克官、食伤生财等） |
| 用"可能"、"也许"太多 | 有依据时用肯定语气，不确定时说明条件 |
| 用古文/文言文 | 用现代白话，口语化，像跟朋友聊天 |

## 串联技巧

用以下连接词让分析流畅：
- **因为**...所以...（因果）
- **这意味着**...（解释）
- **但问题是**...（转折）
- **如果...就...**（条件）
- **举个例子**...（具体化）
- **反过来**...（对比）

## 两种输出模式（根据场景选择）

### 模式A：算命工具（给自己用）
- 简洁断语，看到八字马上能说
- "食神旺→温和有才华，但懒散"
- 像字典一样快速查阅
- 关键词：快、准、直接

### 模式B：分析报告（给客户看）
- 流畅易懂，有说服力
- 像跟朋友聊天，用因果关系串联
- 关键词：通俗、连贯、有理有据

**默认用模式B**，除非用户明确要求简洁断语。
