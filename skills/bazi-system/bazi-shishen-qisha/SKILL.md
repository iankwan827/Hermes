# 七杀专题

## 核心定义

- **阴阳**：同性相克（克我），阳见阳/阴见阴
- **本质**：激烈的压制，如猛兽追赶
- **性格**：强势、有魄力、压力大、危机感强、果断
- **代表**：压力、竞争对手、挑战、变动
- **为用时**：有上进心、有领导力、能成大事
- **为忌时**：压力大、小人多、易惹祸
- **制化**：食伤制杀（用才华制服）或印星化杀（用智慧转化）
