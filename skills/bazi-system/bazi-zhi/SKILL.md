# 八字痣相判断

## 核心口诀

### 一、天干法（必有痣）

**口诀：甲背乙胸丙丁肩，戊己面上庚辛膝，壬癸腿部及四肢**

| 天干 | 痣位置 |
|------|--------|
| 甲 | 背上 |
| 乙 | 胸前 |
| 丙丁 | 肩膀范围 |
| 戊己 | 脸上 |
| 庚辛 | 腰上/膝上 |
| 壬癸 | 腹部、四肢 |

**特点**：天干法必定有痣（地支占空亡可能无）

### 二、地支法（三句口诀）

**口诀：子午卯酉痣在胸，辰戌丑未痣在肚，寅申巳亥痣在阴**

| 地支组 | 痣位置 | 细分 |
|--------|--------|------|
| 子午卯酉 | 胸部 | 子午正中，卯酉在乳房两侧（含腋窝） |
| 辰戌丑未 | 肚脐附近 | 辰戌上部，丑未下部 |
| 寅申巳亥 | 阴部 | 寅申在腹股沟（大腿根），巳亥在器官处 |

**特殊断语**：
- 辰戌：有哥无弟，有弟本人带残疾；先克父
- 丑未：有弟无哥；先克母

**应验规律**：
- 越靠近日支的应验越明显
- 月柱日柱上有空亡会影响断事，但客观事实没有影响
- 找不到可能有刑（刻老疤）
- 前面找不到看后背（人体可翻转）

### 三、土五行法

**土=棕色印记**

身体上皮肤为棕色的就是印记。如果土多连在一起，可能有太极痣。

### 四、交叉验证

同部位可用多种方法交叉验证：
- 金木相克
- 辛金
- 土五行
- 年干十神是伤官、劫财、偏印（尤其伤官，脸上有记号可能性大）

符合两条以上，那就肯定有了。

## 眼角印记——面相入门

眼角=夫妻宫：
- 干净=感情专一、长久
- 有痣=感情丰富
- 一个固定的=一段稳定感情
- 两个变用的=两段
- 三个轮流的=三段
- 四个替换的=四段
- 其他=一次性的

**注意**：痣只代表"标记"，具体事件需结合个人八字原局判断。

---

### 四、丁火+阴木法（背部痣）

**丁火有生（有卯木/乙木生助）→ 背部必定有痣、痘子、小硬粒、小黑点等**

| 条件 | 痣位置 |
|------|--------|
| 天干有丁火 + 有卯木（阴木）生助 | 背部 |
| 丁火日元坐卯木（如丁卯） | 背部 |

**原理**：丁火是烛光之火、星光之火；卯木是阴木，是点蜡烛的材料。丁火坐卯木，说明此人的背部有标记。

**验证**：最起码毛孔粗大、黑头多。

**注意**：甲木、乙木、壬水、寅木等都是生助丁火的，但乙木（阴木）更对应"丁火有生"的情况，因为阳木不好"点蜡烛"。

## 使用注意

1. **"痣"的定义**：痣、痘子、小疱瘾、小黑点、小雀斑、血痣等小印记（统称"痣"）
2. **说法**：不要直接说"你有个痦子"，说"类似于痦子、伤疤等小的印记"
3. **翻转法**：前面找不到看后背对应位置
4. **睡姿影响**：子午卯酉前面几乎都能找到，找不到可能跟小时候睡姿有关
