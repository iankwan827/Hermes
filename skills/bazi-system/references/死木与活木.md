# 死木与活木

> 来源：第十九课讲师插播知识点
> 核心：遇到甲乙木日元时，先判断死活，再定取象和用神

## 定义

| 类型 | 条件 | 取象 |
|------|------|------|
| **活木** | 有根有水，还在生长 | 活的树、生长中的植物 |
| **死木** | 无水无根，已经死了 | 木材、木桩、干木头、被拔出来的木 |

## 核心逻辑：让木有价值

> "不管死木还是活木，都要让这个日元有价值。"

### 活木的价值路径
- 活木要茂盛生长 → 需要水 + 太阳（火）
- 用神：**火**（阳光→光合作用）+ **水**（养分）
- 生活意象：靠近路灯的树叶子黄得更慢，因为光照时间长，生命力延续更久
- 忌神：金（克木断根）

### 死木的价值路径
- 死木已经死了，不可能再活 → 要让它有经济价值
- 用神：**金**（雕刻工具：锯子=劈砍，凿子=精雕）
- 取象：木家具、根雕、木制乐器系列
- 讲师举例：100块木材 → 匠人切割雕刻抛光 → 1000块家具；再装饰金铜条 → 名贵家具
- 甚至唢呐制造：取木材→做爪→刨口→制造→抛光→成品
- 忌神：火（烧了就没价值了）

## 用神区别对比

| | 活木 | 死木 |
|--|------|------|
| **用神** | 火（太阳）+ 水（养分） | 金（雕刻工具） |
| **核心作用** | 光合作用、暖木气 | 劈砍、雕刻、装饰 |
| **忌神** | 金（克木断根） | 火（烧了就没价值了） |
| **取象** | 大树、植物 | 家具、根雕、乐器 |
| **辛金的作用** | 忌（克木） | 用（雕刻装饰） |

## 判断方法

1. 看地支有没有根（寅卯辰等木根）
2. 看有没有水（壬癸亥子等印星/水源）
3. 有根有水 = 活木；无根无水 = 死木
4. 有根但被冲断、有水但被截流 = 活木但环境极不利（"苟着活"）

## 案例应用

**案例四（丁卯己酉甲子丁卯）中的甲木：**
- 有根：双卯木为强根（但被酉金冲断一部分）
- 有水：日支子水印星生木（但子卯相刑打折）
- 判断：**活木**，但环境极不利
- 取象：夜晚星空下的大树，根被斧子砍断，水被截流，天上有两三颗星星（丁火），秋冬天
- 讲师原话："以后遇到甲乙木的时候，先看它是死木还是活木"

## 讲师原话

> "此木去向是什么？如果你能取出此木的取象，我算你厉害。"

> "让木有价值。什么木有价值？活木有价值。死木也有价值——无水无根之木，已经死掉了。就是你采下来的木材，这不就是死了吗？柴火烧了材，这种价值那不是很低贱的价值吗？"

> "死木的趋向——木家具、根雕、乐器系列等这种木质的东西。这才叫死木的趋向。同时你也得到了死木的用神——辛金。辛金这个主雕刻装饰。"
