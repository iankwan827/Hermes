# Phase 2-9 分析步骤详细模板

> ⚠️ 每个Phase标注了需要加载的速查表，分析时必须加载对应速查表才能正确调用知识点。

## Phase 2 命局旺衰 (6步)
**需要加载**：`天干地支取象速查`（五行旺衰判断）
1. 点明日主
2. 看月令得令/失令
3. 看坐支得地/失地
4. 逐柱分析天干地支力量
5. 综合定旺衰
6. 定格局

## Phase 3 喜忌用神 (4步)
**需要加载**：`天干地支取象速查`（五行喜忌）
1. 根据旺衰定用神忌神
2. 处理"虽克但有用/有害"的特殊五行
3. 根据地支冲合细化具体干支喜忌
4. 综合写出完整喜忌

## Phase 4 事业分析 (6步)
**需要加载**：`四柱代表速查`（事业职场维度）+ `天干地支取象速查`（行业取象）
1. 看官杀星（事业星）
2. 看财星与身的关系
3. 看神煞与日柱组合
4. 根据五行喜忌推荐行业（用取象skill的行业取象）
5. 判断体制内/外
6. 综合输出

## Phase 5 婚姻分析 (6步)
**需要加载**：`四柱代表速查`（六亲角色+心性性格）+ `宫位星神配合判断`（配偶判断方法）
1. 看天干冲合
2. 看日支婚姻宫（宫位为主）
3. 看夫妻星（星为辅验证）
4. 看桃花
5. 判断结婚时间
6. 综合输出

## Phase 6 性格分析 (5步)
**需要加载**：`十天干性格速查`（日元性格+日支脾气+年干时干表里+四柱心性）+ `天干地支取象速查`（本义+特质+讲师解读）
1. 日主五行本性 + **取象本义**（如甲木=参天大树→需要平台依靠）
2. 十神旺衰反映性格 + **取象特质**（如丁火=灯烛→内敛文雅）
3. 特殊组合 + **讲师独有解读**（如丁火+水=聪明/近视、卯木要凑堆）
4. 格局特点
5. 综合输出（用取象的语言描述，不要只列十神标签）

## Phase 7 六亲分析 (5步)
**需要加载**：`四柱代表速查`（六亲角色+身体部位）+ `宫位星神配合判断`（宫位为主判断方法）+ `天干地支取象速查`（身体取象）
1. 确定对应关系（宫位为主，星为辅）
2. 看宫位状态（旺衰、冲克、空亡）
3. 看宫位上的十神→判断六亲处境
4. 找该六亲的星→辅助验证
5. 综合输出

## Phase 8 大运流年（加载 bazi-dayun-liunian 后执行）
**需要加载**：`四柱代表速查`（时间阶段维度）
1. **Step 0 定格局定用忌**：用格局法推导用神忌神，绝不能抄脚本输出
2. **Step 1 查基调**：判定大运是助用神（吉运）还是助忌神（凶运）
3. **Step 2 找引线**：看流年天干透出什么十神，是用神还是忌神
4. **Step 3 看化学反应**：检查流年地支与大运、原局的冲合刑
5. **Step 4 下断语**：结合四个核心公式给出具体断语
6. 输出：每步大运（时间段→天干十神→地支冲合→综合吉凶→建议）+ 流年重点年份

## Phase 8.5 空亡分析（加载 bazi-kongwang 后执行）
1. 确定日柱旬首→查空亡地支
2. 四柱地支空亡情况
3. 空亡对婚姻/事业/健康的影响
4. 填实应期

## Phase 8.6 墓库分析（加载 bazi-muku，仅辰戌丑未出现时）
1. 确认原局/大运/流年有无辰戌丑未
2. 判断旺衰→旺为库、弱为墓
3. 看开库条件
4. 财库/官库/印库/食伤库具体断语
