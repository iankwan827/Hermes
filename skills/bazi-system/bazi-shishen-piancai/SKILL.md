# 偏财专题

## 核心定义

- **阴阳**：同性相克（我克），阳见阳/阴见阴
- **本质**：意外的收获，如中奖/投资
- **性格**：慷慨、灵活、大方、桃花旺
- '代表：情人（男命）、意外之财、投机、兼职
- **为用时**：交际能力强、求财手段多、桃花旺
- **为忌时**：花钱大手大脚、感情复杂
