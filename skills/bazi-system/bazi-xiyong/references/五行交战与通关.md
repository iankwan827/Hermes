## 一石三鸟原则

当某行太旺时，用它所生的五行可以同时泄+耗：
- 金水旺 → 用水所生的木 → 木泄水+耗金
- 木火旺 → 用木所生的土 → 土泄火+耗木
- 土金旺 → 用土所生的金 → 金泄土（不对，应该是水泄金+耗土）

正确的对应：
- 金水旺 → 木（水生木=泄水，金克木=耗金）
- 木火旺 → 土（火生土=泄火，木克土=耗木）
- 土金旺 → 水（金生水=泄金，土克水=耗土）
- 水木旺 → 火（木生火=泄木，水克火=耗水）
- 火土旺 → 金（土生金=泄土，火克金=耗火）

## 病药判断

只有特定组合才算"病"：
- 金水旺（三会金局+水多）→ 病
- 木火旺（三会木局+火多）→ 病
- 其他组合 → 看具体情况

不是所有盘都有病，没有病就显示"无明显病象"。
