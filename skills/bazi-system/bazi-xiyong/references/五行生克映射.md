# 五行生克映射

## 相生（a生b）

| a | → | b |
|---|---|---|
| 水 | 生 | 木 |
| 木 | 生 | 火 |
| 火 | 生 | 土 |
| 土 | 生 | 金 |
| 金 | 生 | 水 |

## 相克（a克b）

| a | → | b |
|---|---|---|
| 木 | 克 | 土 |
| 土 | 克 | 水 |
| 水 | 克 | 火 |
| 火 | 克 | 金 |
| 金 | 克 | 木 |

## 十神映射（以日主为基准）

| 关系 | 十神 | 示例（甲木日主） |
|------|------|-----------------|
| 同我 | 比劫 | 甲=比肩，乙=劫财 |
| 生我 | 印星 | 壬=偏印，癸=正印 |
| 我生 | 食伤 | 丙=食神，丁=伤官 |
| 我克 | 财星 | 戊=偏财，己=正财 |
| 克我 | 官杀 | 庚=七杀，辛=正官 |

## 判断函数

```javascript
function wxToShishen(wx, dayWx) {
  const shengMap = { '水':'木', '木':'火', '火':'土', '土':'金', '金':'水' };
  const keMap = { '木':'土', '土':'水', '水':'火', '火':'金', '金':'木' };
  
  if (wx === dayWx) return '比劫';
  if (shengMap[wx] === dayWx) return '印星'; // wx生日主
  if (shengMap[dayWx] === wx) return '食伤'; // 日主生wx
  if (keMap[dayWx] === wx) return '财星';   // 日主克wx
  if (keMap[wx] === dayWx) return '官杀';   // wx克日主
  return wx;
}
```

**常见错误：** shengMap和keMap写反会导致十神判断全部错误。
