# 十二长生与旺衰判断

## 十二长生体系

十二长生描述天干在地支中的能量状态：长生、沐浴、冠带、临官、帝旺、衰、病、死、墓、绝、胎、养。

### 版本二：部分流派阴干同阳干

此版本中，阴干也按阳干方向顺行（如乙木也长生在亥），不逆行。

## 得地的判断（传统三得法）

得地指日主在地支中是否有根。**使用十二长生表判断：**

**判定标准：**
- 日主在某地支处于**长生、沐浴、冠带、临官、帝旺**（前五位）→ 得地
- 日主在某地支处于衰、病、死、墓、绝、胎、养（后七位）→ 不得地

**示例（甲木日主）：**
- 地支有亥（长生）→ 得地 ✓
- 地支有子（沐浴）→ 得地 ✓
- 地支有丑（冠带）→ 得地 ✓
- 地支有寅（临官）→ 得地 ✓
- 地支有卯（帝旺）→ 得地 ✓
- 地支有辰（衰）→ 不得地 ✗
- 地支有巳（病）→ 不得地 ✗

**注意：** 得地只看十二长生状态，不看藏干五行是否同党。这是独立于五行生克的系统。

## 旺衰判断的综合方法（三得法）

**核心概念：三得法是三个独立系统，不是同一系统的不同方面。**

| 维度 | 系统 | 依据 | 与季节/生克的关系 |
|------|------|------|------------------|
| 得令 | 旺相休囚死 | 季节 | 纯看季节，跟生克无关 |
| 得地 | 十二长生 | 日干在地支的状态 | 跟季节无关，跟生克无关 |
| 得生 | 五行生克 | 天干地支是否生助日干 | 跟季节无关，跟长生无关 |

**月支可以同时满足三个条件，不算重复：**
- 得令：月支是季节（如寅月木旺）
- 得地：日干在月支的十二长生状态（如甲木临官在寅）
- 得生：月支藏干是否生助日干（如寅中藏甲木，比肩帮身）

**判定规则：**
- 三得二以上 → 身强
- 三得一或零 → 身弱
- 没有优先级，纯粹数数

**大运流年处理：**
- 原局先定身强弱（只看四柱）
- 大运流年加进来变成六柱，重新断一次
- 得令不变（只看月支），得地和得生重新计算

**⚠️ 不能只看十二长生，必须三得法综合判断。**

## 通关用神

当命局中两种五行激烈相战时，取能调和双方的五行为通关用神。

| 相战组合 | 通关用神 | 原理 |
|---------|---------|------|
| 金木相战 | 水 | 金生水→水生木，化敌为友 |
| 木土相战 | 火 | 木生火→火生土 |
| 土水相战 | 金 | 土生金→金生水 |
| 水火相战 | 木 | 水生木→木生火 |
| 火金相战 | 土 | 火生土→土生金 |

**通关用神优先级高于普通用神。** 当命局有明显相战时，先考虑通关，再考虑其他维度。

## 五行交战与成局

**五行交战（六冲导致）：**

| 冲合 | 交战 | 通关用神 |
|------|------|---------|
| 卯酉冲/寅申冲 | 金木交战 | 水（金生水→水生木） |
| 子午冲/巳亥冲 | 水火交战 | 木（水生木→木生火） |
| 辰戌冲/丑未冲 | 土土交战 | 金（土生金，泄土气） |

**成局（三会/三合导致，力量增强）：**

| 成局 | 力量变化 |
|------|---------|
| 申酉戌/巳酉丑 | 金力大增 |
| 寅卯辰/亥卯未 | 木力大增 |
| 亥子丑/申子辰 | 水力大增 |
| 巳午未/寅午戌 | 火力大增 |

**关键区别：**
- 交战 = 两个对立五行互克（冲）
- 成局 = 三个相同/相生五行汇聚，力量增强（会/合）
- 交战→用通关用神
- 成局→用病药用神（找克制旺行的五行）

## 食神泄秀（特殊格局）

身强+食神透出且有力=食神泄秀格，才华自然流露，以食神为用神。

**成立条件：**
- 日主身强（三得法判定）
- 食神透干或坐旺（有力）
- 无强枭克制食神

**取用：** 食神为用，泄身生财，才华变现。

**与其他格局的区别：**
- 普通身强→克泄耗（官杀/食伤/财星都可）
- 食神泄秀→专取食神（食神是最佳泄身方式）

## 病药用神

找命局的"病"（五行旺衰失衡），取"药"（对治的五行）。

**常见病症与药：**

| 病症 | 药 | 原理 |
|------|-----|------|
| 金水旺 | 火（克金）或土（克水） | 制旺扶弱 |
| 木火旺 | 水（克火）或金（克木） | 制旺扶弱 |
| 土金旺 | 木（克土）或火（克金） | 制旺扶弱 |
| 水木旺 | 土（克水）或金（克木） | 制旺扶弱 |
| 火土旺 | 水（克火）或木（克土） | 制旺扶弱 |

**判断方法：**
1. 统计天干地支各五行数量
2. 考虑成局后的力量增强（如三会金局→金力大增）
3. 找出最旺的五行 = 病
4. 取克制该旺行的五行为药

**病药 vs 通关的区别：**
- 病药：针对五行旺衰失衡（某行太旺）
- 通关：针对五行交战（两行互克）
- 两者可能同时存在，优先处理交战
