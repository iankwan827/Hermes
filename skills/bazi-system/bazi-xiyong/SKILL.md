# 八字取喜用神

> 核心方法：6个维度各取候选用神，看哪几个维度的用神重叠，重叠最多的=最稳用神。

---

## 一、6个维度

| # | 维度 | 看什么 | 输出 |
|---|------|--------|------|
| 1 | **格局** | 月令取格→格局的用神方向 | 候选用神A |
| 2 | **调候** | 出生季节寒暖→需要什么来调 | 候选用神B |
| 3 | **旺衰** | 身强→克泄耗；身弱→生扶 | 候选用神C |
| 4 | **病药** | 命局的"病"是什么→取对治的为"药" | 候选用神D |
| 5 | **连锁反应** | 用神X的喜神Y是否跟扶抑方向一致 | 验证/排除 |
| 6 | **特殊格局** | 三奇、魁罡、天干一字等 | 候选用神E（优先级最高） |

---

## 二、各维度详解

### 维度1：格局用神

月令取格后，格局决定用神方向（详见bazi-geju skill）。

| 格局 | 用神方向 | 说明 |
|------|---------|------|
| 正官格 | 财星（财生官）、印星（印化官） | **不是用正官本身** |
| 七杀格 | 食神（制杀）、印星（化杀） | |
| 正印格 | 官星（官生印）、比劫 | |
| 偏印格 | 食神（制枭）、比劫 | |
| 正财格 | 财星、官星（财生官） | |
| 偏财格 | 财星、官星 | |
| 食神格 | 食神生财、印星 | |
| 伤官格 | 伤官生财、印星（伤官佩印） | |

### 维度2：调候用神

| 出生季节 | 调候需求 | 调候用神 |
|---------|---------|---------|
| 亥子丑月（冬） | 太寒 | 火（丙丁） |
| 巳午未月（夏） | 太热 | 水（壬癸） |
| 寅卯月（春） | 偏寒偏湿 | 火为主 |
| 申酉月（秋） | 偏凉偏燥 | 看具体 |

调候优先级高于旺衰（"先活再说强弱"）。

### 维度3：旺衰用神

| 旺衰状态 | 扶抑方向 | 候选用神范围 |
|---------|---------|-------------|
| **身旺** | 克泄耗 | 官杀（克）、食伤（泄）、财星（耗） |
| **身弱** | 生扶 | 印星（生）、比劫（助） |

身弱→官杀不能做用神（扛不住克）
身强→官杀可以做用神

### 维度4：病药用神

找命局的"病"（失衡根源），取"药"（对治的五行）。

| 病症 | 药 |
|------|-----|
| 土多金埋 | 木（疏土） |
| 木多火塞 | 金（克木） |
| 水多木漂 | 土（克水） |
| 金多水浊 | 火（克金） |
| 火多土焦 | 水（克火） |

### 维度5：连锁反应验证

**核心规则：用神的喜神必须跟扶抑方向一致。**

- 身弱需要生扶 → 用神X的喜神Y必须也是生扶类（印星或比劫）
- 身旺需要克泄耗 → 用神X的喜神Y必须也是克泄耗类（官杀、食伤、财星）

**验证方法：**

| 扶抑方向 | 候选用神 | 喜神（生用神的） | 喜神类别 | 是否一致 |
|---------|---------|----------------|---------|---------| 
| 身弱→生扶 | 印星（水） | 金（金生水） | 金=克泄耗 | ❌ 矛盾 |
| 身弱→生扶 | 比劫（木） | 水（水生木） | 水=生扶 | ✅ 一致 |
| 身旺→克泄耗 | 官杀（金） | 土（土生金） | 土=克泄耗 | ✅ 一致 |
| 身旺→克泄耗 | 食伤（火） | 木（木生火） | 木=生扶 | ❌ 矛盾 |
| 身旺→克泄耗 | 财星（土） | 火（火生土） | 火=克泄耗 | ✅ 一致 |

### 维度6：特殊格局结构

| 类型 | 组合 | 说明 |
|------|------|------|
| 天三奇 | 甲丙戊 | 有其中两个缺第三个→缺的锁定为用神 |
| 地三奇 | 寅午戌 | 同上 |
| 魁罡 | 庚辰/庚戌/壬辰/戊戌 | 特殊取用规则 |
| 天干贵格 | 各天干专属 | 详见 `references/十天干贵格速查.md` |

特殊格局优先级最高，可突破旺衰方向限制。

## 三、融合判断流程

```
排盘
  ↓
第一步：格局取格→确定格局用神方向+排除格局忌神（如正印格忌财星金）
  ↓
第二步：5个五行（金木水火土）全部列出，不遗漏
  ↓
第三步：每个五行过6个维度（格局/调候/旺衰/病药/连锁反应/特殊格局）
  ↓
第四步：连锁反应验证→喜神方向矛盾或触犯格局忌神的排除
  ↓
第五步：数每个五行通过几个维度→通过最多的=最终用神
  ↓
输出：用神、喜神、忌神、仇神、闲神
```

**⚠️ 核心原则：格局推荐的用神只是维度之一，不能替代5个五行逐个检查。食伤、财星等"格局没推荐"的五行也可能通过所有维度成为最佳用神。**

## 五、常见错误

1. **❌ 不会做就问用户，不按skill流程走**：skill已经写好了6维度+5个五行逐个检查的完整流程。遇到卡住的情况，应该回头按流程走，而不是停下来问用户"怎么处理"。用户是知识来源，不是你的拐杖。
2. **❌ 格局忌神没有第一时间排除**：格局判定后，忌神必须立即从5个五行候选中删除，不能留到最后才排除。案例：正印格忌财星（金）→金从一开始就不应出现在候选里。
3. **❌ 没有5个五行逐个检查**：必须把金木水火土5个五行全部列出来，每个都过一遍6个维度，找通过最多的。不能只盯着格局推荐的用神死磕。
4. **❌ 格局推荐用神替代5行检查**：格局说用官杀或比劫，不代表只有官杀和比劫能用。食伤、财星等其他五行也可能通过所有维度，必须全部检查。
5. **❌ 连锁反应没有检查到底**：用神X的喜神Y如果是格局忌神→X也不能用。不要只看Y是否克日主，还要看Y是否触犯格局禁忌。
6. **❌ 旺衰只套公式不看实质**：必须分析地支实际力量集团和五行化学反应（见下方重要提醒）
7. **❌ 特殊格局被忽略**：三奇优先级最高，可突破旺衰方向
8. **❌ 调候不验证**：调候用神也需通过连锁反应验证
9. **❌ 单一维度取用神**：必须多维度交叉，找交集

### ⚠️ 旺衰判断必须看地支实际力量

旺衰判断不能只套公式。必须分析地支实际力量集团和五行化学反应。

**公式视角（初筛用）：** 得令/得地/得助三项计数→快速判断
**实质视角（定论用）：** 看地支结党、五行化学反应、天干是否为地支延伸

当公式和实质矛盾时，以实质为准。详见 `references/十二长生与旺衰判断.md` 和 bazi-geju skill。

### ⚠️ 三得法有两个版本

- **渊海子平原版**：得助看天干+地支整体（印星/比劫出现即算）
- **后人版本（课程教）**：得助只看天干透干（有盲区）

遇到天干无印无比但地支水木成势的盘，以后人版本会误判身弱。应以渊海子平原版为准或综合判断。
