# 比肩专题

## 核心定义

- **阴阳**：同性同类（同我），阳见阳/阴见阴
- **本质**：独立的自我，如兄弟并肩
- **性格**：自信、独立、讲义气、固执、以自我为中心
- **代表**：兄弟、朋友、同事、竞争
- **为用时**：有朋友帮、有上进心、独立自主
- **为忌时**：竞争激烈、人际纠纷、刚愎自用
