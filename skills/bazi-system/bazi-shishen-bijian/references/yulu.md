# 比肩语录集

## 性格（2条）

- **Day49** 5. 天干地支五行相同的人，一般比较豪爽仗义，但也比较急脾气，容易情绪突然爆发。比如甲寅、乙卯、丙午、丁巳、戊戌、己未、庚申、辛酉、壬子、癸亥等。

- **Day72** 2. 身旺的人一般抗压能力强，身弱的人一般定力差，容易受到外界影响，内心敏感，可能别人看来不算事的事，但身弱的人就很难接受，而且会无限放大痛苦，容易情绪崩溃。

## 婚姻感情（1条）

- **Day28** 3. 日支是比肩（如日柱干支为乙卯、甲寅之类干支为同一五行、阴阳又同性的）、劫财（如丙午、丁巳之类干支为同一五行、阴阳不同性的），夫妻五行同属一性、性格雷同、有争吵争斗之嫌、夫妻情缘关系表现为一般。不过此说是有使用条件的，那就是在日干身旺的情况下，才是如此假如。假如身弱，日支这个比肩、劫财就是喜用神，则所预示的信息是相反的。身弱日坐比肩代表夫妻同心，可以与你同甘共苦。日坐劫财，因为劫财多为阳刃，性暴，配偶虽然可以与你同甘共苦，但是难免不利之事，如争吵、伤残之类。

## 事业（1条）
