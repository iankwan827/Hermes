# 正印专题

## 核心定义

- **阴阳**：异性相生（生我），阳见阴/阴见阳
- **本质**：温和的庇护，如母亲照顾孩子
- **性格**：温柔、包容、善良、重传统、有贵人运
- **代表**：母亲、贵人、文凭、学业、护身之物
- **为用时**：有贵人、学业好、有庇护
- **为忌时**：懒惰、依赖、缺乏独立性
