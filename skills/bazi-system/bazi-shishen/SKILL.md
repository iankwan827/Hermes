## 三、十神实战应用

### 看性格
- 印星多→温柔善良，重传统，适合教育文化
- 比劫多→自信讲义气，以自我为中心
- 食伤多→乐观善表达，想法多（食神温和，伤官激进）
- 财星多→务实爱赚钱
- 官杀多→自律事业心强

### 看事业
- 食伤旺→创意、艺术
- 财星旺→经商、金融
- 官杀旺→管理、官场
- 比劫旺→合作、创业

### 看感情
- 男命：正财=正妻，偏财=情人
- 女命：正官=正夫，七杀=偏缘
- 食神旺女命→生贵女，温和持家
- 伤官旺女命→克夫（"伤官见官，为祸百端"）

### 看健康
- 印星→体质、免疫力
- 食伤→消化系统
- 财星→脾胃、气血
- 官杀→压力疾病
- 比劫→四肢、肝胆

## 四、讲师实用口诀（十神代表什么人）

> - 正印 = 温和的妈妈 / 贵人 / 护身之物

> - 劫财 = 朋友，蹭你酒的

> - 伤官 = 酒店演员，口碑好
> - 正财 = 稳定工作
> - 偏财 = 财票、意外之财
> - 正官 = 好老板，讲道理
> - 七杀 = 强势领导，压榨你

## 五、常见误区

1. 十神无绝对吉凶，为用神则吉，为忌神则凶
2. 不能孤立看单个十神，需结合日主旺衰和整体格局
3. 男女命十神差异：男命财星为妻，女命官杀为夫
4. **偏神多→非成大事者不成**，因为只有偏神才有非常规力量
5. **正神均衡多→一生平顺**（平凡但好命）

## Pitfalls

- 十神无绝对吉凶，必须结合用神忌神判断
- 不能孤立看单个十神，需结合日主旺衰和整体格局
- 男女命十神差异：男命财星为妻，女命官杀为夫
- 偏神多≠坏事，非成大事者不成
- 正神均衡多→一生平顺但平凡
- 伤官见官为祸百端（女命尤其注意）
- 财多坏印影响学习（学生时代最怕）
- **丁火不能当丙火用**：丁火是炉灶之火/蜡烛之火，贴身作用，不能暖土。三个丁火不会变成丙火，只是局部过热。详见 `references/丁火特性与三为过.md`
