# 抖音推流算法机制（2025年官方公开）

## 核心公式

推荐优先级 = 综合预测用户行为概率 × 行为价值权重

## 2025年新权重排序（从高到低）

1. 收藏率 ← 权重最高
2. 复访率（用户回来看你主页）
3. 铁粉互动
4. 5秒完播率
5. 整体完播率
6. 评论质量（不是数量）
7. 点赞
8. 转发

注意：完播率不再是第一指标，收藏率才是。

## 行为价值权重参考

| 行为 | 权重系数 | 说明 |
|------|---------|------|
| 转发 | 1.5-2.0 | 最高，代表社交信用背书 |
| 评论 | 1.2-1.5 | 次高，带关键词的评论权重更高 |
| 收藏 | 1.0-1.2 | 2024年重点升级维度 |
| 点赞 | 0.5-1.0 | 最低，因为成本最低 |

## 流量池分级门槛

| 层级 | 曝光量 | 核心考核门槛 | 淘汰比例 |
|------|--------|------------|---------|
| 冷启动池 | 300-1000 | 3秒/5秒留存率 | ~60% |
| 初级池 | 1000-5000 | 完播率>30%，互动率>5% | ~40% |
| 中级池 | 5000-3万 | 收藏率>2%，铁粉互动 | ~30% |
| 高级池 | 3万-50万 | 转发率>2%，完播率>15% | ~20% |
| 热门池 | 50万+ | 综合数据持续优秀 | - |

## 互动率计算

互动率 = (点赞+评论+分享+收藏) / 播放量 × 100%

## 赛马机制

同一时间段内，系统将同标签视频放入流量池PK数据，胜出者晋级更高层级。
数据达标则进入下一级流量池，不达标则停止推流。

## 第二波流量触发条件

最快响应（发布后2-6h）：完播率≥48%、点赞率≥5.2%、评论率≥1.8%、账号近7日平均互动率>4%
常规窗口（发布后12-36h）：占所有触发第二波流量案例的大部分

## 评论互动的特殊作用

- 评论的权重占比约30%，点赞占20%
- 评论之间的回复互动权重更高
- 短时间内评论数突然增加（互动速率变化）可以触发算法重新评估
- 即使视频推流已停止，新增评论互动可能触发二次推流
