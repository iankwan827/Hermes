# Whisper八字领域常见听错

## 同音字错误

| 听错结果 | 正确内容 | 说明 |
|----------|----------|------|
| 鬼害 | 癸亥 | 天干癸+地支亥，同音 |
| 鬼水 | 癸水 | 天干癸的同音 |
| 人鬼水 | 壬癸水 | 壬癸连读混淆 |
| 官鬼 | 官杀 | 十神术语混淆 |
| 人水 | 壬水 | 天干壬的同音 |
| 同步型 | 同五行 | 同音字 |

## 批量替换脚本

```python
import re

def fix_whisper_errors(text):
    """修正whisper在八字领域的常见听错"""
    replacements = {
        "鬼害": "癸亥",
        "鬼水": "癸水",
        "人鬼水": "壬癸水",
        "人水": "壬水",
        "官鬼": "官杀",
        "同步型": "同五行",
    }
    for wrong, correct in replacements.items():
        text = text.replace(wrong, correct)
    return text
```

## 注意

- 替换前建议先grep确认上下文，避免误替换
- 有些"鬼"字是正确的（如"枭神夺食"中的比喻），不要全部替换
- 最好只替换明确的天干地支组合
