# 八字知识库组织方法

## 用户偏好（重要）

用户明确指出：八字断语笔记应该按**十神组合**组织，而不是按婚姻/事业/财运等通用主题。

### 原因

实际断命流程：
1. 排盘 → 看命局中的十神组合
2. 根据组合查找对应的断语
3. 给客户解读

因此，笔记组织应该匹配这个工作流程。

### 正确的组织方式

```
十神组合/
├── 伤官格.md        (伤官见官、伤官配印、金水伤官等所有伤官组合)
├── 官杀格.md        (正官、七杀的各种组合，含杀印相生)
├── 食神格.md        (食神制杀、食神生财等)
├── 墓库.md          (辰戌丑未相关断语)
├── 空亡.md          (旬空相关断语)
├── 贵格.md          (十天干贵格大全)
├── 物品取象.md      (十神/地支/五行对应物品)
└── ...
```

### 错误的组织方式

```
婚姻/          ← 不要这样分
事业/          ← 不要这样分
财运/          ← 不要这样分
健康/          ← 不要这样分
```

## 四Agent分类法（推荐）

单Agent分类容易出现错位和遗漏。推荐四Agent协作：

### Agent分工

1. **Agent2（搬运工）**：逐条提取断语，提交审核
   - 从原始文档中提取每条断语
   - 标注来源（第X课）和关键词
   - 输出到 all_assertions.txt

2. **Agent1（标题审核）**：只看标题关键词，判断断语是否匹配
   - 不需要读全部内容，只判断"这条断语是不是讲这个主题的"
   - 例如标题"伤官格"，审核断语是否关于伤官的各种用法
   - 输出到 review_results.txt

3. **Agent4（条件检查）**：检查断语是否有完整的前置条件
   - 断语必须包含"条件+结论"，不能只有结论
   - ❌ 错误：适合从事管理、谈判专家（缺少条件）
   - ✅ 正确：【七杀有制化为权】适合从事管理、谈判专家
   - 如果缺少条件，标记为"需要补充条件"并建议补充内容

4. **Agent3（监控）**：确保无遗漏
   - 对比原始文档和提取结果
   - 检查是否有断语未被分类
   - 检查是否有错误匹配
   - 输出质检报告

### 实际流程

```
Agent2: 从44篇文档提取1,465条断语 → all_assertions.txt
Agent1: 逐条审核是否匹配标题 → review_results.txt
Agent4: 检查每条断语的条件完整性 → 标记缺条件的断语
Agent3: 检查遗漏 → 生成最终分类文件 + quality_report.md
```

### 关键词分类的陷阱

用关键词匹配会导致误分类：
- "伤官见官"和"伤官配印"都含"伤官"，但含义相反
- Agent1必须理解**完整概念**，不能只匹配部分关键词

## 标题命名规则

**用宽标题，不用窄标题**：
- ✅ 伤官格（包含伤官见官、伤官配印、金水伤官等）
- ❌ 伤官见官（太窄，会漏掉其他伤官组合）
- ✅ 官杀格（包含正官、七杀的各种组合）
- ❌ 官印格（不准确，官印相生只是其中一种）
- ❌ 杀印格（不准确，应合并到官杀格）

**原因**：实际断命中，看到命局有伤官，需要查所有伤官相关的断语，不只是"伤官见官"。

## 断语完整性规则

每条断语必须包含**前置条件+结论**，不能只有结论部分：

| 类型 | 示例 |
|------|------|
| ❌ 缺条件 | 适合从事管理、谈判专家 |
| ✅ 完整 | 【七杀有制化为权】适合从事管理、谈判专家 |
| ❌ 缺条件 | 主事业爆发、名声鹊起 |
| ✅ 完整 | 【火空则发】主事业爆发、名声鹊起 |

常见需要补充的条件：
- 格局名称（如"乙庚合化金格"）
- 日主（如"甲木日主"）
- 十神状态（如"七杀有制"）
- 五行旺衰（如"木旺无制"）

## 物品取象（重要参考）

八字中十神、地支、五行都对应具体物品，详见 `物品取象.md`：
- 五行对应物品（金→金属首饰、木→书籍字画等）
- 十神对应物品（正官→工作文件、七杀→防身用品等）
- 十二地支对应物品（子→电子设备、丑→收纳箱等）
- 神煞对应物品（桃花→情趣用品、华盖→宗教物品等）

## 质检要点

- 四Agent比三Agent更可靠：Agent4专门检查条件完整性
- 每条断语必须标注来源，便于回溯验证
- 标题必须匹配内容范围，避免过窄或过宽
- 分类完成后检查：每个文件是否混入其他主题的断语
- 断语必须有完整条件，不能只有结论
