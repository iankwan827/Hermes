# 抖音算法阈值与推流机制（2025-2026）

基于抖音官方公开的算法原理（2025年4月）和第三方实测数据整理。

## 核心公式

推荐优先级 = 用户行为概率 × 行为价值权重

算法不"理解"内容，只通过行为数据（点击、完播、点赞、评论、转发、收藏）预估用户对内容的价值反馈。

## 2025年权重排序（从高到低）

1. 收藏率 ← 权重最高（代表"长尾价值"）
2. 复访率（用户回来看你主页）
3. 铁粉互动
4. 5秒完播率
5. 整体完播率
6. 评论质量（不是数量，带关键词的评论权重更高）
7. 点赞（权重最低，因为成本最低）
8. 转发（社交信用背书）

### 行为价值权重系数（参考值）

| 行为 | 权重系数 | 说明 |
|------|---------|------|
| 转发 | 1.5-2.0 | 最高，社交信用背书 |
| 评论 | 1.2-1.5 | 次高，尤其是带关键词的 |
| 收藏 | 1.0-1.2 | 2024年重点升级维度 |
| 点赞 | 0.5-1.0 | 最低，成本最低 |

## 流量池分级与门槛

| 层级 | 曝光量 | 核心考核 | 淘汰率 |
|------|--------|---------|--------|
| 冷启动池 | 300-1000 | 3秒/5秒留存率 | ~60% |
| 初级池 | 1000-5000 | 完播率>30%，互动率>5% | ~40% |
| 中级池 | 5000-3万 | 收藏率>2%，铁粉互动 | ~30% |
| 高级池 | 3万-50万 | 转发率>2%，完播率>15% | ~20% |
| 热门池 | 50万+ | 综合数据持续优秀 | - |

## 第二波推流触发条件

- 最快：发布后2-6小时（需完播率≥48%、点赞率≥5.2%、评论率≥1.8%）
- 常规：发布后12-36小时
- 人工触发：小号评论制造互动信号（用户实测有效）

## 互动率计算

互动率 = (点赞 + 评论 + 转发 + 收藏) / 播放量 × 100%

## 完播率合格线

- 大盘合格线：15-20%
- 优秀：40-50%+
- 短视频（15秒）：>40%易进中级池
- 1分钟视频：>15%为合格

## 用户实测发现

1. 1条评论可以从0推到~1500播放
2. 更多评论 = 更高播放上限（需测试具体数量）
3. 算法对"互动速率变化"敏感，不只看绝对值
4. 停滞的视频突然出现评论互动 = 算法重新评估
5. 老视频可能有延迟释放（发布8天后仍在获推荐）
