# 课程笔记提取工作流

## 完整流程

1. **创建新文件夹**：`D:/hermes-agent/imge_v2/`（docs/ images/ images_renamed/）
2. **复制图片**：从 `D:/hermes-agent/imge/` 复制到 images/
3. **运行提取脚本**：`extract_and_rename.py` → 自动切割+提取+分类
4. **检查分类结果**：用户逐个检查 `_rename_map.json`，手动修正分类
5. **重命名图片**：按映射表把哈希值图片重命名为课程编号或内容名称

## 分类规则

### 识别课程编号
- 匹配文本中的"拾易八字课X"或"第X课"
- 中文数字自动转阿拉伯数字
- 识别到 → `第X课_xxx.png`

### 识别不到课程编号时，按内容分类
- 从内容前2000字提取关键词
- 匹配规则（优先级从高到低）：
  - 案例：案例、问题描述、命盘表格
  - 五行：五行、金木水火土、天干、地支
  - 婚姻：婚姻、夫妻、配偶、桃花
  - 事业：事业、职业、工作、官杀
  - 财运：财运、财星、发财
  - 子女：子女、孩子、生育
  - 健康：健康、疾病、心脏、肝胆
  - 性格：性格、日主、甲木
  - 风水：风水、阳宅、方位
  - 择日：择日、婚嫁、开业
  - 神煞：神煞、羊刃、天乙贵人
  - 格局：格局、从格、化气格

### 命名规则
- 用具体名称，不用笼统
- ✓ 心脏健康、戊己土、性爱姿势吉神、夫妻性爱空亡
- ✗ 健康课、五行课、案例课

## 注意事项

1. 课标题在图片最左边，蓝底白字
2. 大图用1500px段高切割（不用3000px）
3. 用户会逐个检查分类并手动修正
4. 禁止合并成ALL_COURSES.md（太长）
5. docs_v2是原始提取，references是加工知识库
